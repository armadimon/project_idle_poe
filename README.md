# project_idle_poe

**라이트한 PoE**를 지향하는 모바일 방치형 RPG를 기획한다. 전투는 완전 자동으로 진행하고 제작과 득템에 무게를 둔다. **종결 장비 제작이 핵심이며, 종결 장비를 통해 경쟁하는 게임**을 목표로 한다. 프로젝트 이름은 작업용 이름이며 출시명과 세계관은 미정이다.

종결 장비는 빌드별로 좋은 옵션 조합을 찾고, 그 조합의 옵션 등급과 수치까지 완성하는 혼합형을 기준으로 한다.

종결 장비 경쟁은 같은 도전에서 제작한 장비·스킬 조합이 낸 자동 전투 성과를 중심으로 평가하며, 주 지표는 최고 도달 단계다. 점점 강해지는 도전을 어디까지 돌파했는지 비교한다. 각 단계에 별도의 제한 시간을 적용해 주어진 시간 안에 돌파해야 한다. 실패 후 재도전은 실패한 단계부터 시작하며, 재도전 입장 자체에는 별도 재료·재화를 소모하지 않는다. 구체적인 시간 수치와 단계 구성·기록 인정 조건·그 밖의 실패 처리·재도전 횟수·초기화·동률 처리 및 보상은 별도로 확인한다.

파밍 던전은 장비 제작 재료로 패널티를 부여하고 추가 드롭 기회를 높이는 구조다. 최초 부여·한 줄 교체·고정 강도 패널티 6종과 보상 계산을 확인했다. 해금된 파밍 대상은 무료로 횟수·대기 시간 제한 없이 도전하며, 성공 기본 보상은 희귀 장비 1회·제작재료 2회 추첨이다. 실패·직접 포기에는 해당 도전 보상을 지급하지 않고 사용한 재료는 환급하지 않는다. 접속 중단은 상태를 보관해 같은 파밍 도전을 이어한다. 현재 규칙과 승인 근거는 [파밍 던전 변화 기획서](Docs/Design/Systems/Farming-Dungeon-Modification.md)에 모았다. 최고 도달 단계 경쟁은 모딩을 적용하지 않는 공통 도전 조건을 유지한다.

파밍은 1~5성 구간으로 나누고 해당 구간 첫 완주로 다음 구간을 해금한다. 구간과 같은 성급·선택한 부위의 장비를 얻으며, 기반과 옵션은 유효 후보에서 균등하게 추첨한다. 희귀 드롭의 옵션 개수는 4개 60%·5개 30%·6개 10%다. 현재 규칙과 정보 공개 범위는 [장비 득템·파밍 대상 기획서](Docs/Design/Systems/Equipment-Drops-and-Farming-Targets.md)에 모았다.

주력 제작 경로는 전투에서 얻은 장비의 기반과 기존 옵션을 보고 제작할 대상을 선별해 다듬는 방식이다.

제작 잠재력은 진행 구간에 따른 5단계의 장비 등급으로 구분하고, 성급 같은 직관적인 구분을 장비에 직접 표시한다. 표시되는 등급과 실제 제작 가능 범위의 구간을 일치시켜 게임 안에서 제작 투자 대상을 파악할 수 있게 한다. 역할은 1성 성장 초반, 2성 성장 중반, 3성 성장 후반, 4성 엔드게임 진입, 5성 종결 제작으로 배분한다.

개별 추가 옵션은 낮은 1단계부터 높은 7단계로 표시한다. 성급별 허용 범위는 1성 1~3·2성 2~4·3성 3~5·4성 4~6·5성 5~7이다. 첫 희귀 옵션은 접두 19종·접미 15종, 총 34종이며 단계별 정수 1단위 범위를 제공한다. 기반 기본 성능·고정 특성 수치·계열별 후보와 피해/방어 계산은 [옵션·전투 기능 기획서](Docs/Design/Systems/Equipment-Affixes-and-Combat-Numbers.md)에 모았다. 제작 작업별 추첨과 비용·실행/종료 처리는 [기본 제작 기획서](Docs/Design/Systems/Equipment-Crafting.md)를 따른다.

같은 옵션의 인접 등급은 수치 범위가 일부 겹치도록 설계한다. 하위 등급의 좋은 결과가 상위 등급의 낮은 결과보다 좋은 수치를 제공할 수 있으며, 첫 34종의 겹침 범위는 옵션·전투 기능 기획서의 수치표를 따른다. 5성 희귀 장비는 드롭과 제작 모두 최상위 등급의 추가 옵션을 허용하며, 파밍 희귀 드롭의 분포는 기능 기획서를 따르며 제작과 다른 획득 경로의 분포는 별도로 정한다.

획득한 희귀 장비의 성급은 고정하며, 다음 성급의 장비를 새로 얻어 제작 대상을 교체한다. 희귀 장비의 추가 옵션은 다른 장비로 이전하지 않으며, 새 장비에 붙은 옵션부터 다듬는다. 미장착 장비는 무료 500칸에 보관하고 전투 밖에서 비교·교체·제작·분해한다. 희귀 분해와 고유 단건 분해마다 기존 5종 제작재료 중 1개를 추첨하며 과거 제작 재료를 추가 환급하지 않는다. 보호·교체·보상과 파밍 공간은 [장비 관리 기획서](Docs/Design/Systems/Equipment-Inventory-Comparison-and-Salvage.md)를 따른다.

기본 제작 장비의 추가 옵션은 접두 최대 3개와 접미 최대 3개를 기준으로 한다. 희귀 장비의 전투 드롭에는 추가 옵션이 일부만 붙은 장비와 6개가 모두 찬 장비를 함께 제공한다.

장비는 주무기·보조 장비·방어구·장신구를 합해 10칸으로 구성하고 첫 무기는 한손검·양손도끼·마법봉이다. 기반마다 고정 특성 1개를 추가 옵션 6칸과 별도로 제공한다. 같은 기반·성급에서 특성 수치는 고정이며 기본 제작으로 바꾸지 않는다. 모든 기반 역할을 1~5성에 제공하고 같은 계열끼리 추가 옵션 후보를 공유한다. 실제 장착 관계와 기반 역할은 [장비 편성·기반 구조 기획서](Docs/Design/Systems/Equipment-Catalog-and-Base-Structure.md)에 모았다.

추가 옵션 제작은 희귀 장비를 중심으로 한다. 기본 제작 작업은 옵션 한 개씩 추가·제거·교체하는 세 종류를 각각 제공한다. 기본 세 작업에는 별도의 성공·실패 판정을 두지 않는다. 고유 장비는 정해진 특수 효과를 제공하며 추가 옵션 제작에서 제외한다. 고유는 부위 관계가 맞으면 여러 개를 함께 착용하고 총수 1개 제한을 두지 않는다. 첫 목록은 목걸이·반지·허리띠 각 1종을 4/5성으로 제공하며 같은 고유·성급의 성능은 고정이다. 해당 4/5성 목표 부위의 장비 추첨마다 희귀 97%·고유 3%를 적용하고 기존 보상 최대량은 유지한다. 고유는 단건 분해만 허용한다. 공통 규칙은 [고유 장비 기획서](Docs/Design/Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)를 따르며 개별 효과/수치·동일 고유 중복과 중첩은 후속 확인한다.

조율석 1개로 현재 붙어 있는 모든 추가 옵션의 종류·단계를 유지하고 각 정수값을 독립 균등 재추첨한다. 새 값은 같거나 나빠져도 바로 적용하며 기존 값으로 되돌리거나 환급하지 않는다.

추가·제거·교체·수치 재추첨은 각각 부여석·제거석·교체석·조율석을 1개 소모한다. 추가·제거·교체에서 범위를 좁히는 접두/접미 지정에는 집중석 1개를 추가 사용하며, 유효 그룹이 하나뿐이면 집중석을 소모하지 않는다. 전투 밖에서 장착 중 장비도 제작하고 무효 동작은 차감하지 않는다. 같은 결과·나빠진 결과도 확정 적용하며 취소/중단과 복원은 [기본 제작 기획서](Docs/Design/Systems/Equipment-Crafting.md)를 따른다.

제작 결과는 기본적으로 무작위이며, 재료나 작업으로 추첨 범위를 제한적으로 좁히는 통제 수단을 제공한다. 통제는 접두·접미 중 대상 그룹을 고르는 방식이며, 선택한 그룹 안의 개별 결과는 무작위다. 그룹 지정에는 기본 제작 비용 외에 추가 재료를 사용하고, 추가 통제 재료 없이 진행하는 제작도 제공한다. 세 작업 모두 통제를 허용하며 통제한 교체의 제거·추가는 같은 그룹 안에서 진행한다.

통제 재료 없이 교체할 때도 제거한 옵션의 그룹을 유지한다. 접두를 제거하면 새 접두, 접미를 제거하면 새 접미를 추첨해 교체 전후의 그룹별 옵션 개수는 유지한다. 제거할 기존 옵션과 새로 붙을 개별 옵션은 무작위다.

같은 종류의 추가 옵션은 한 희귀 장비에 1개만 허용한다. 등급·수치가 달라도 동일 종류로 보며, 드롭과 제작에 공통으로 적용한다. 접두 최대 3개·접미 최대 3개의 상한은 유지한다.

교체에서 방금 제거한 옵션 종류도 새 추첨 후보에 포함한다. 통제 여부에 관계없이 재등장을 허용하며, 같은 접두·접미 그룹과 동일 종류의 동시 중복 제한을 따른다. 옵션 종류가 그대로일 수 있다. 교체할 새 옵션의 성능 등급은 장비 성급의 허용 범위에서 다시 추첨하며, 기존보다 높거나 낮아질 수 있다. 통제 여부와 같은 종류의 재등장 여부에 관계없이 적용한다. 새 옵션의 성급별 허용 3단계는 각각 1/3, 단계 내 정수값은 균등 추첨한다.

희귀 장비의 추가·제거·교체·수치 재추첨에는 장비당 제작 횟수 제한을 두지 않는다. 각 작업의 실행 조건을 만족하고 필요한 비용을 지불하면 같은 장비를 계속 다듬을 수 있다. 기본 비용은 성급·반복 횟수에 관계없이 같으며 별도 골드·대기 시간·할증을 두지 않는다. 작업별 실행 조건과 기존 파밍 공급은 확정 기능 기획서를 따른다.

첫 제작 검증은 기본 4종과 집중석까지로 구성한다. 개별 옵션 잠금·영구 고정·확정 부여·추가 위험 강화와 별도 완성 비용/보너스는 도입하지 않으며, 분해 보호는 제작으로 옵션이 바뀌는 것을 막지 않는다. 기존 수치·자리 상한과 반복 제작 가능 상태를 유지하고 후속 특수 제작의 필요성은 목표 빌드와 파밍 시간을 정한 뒤 다시 검토한다. 승인 범위는 [DEC-0102](Docs/Design/Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md)와 [기본 제작 기획서](Docs/Design/Systems/Equipment-Crafting.md)를 따른다.

제작에서 가능한 옵션 후보·허용 옵션 등급·수치 범위와 옵션 종류별·등급별 추첨 확률을 게임 안에서 공개한다. 현재 장비와 선택한 작업·통제 조건에 적용되는 정보를 기준으로 하며, 확률은 기본 제작 기획서의 작업별 조건을 따르며 실제 화면 구성은 후속 확인한다.

장비·스킬의 작동 구조는 **PoE 1**, 아이템 제작은 **PoE 2**를 기준으로 삼는다. 공식 자료와 PoEDB 계열 데이터, 제작자·커뮤니티 기록을 조사해 기획에 활용한다.

세부 기획은 선택지 제안 → 사용자 확인 → 결정 기록 순서로 진행한다. 확인하지 않은 사항을 게임 사양으로 확정하지 않는다. 현재 단계는 기획이며 Unity 프로젝트와 게임 코드는 아직 없다.

## 내려받기

```sh
git clone --recurse-submodules https://github.com/armadimon/project_idle_poe.git
cd project_idle_poe
python3 Tools/validate_design.py
```

이미 복제한 저장소에서 원본 참고자료를 받으려면 다음 명령을 실행한다.

```sh
git submodule update --init --recursive
```

원본은 `References/game-design-ai-practice/`에서 읽을 수 있다. 서브모듈을 포함하지 않는 GitHub ZIP 다운로드에는 원문이 들어 있지 않다.
