# 부여 재화에 따른 던전 패널티 개수 조사

확인일: 2026-11-18. 사용자 지시에 따른 [DEC-0082](../Design/Decisions/DEC-0082-currency-dependent-random-count-for-initial-dungeon-penalties.md)의 참고 구조를 문헌으로 확인했다. PoE 클라이언트 실행·확률 측정·Unity 구현은 수행하지 않았다.

## 출처와 확인한 내용

| 출처 | 확인 버전과 내용 | 적용 한계 |
| --- | --- | --- |
| [PoEDB: Orb of Transmutation](https://poedb.tw/us/Orb_of_Transmutation) | 확인일의 동적 항목. 데이터 설명은 일반 아이템을 마법으로 변환. Community Wiki는 결과가 접두·접미 중 한쪽 또는 둘을 가질 수 있다고 설명 | 게임 패치 번호는 확인하지 못함. 아이템 일반 설명을 모든 지도·예외의 현행 규칙으로 일반화하지 않음 |
| [PoEDB: Orb of Alchemy](https://poedb.tw/us/Orb_of_Alchemy) | 확인일의 동적 항목. 데이터 설명은 일반 아이템을 희귀로 변환. Community Wiki는 일반적인 결과의 옵션 종류와 개수가 무작위이며 4~6개라는 설명과 지도 적용 예시를 제공 | 보석 예외도 구분하는 일반 설명이며, 우리 게임의 개수 범위나 실제 확률을 정하는 자료는 아님 |
| [PoEDB: Maps](https://poedb.tw/us/Maps) | 확인일의 맵 데이터와 Community Wiki | 구형 설명이 섞일 수 있어 같은 페이지를 단일 최신 패치 사양으로 취급하지 않음. 최신 맵 전체와 통화별 예외를 검증하지 않음 |

확인한 연결은 재화가 만드는 희귀도와 옵션 생성 규칙이 다르다는 구조다. 여기에서 우리 게임의 부여 재화별 개수 추첨 규칙을 구분할 수 있다는 것은 설계적 해석이다. 실제 범위·확률·재화 수는 사용자 확인 전까지 미정이다. 공식 통화 항목 URL 열람은 404로 실패해 근거로 사용하지 않았다.

## 호환성·라이선스·재사용 범위

이번 자료는 게임 규칙을 이해하기 위한 참고 문헌이며 Unity에 가져올 라이브러리가 아니다. PoEDB의 Community Wiki에 표시된 CC BY-NC-SA 3.0을 데이터·GGG 게임 자산 전체의 제품 재사용 허락으로 확대하지 않는다. 원문·통화 이름·이미지·게임 데이터는 제품에 복사하지 않고 규칙과 표현을 자체 작성한다.

관련 오픈소스 검색 도구의 고정 커밋·React/Vite 버전·AGPL 및 별도 데이터 라이선스와 Unity 호환성 한계는 [기존 맵 모딩 조사](2026-11-17-dungeon-modification.md)에 기록되어 있다. 이번 변경을 위해 새 라이브러리·코드·데이터를 반입하거나 설치·실행하지 않았다.

## 적용 범위와 검증 계획

사용자가 확인한 범위는 부여 재화에 따라 최초 패널티 개수를 무작위로 결정하는 원칙이다. 최초 일괄 부여와 이후 한 줄 교체를 유지한다. 기존 고정 개수 제안은 채택된 규칙이 아니며 미승인 상태의 수치를 구현에 전파하지 않는다.

다음에는 [부여 재화 종류 수](../Design/Proposals/Dungeon-Modification.md)를 비교하고, 확인 뒤 기존 제작 재료 공유 여부·재화별 개수 범위·확률·비용·보상을 제안한다. 수치 승인 뒤 표본별 개수 분포와 한 줄 교체의 개수 보존, 서로 다른 빌드의 클리어 성과·재료 소비를 검증한다. 현재 완료한 검증은 출처 열람과 기획 문서 검사이며 실제 확률·사용성·경제 검증은 미실시다.
