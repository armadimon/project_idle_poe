# 기본 제작의 실행·비용·확률 조사

확인일: 2026-11-18. 제작 재료·실행·비용·확률·종료는 후속 [DEC-0098](../Design/Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)에서 확인했고 [기본 제작 기획서](../Design/Systems/Equipment-Crafting.md)에 모았다. 이 규칙은 자체 초기값이며 게임 구현·경제 검증 완료와 구분한다.

이번 PoE2DB Chaos Orb 개별 페이지 열람은 시간 초과로 실패했다. 같은 효과를 설명한 제작 개요를 읽은 범위와 구분한다. 고정 poe2-craft README의 GitHub/Raw 재열람도 캐시 오류로 실패했으므로 해당 코드·라이선스를 새로 확인했다고 기록하지 않는다. 공개 시뮬레이터의 구조 설명은 기존 고정 조사 기록을 사용한다.

공식 0.5.0과 동적 DB를 최신 단일 규칙으로 섞지 않는다. 개요에 남은 다중 Desecrated 설명은 공식 패치의 개수 제한과 함께 무조건 적용할 수 없다. 이번 제안은 해당 특수 제작을 도입하지 않으며 기본 4종과 기존 그룹 통제만 구체화한다.

## 기획 해석·대안·권장 범위

기본 작업의 소비량과 유효 조건·보존 범위·대상 추첨을 한 흐름으로 보여 주면 어떤 중간 결과에 더 투자할지 판단하기 쉽다는 것이 기획 해석이다. 그룹을 지정해도 그 안의 개별 옵션은 무작위라는 차이를 비용과 정보에 연결한다.

성급/반복 비용 상승·서로 다른 가중치와 고정 비용/균등 추첨을 비교했다. 우선 기본 재료 1개·필요한 그룹 통제 1개 추가·유효 후보 내 균등 추첨을 제안한다. 이는 원작 비용·드롭률·제작 확률의 채택이 아니다. 부여석·제거석·교체석·조율석·집중석이라는 이름과 무효/취소·중단·장착 조건 처리는 우리 게임의 자체 설계로 후속 승인된 초기 규칙이다.

옵션 34종의 후보와 수치표는 [확정 기획](../Design/Systems/Equipment-Affixes-and-Combat-Numbers.md)을 사용하되 제작의 확률까지 승인됐다고 해석하지 않는다. 공급 30/15/35/15/5%와 던전 비용은 기존 파밍 승인값을 유지한다.

## 문헌 조사와 실제 검증

현재 Unity 6000.3.11f1의 C# 프로젝트에 웹 시뮬레이터를 도입하거나 원작 데이터를 복제하지 않는다. 참고할 것은 단계별 작업·유효 대상/후보·중단과 비용을 기록해 비교하는 접근이다. 구현 전에 현재 제작/저장 코드·공식 기술 문서와 대안을 조사하고 적용·검증 계획을 제안한다.

| 구분 | 이번 범위 |
| --- | --- |
| 문헌 | 공식 0.5.0 Item Changes·PoE2DB Crafting/Omen 재열람, 기존 공개 프로젝트·커뮤니티 기록 참조 |
| 새 라이브러리/데이터 도입 | 없음 |
| 문서 산술 | 개별 대상 균등과 그룹 합계, 새 종류·단계·정수값의 조건부 확률 설명 |
| 실행 검증 | PoE 2·공개 시뮬레이터·Unity의 제작 실행/저장 복원을 수행하지 않음 |
| 밸런스 | 현재 시간·몬스터·스킬·경제를 연결한 완성 비용과 실제 성장 속도는 미검증 |

승인 뒤 작업별 유효/무효·통제/강제 그룹·상한/중복·교체 재등장·단계/값 분포와 조율 독립성, 차감·정산·취소/중단·장착 장비의 능력치/젬 조건을 검증한다. 이후 실제 파밍 수급과 제작 비용을 연결해 중간 완성과 종결 제작 비용의 분포를 비교한다.
