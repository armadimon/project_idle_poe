# 잠금 해제는 최대 한 줄, 대상 전환 시 기존 줄 자동 잠금

파밍 던전의 패널티 목록에서 **잠금 해제할 수 있는 줄은 최대 한 줄**이다. **다른 줄을 잠금 해제하면 기존에 해제된 줄은 자동으로 잠긴다.** 교체를 실행할 때 해제된 해당 한 줄을 무작위로 바꾸고 나머지는 보존한다.

## 확인 근거와 범위

사용자는 1안 한 줄만 해제하고 다른 줄을 해제하면 기존 줄 자동 잠금, 2안 여러 줄을 해제하고 그 줄을 한 번에 모두 교체 중 1안을 선택했다. 사용자 답변은 “1”이다. 비용·횟수·결과 적용 방식은 별도 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 잠금 해제 범위와 대상 전환의 동작까지다. 각 줄 우측 잠금 체크박스와 체크한 줄의 보존, 지정한 한 개만 무작위 교체하는 범위를 유지한다.

처음 표시할 때 기본 잠금 상태와 전부 잠긴 상태의 처리, 현재 해제된 줄을 다시 잠그는 동작과 재추첨 뒤 잠금 상태 유지, 잠금에 따른 비용 변화는 별도로 확인한다. 최대 한 줄이라는 제한을 언제나 한 줄은 반드시 해제되어 있어야 한다는 규칙으로 확대하지 않는다.

재추첨 비용·횟수·실행 조건과 새 결과의 즉시 적용 또는 기존 결과와 선택, 추첨 확률·중복·같은 패널티 재등장·보상 변화·취소·환급도 미정이다. 던전 변화는 파밍에만 적용하고 최고 단계 경쟁은 공통 도전 조건을 유지한다.

이번 기록은 조작 기획이다. 화면 시안·리소스·엔진 구현과 실제 입력·가독성 검증을 수행한 기록으로 취급하지 않는다.
