# 좋은 드롭 장비를 골라 다듬는 제작 경로 중심

주력 제작 경로는 전투에서 얻은 장비의 기반과 기존 옵션을 보고 제작할 대상을 선별해 다듬는 방식으로 구성한다. 좋은 출발 장비를 발견하는 득템의 재미와 종결 장비 제작을 연결한다.

## 확인 근거와 범위

사용자는 좋은 드롭 장비를 골라 다듬기 중심, 빈 기반 장비부터 제작하기 중심, 두 경로 모두 주력의 세 대안 중 1번을 선택했다.

이번 결정은 주력 경로에 관한 것이다. 추가 옵션이 없는 기반 장비로 시작하는 보조 경로의 허용 여부와 공급 방식은 미정이다. 일부 옵션과 6개 옵션 구성을 함께 드롭하는 범위는 후속 [DEC-0021](DEC-0021-partial-and-full-affix-drops.md)에서 확인했다. 기반 장비의 종류, 드롭 시 최소 옵션 개수와 접두·접미 배치, 옵션 등급·수치와 분포, 완제품 드롭의 범위와 재료 공급은 별도로 확인한다.

장비의 가치를 공통 점수 하나로 평가하거나 제작할 장비를 자동 선별하는 기능은 이번 결정에 포함하지 않는다.
