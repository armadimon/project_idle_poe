# 5성 희귀 장비의 최상위 추가 옵션은 드롭과 제작 모두 허용

5성 희귀 장비에는 드롭 시에도 최상위 등급의 추가 옵션이 붙을 수 있다. 제작에서도 해당 최상위 등급을 허용한다.

## 확인 근거와 범위

사용자는 최상위 등급을 드롭과 제작 모두 허용하는 1안과, 제작에서만 허용하는 2안 중 1안을 선택했다. 이번 결정은 5성 희귀 장비의 최상위 추가 옵션 등급에 접근할 수 있는 획득 경로에 관한 것이다.

드롭에서 좋은 옵션을 얻고 기존 제작 규칙에 따라 장비를 다듬는 경로를 허용한다. 최상위 등급 옵션의 출현이나 개수, 원하는 옵션 종류·조합, 최고 수치를 보장하지 않는다.

드롭과 제작의 추첨 확률·등급 분포가 같다는 뜻은 아니다. 옵션 등급의 전체 단계 수는 후속 [DEC-0031](DEC-0031-seven-affix-performance-tiers.md)에서 7단계로 확인했다. 성급별 허용 범위는 후속 [DEC-0032](DEC-0032-three-affix-tiers-per-equipment-grade.md)에서 확인했다. 개별 옵션의 적용 범위·예외와 최상위 등급의 실제 수치 범위, 경로별 확률·분포와 완성 장비의 드롭 분포는 별도로 확인한다. 1~4성의 경로별 허용 옵션 등급과 고유 장비 규칙도 이번 범위에 포함하지 않는다.

같은 성급 안에 숨은 세밀한 아이템 레벨 경계를 다시 두지 않는 방향과, 좋은 드롭 장비를 골라 다듬는 주력 제작 경로는 유지한다. 이번 단계에는 확률 데이터나 게임 구현을 추가하지 않는다.
