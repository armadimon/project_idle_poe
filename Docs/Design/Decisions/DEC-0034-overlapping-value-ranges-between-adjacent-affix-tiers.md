# 같은 옵션의 인접 등급 간 수치 범위는 일부 겹치도록 설계

같은 옵션의 인접한 성능 등급은 수치 범위가 일부 겹치도록 설계한다. 하위 등급의 좋은 결과가 상위 등급의 낮은 결과보다 좋은 수치를 제공할 수 있다.

## 확인 근거와 범위

사용자는 상위 등급의 가장 낮은 결과도 하위 등급의 최고 결과보다 좋은 1안과, 인접 등급의 수치 범위가 일부 겹치는 2안 중 2안을 선택했다. 이번 결정은 같은 옵션의 인접 성능 등급 간 수치 범위에 관한 원칙이다.

옵션 등급과 실제 수치를 함께 비교하고 중간 등급의 좋은 결과를 활용할 여지를 둔다. 실제 겹침 폭과 각 등급의 최솟값·최댓값, 값의 간격·단위·분포·확률과 개별 옵션의 적용 범위·예외는 미정이다. 모든 옵션 종류의 겹침 비율이 같다고 정한 것은 아니다.

성급별로 허용하는 옵션 등급 범위와 등급 안에서 여러 수치를 추첨하는 기존 결정은 유지한다. 이번 선택으로 인접하지 않은 등급의 수치 범위까지 겹치거나 모든 하위 등급이 최상위 등급을 대체할 수 있다고 정하지 않는다. 서로 다른 옵션이나 장비 전체의 빌드 가치를 등급 하나로 평가하는 규칙도 아니다.

수치만 다시 추첨하는 작업은 후속 [DEC-0035](DEC-0035-reroll-affix-values-keeping-types-and-tiers.md)에서 옵션 종류·등급을 유지하는 방식으로 도입을 확인했다. 대상 개수·선택 방식·실행 조건·비용과 기존 수치의 보존, 다른 기본 작업의 옵션 보호, 최고 수치 보장과 보호 재료는 별도 확인한다. 이번 단계에는 실제 옵션 데이터나 게임 코드를 추가하지 않는다.
