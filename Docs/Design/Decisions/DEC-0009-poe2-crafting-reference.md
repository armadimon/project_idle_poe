# 아이템 제작은 PoE 2를 기준으로 기획

아이템 제작 시스템은 Path of Exile 2를 기준으로 기획한다. 장비·스킬의 작동 구조는 [PoE 1 기준](DEC-0005-poe1-reference.md)을 유지하고 제작 작업은 이 결정에 따른다.

## 확인 근거와 범위

사용자가 더 라이트한 제작 기준으로 PoE 2를 선택했다. 이는 참조할 제작 체계를 정한 결정이며 특정 패치의 모든 제작 수단, 원본 통화와 수치, 확률, 실패 시 옵션 손실이나 장비 파괴를 일괄 승인한 것은 아니다.

세부 제작 범위와 라이트함을 구현할 방법은 [조사](../../Research/Crafting/README.md)와 [적용 제안](../Proposals/Crafting-Endgame.md)을 보고 확인한다.
