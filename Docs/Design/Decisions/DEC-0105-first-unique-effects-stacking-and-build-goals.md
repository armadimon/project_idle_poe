# 첫 고유 3종의 효과·수치·중복과 빌드 검증 목표

사용자는 직전 요약과 링크한 상세 조건 전체를 “응 진행해줘”로 확인했다. 현행 정의는 [고유 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합하며 기획용 이름과 기반/일반 고정값·특수 효과, 동일 고유의 복수 착용·적용 순서를 하나의 승인으로 기록한다.

| 고유 | 기반 성능 | 일반 옵션 2개 | 특수 효과 1개 |
| --- | --- | --- | --- |
| 안정의 목걸이 | 힘형: 힘 +20→25 | 최대 생명력 +60→75, 힘 +16→20 | 치명타를 발생시키지 않으며 자신의 명중 피해 25% 증폭 |
| 속행의 반지 | 화염 저항형: 화염 저항 +12→14%p | 최대 생명력 +48→60, 재사용 회복 속도 12→15% 증가 | 재사용 회복 속도 40% 증가, 자신의 명중 피해 20% 감폭 |
| 불굴의 허리띠 | 생명력형: 최대 생명력 +80→100 | 최대 생명력 +60→75, 화염 저항 +12→15%p | 최대 보호막 0, 최대 생명력 30% 증가 |

| 연결 규칙 | 확정 규칙 |
| --- | --- |
| 같은 고유 착용 | 부위가 허용하면 가능. 속행의 반지 두 개를 반지 두 칸에 각각 착용 가능 |
| 일반 수치 | 각 장착 인스턴스의 기반 성능·일반 옵션을 모두 정상 합산 |
| 반지 중첩 | 개당 재사용 회복 +40%를 같은 증가 합계에 더하고, 명중 피해는 개당 ×0.8을 곱함. 두 개면 특수 효과만 +80%와 ×0.64 |
| 목걸이 우선순위 | 무기/젬 기본 확률·장비 증가·패널티와 관계없이 자신의 최종 치명타 확률 0. 치명타 배율은 해당 장착 중 피해에 기여하지 않음 |
| 허리띠 우선순위 | 다른 장비에서 보호막을 얻어도 최종 최대 보호막 0. 생명력 증가 +30%는 해당 증가 합계에 더함 |
| 함께 착용 | 목걸이+반지 2개+허리띠 동시 가능. 이 첫 목록으로 고유 4개를 착용할 수 있으며 추가 총수 제한을 두지 않음 |
| 효과 주체 | 자신의 기본 공격과 공격/주문 스킬의 명중 피해. 반지 회복 속도는 재사용 시간이 있는 자신의 스킬에 적용하며 공격/시전 동작 속도는 바꾸지 않음 |
| 장착/해제 상태 | 장착 변경 자체로 생명력/보호막을 회복하지 않음. 현재값은 새 최대값 이하로만 제한하며, 허리띠 해제 후 보호막은 0에서 기존 재충전 규칙으로 회복 |

4+5성 속행의 반지는 일반 재사용 회복 +27%와 특수 회복 +80%, 명중 피해 ×0.64다. 재사용의 다른 적용 가능한 증가를 I(%)라 하면 기본 시간÷(1+(I+40k)/100)이며 공격/시전 동작 시간은 별도다. 목걸이+반지 둘의 특수 명중 배율은 1.25×0.8²=0.8이다.

허리띠는 정액 생명력 합산 뒤 최대 생명력 증가 합계에 +30%를 더하고 최종 최대 생명력의 소수점 아래만 버린다. 기초 치명타/배율·보호막 장비 데이터는 삭제하지 않고 해제 시 다시 계산한다. 치명타와 보호막 수치를 다른 능력으로 전환하지 않는다.

## 검증 목표·후속 범위

비치명 명중, 재사용 중심의 잦은 스킬 사용, 보호막을 포기한 생명력 생존과 그 결합을 비교 목표로 둔다. 고유 없는 희귀 구성과도 비교한다. 목걸이 0/1×반지 0/1/2×허리띠 0/1의 12가지 착용 형태와 성급/혼합, 요구 능력치와 생존·동작 병목·희귀 옵션의 기여를 같은 조건에서 볼 계획이다.

효과 주체는 자신의 기본 공격과 공격/주문 명중이다. 지속 피해·소환수·상태이상, 정식 젬 성장/획득·직업·패시브·몬스터/파밍 시간, 추가 고유/효과는 이번에 확정하지 않는다. 기존 고유의 드롭·분해·성급 고정·제작 불가는 유지한다.

[조사](../../Research/2026-11-19-unique-effects-stacking-and-build-cases.md)의 문헌·정의/산술 확인과 실제 실행을 구분한다. 이번에는 기획 문서만 반영했으며 새 고유의 Unity 데이터/전투/저장·PoB 실행·경제/사용성 검증은 수행하지 않았다. 구현 전 기술 조사와 적용·검증 계획을 별도로 제안한다.
