# 파밍 던전 준비·변경 기본 동작

사용자는 아래 **던전 준비·변경 기본 동작 묶음 전체**에 “응 진행해줘”라고 답했다. 현행 규칙은 [파밍 던전 변화 기획서](../Systems/Farming-Dungeon-Modification.md)에 통합한다.

## 확인된 기본 동작

| 항목 | 확정 동작 |
| --- | --- |
| 입장 | 패널티를 부여하지 않은 상태로도 도전 가능 |
| 최초 부여 비용 | 추가·교체 재료 중 선택한 한 종류의 재료 1개 소모 |
| 한 줄 교체 비용 | 교체할 때마다 옵션 교체 재료 1개 소모 |
| 부여 후 조정 | 같은 도전 준비에서 최초 부여는 1회. 이후 추가·전체 재추첨 없이 한 줄 교체만 제공 |
| 잠금 | 최초에는 전부 잠금. 선택한 줄은 교체 후에도 해제 상태 유지 |
| 실행 불가 처리 | 전부 잠겼거나 재료가 부족하면 교체 비활성화·사유 안내·재료 차감 없음 |
| 변경 시점 | 전투 시작 전 준비 중에만 변경 가능 |

## 기존 규칙과의 연결

최초 부여의 개수별 확률은 기존대로 추가 재료의 1개·2개 각각 50%, 교체 재료의 3개·4개 각각 50%다. 이번 1개 소모는 부여할 패널티 개수가 아니라 선택한 재료의 수량이다.

최대 한 줄만 잠금 해제하며 다른 줄을 해제하면 기존 줄은 자동으로 잠긴다. 한 줄 교체는 새 결과를 바로 적용하고 나머지 줄과 전체 개수를 보존한다. 같은 조건에서 반복 교체에 따른 비용 증가는 없고 별도 교체 횟수 제한도 없다. 장비 제작의 기본 재료를 공유하지만 장비 제작 자체의 소모량을 1개로 정하는 결정은 아니다.

성공·실패 후 패널티와 연결된 보상 강화 설정 초기화, 실패한 도전의 패널티 교체 재료 환급 없음, 같은 대상의 새 도전 허용과 재도전 입장 자체의 별도 비용 없음은 유지한다.

## 확인 범위와 미정 사항

이번 확인은 위 준비·변경 동작까지다. 패널티 없는 입장 허용은 최초 입장 자체의 비용을 확정하지 않는다. 최초 부여 재료의 환급·취소·중단·재접속·대상 전환과 다른 종료 예외는 별도로 확인한다.

패널티 종류·수치·중복·종류별 확률·보상 강화 공식은 다음 콘텐츠 묶음의 제안이며 아직 승인되지 않았다. 이번 승인은 기획 확정과 문서 반영으로 처리하며 개인 파밍 모딩의 Unity 기능·화면 구현이나 정식 밸런스 검증 완료로 확대하지 않는다.

## 검증

문서 검사 뒤 기능 구현을 별도로 승인받으면 준비 흐름 전체의 무패널티 입장·재료 선택과 차감·잠금 전환·한 줄 교체·전투 시작을 검증한다. 전부 잠겼거나 교체 재료가 부족할 때 차감이 없는지와 나머지 줄·개수 보존을 확인한다. 실제 난도·경제 검증은 관련 콘텐츠와 수급 수치를 확인받은 뒤 수행한다.
