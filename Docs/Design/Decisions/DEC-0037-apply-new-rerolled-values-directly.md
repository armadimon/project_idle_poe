# 수치 재추첨의 새 결과는 바로 적용

수치 재추첨의 새 결과를 바로 적용한다. 수치가 나빠져도 기존 값을 대체한다. 재추첨 후 기존 결과와 새 결과 중 하나를 고르는 방식을 제공하지 않는다.

## 확인 근거와 범위

사용자는 새 결과를 바로 적용하는 1안과 기존·새 결과 중 한 세트를 선택하는 2안 중 1안을 선택했다. 이번 결정은 수치 재추첨 작업 실행 뒤의 결과 적용 규칙이다.

옵션 종류·등급을 유지하고 현재 붙은 모든 추가 옵션의 수치를 함께 재추첨하는 기존 결정을 따른다. 종류나 등급까지 재추첨하거나 빈 칸에 새 옵션을 추가하는 작업으로 바꾸지 않는다.

재료·비용과 실행 조건, 추첨 분포·확률과 추가 통제·보호 경로의 도입 여부는 미정이다. 이번 선택을 다른 제작 작업의 결과 적용 규칙이나 별도 되돌리기·보호 기능의 승인으로 확장하지 않는다. 작업 실행 전 확인 방법과 구체적인 화면·조작도 별도로 확인한다.

장비 성급 고정과 옵션 이전 없음, 성급별 허용 등급과 수치 범위 안의 추첨은 기존 결정을 따른다. 이번 단계에는 실제 옵션·재료 데이터나 게임 코드를 추가하지 않는다.
