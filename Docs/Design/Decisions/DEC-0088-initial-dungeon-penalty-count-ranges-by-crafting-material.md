# 최초 패널티 개수 범위는 추가 재료 1~2개·교체 재료 3~4개

파밍 던전의 최초 패널티 부여 개수는 **옵션 추가의 기본 재료 사용 시 1~2개, 옵션 교체의 기본 재료 사용 시 3~4개를 무작위로 결정**한다.

| 최초 부여에 사용하는 재료 | 무작위로 생성할 패널티 개수 |
| --- | --- |
| 옵션 추가의 기본 재료 | 1개 또는 2개 |
| 옵션 교체의 기본 재료 | 3개 또는 4개 |

## 확인 근거와 범위

사용자는 1안 옵션 추가 재료 1~2개·옵션 교체 재료 3~4개, 2안 옵션 추가 재료 1~2개·옵션 교체 재료 4~6개 중 1안을 선택했다. 사용자 답변은 “1”이다. 모두 범위 안에서 무작위로 결정하며, 개수별 확률·재료 소모량·보상 수치는 별도로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 최초 부여에서 생성할 패널티 개수 범위까지다. 표의 숫자는 소모하는 재료 수량이 아니다. 개수별 확률은 후속 [DEC-0089](DEC-0089-initial-dungeon-penalty-generation-rules.md)에서 각 범위의 두 개수를 각각 50%로 추첨하는 것으로 확인했다. 패널티 종류 및 수치의 추첨 확률은 별도 확인 사항이다.

기존의 한 번의 작업으로 최초 패널티들을 함께 부여하는 방식과 두 기본 재료의 공유를 유지한다. 이후 지정한 패널티 한 줄 교체는 나머지 줄을 보존하며, 전체 개수를 다시 추첨하거나 늘리는 작업으로 바뀌지 않는다.

재료 이름·실제 소모량·공급·실행 조건·보상 강화는 별도로 확인한다. 옵션 교체 재료가 최초 부여에서 더 많은 패널티를 만들더라도 재료 가격·희소성·전반적인 성능 순서나 장비 제작과 같은 비용을 확정하지 않는다.

최초 부여 후 추가 허용·전체 최대 개수·패널티 없는 입장·패널티 중복·삭제와 다른 변화 작업의 도입 여부도 미정이다. 성공·실패 후 패널티와 연결된 보상 강화 설정 초기화, 실패 시 교체 재료 환급 없음은 유지한다.

이번 기록은 기획 문서 반영까지다. 재화·개수 추첨 기능이나 실제 확률을 구현하지 않았으며 난도·경제·재미 실험은 수행하지 않았다.
