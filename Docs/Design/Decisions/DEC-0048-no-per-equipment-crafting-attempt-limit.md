# 희귀 장비의 네 제작 작업에 횟수 제한 없음

희귀 장비의 추가·제거·교체·수치 재추첨에는 장비당 제작 횟수 제한을 두지 않는다. 각 작업의 실행 조건을 만족하고 필요한 비용을 지불하면 같은 장비를 계속 다듬을 수 있다.

네 작업의 실행 횟수가 누적되었다는 이유로 해당 장비의 제작 가능 횟수가 소진되거나 제작을 종료하는 구조를 두지 않는다.

## 확인 근거와 범위

사용자는 1안 횟수 제한 없음과 2안 네 작업이 장비당 공통 한도를 소모하는 횟수 제한 중 1안을 선택했다. 희귀 장비 하나에 추가·제거·교체·수치 재추첨을 공통으로 적용한다고 명시한 질문에 대한 선택이다.

이번 결정은 위 네 작업의 장비당 제작 횟수 제한 여부다. 옵션의 빈 칸·제거 대상·재료 등 각 작업의 실행 조건은 계속 만족해야 한다. 실행 불가 상황의 처리와 구체적인 비용·소모량·공급은 별도로 확인한다.

횟수 제한이 없다는 것은 무료 제작, 원하는 결과나 성능 향상 보장, 기존 옵션 보호 기능을 채택한 것이 아니다. 반복 제작의 비용 변화, 별도 특수 제작·보호 수단과 그 제약도 이번 결정으로 정하지 않는다. 추가·제거·교체의 별도 성공·실패 판정 없음과 수치 재추첨의 기존 승인 범위는 유지한다.

장비 성급 고정과 추가 옵션 이전 없음, 접두·접미 상한과 추첨 규칙, 작업별 기본 재료 4종과 공통 통제 재료 1종을 유지한다. 실제 비용·확률 데이터나 게임 코드는 이 기록에 추가하지 않는다.
