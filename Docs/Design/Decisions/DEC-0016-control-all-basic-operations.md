# 추가·제거·교체 모두 접두·접미 통제 허용

기본 제작의 추가·제거·교체 세 작업 모두 접두 또는 접미를 선택하는 통제를 허용한다. 선택한 그룹 안의 개별 결과는 무작위다.

| 통제한 작업 | 대상 범위 |
| --- | --- |
| 추가 | 선택한 그룹에 새 옵션 한 개를 추가 |
| 제거 | 선택한 그룹의 기존 옵션 중 한 개를 제거 |
| 교체 | 선택한 그룹의 기존 옵션 중 한 개를 제거하고, 같은 그룹의 새 옵션 한 개를 추가 |

## 확인 근거와 범위

사용자는 세 작업 모두 허용, 추가·제거에만 허용, 추가에만 허용하는 세 대안 중 1번을 선택했다. 통제한 교체에서 제거와 추가를 같은 그룹 안에서 진행하는 범위까지 확인했다.

이 결정은 통제를 사용할 수 있는 작업의 범위다. 통제의 비용과 재료, 통제 없이 실행 가능한 작업의 범위는 미정이다. 선택한 그룹에 대상이나 빈자리가 없는 경우의 처리, 추첨 후보와 가중치, 실행 조건도 별도로 확인한다. 기본 세 작업에 별도의 성공·실패 판정을 두지 않는 범위는 후속 [DEC-0018](DEC-0018-basic-crafting-no-failure-roll.md)에서 확인했다.

원하는 개별 옵션을 지정하거나 별도의 옵션 보호 기능을 추가하는 결정은 아니다.
