# 동일 추가 옵션 종류는 희귀 장비당 1개

같은 종류의 추가 옵션은 한 희귀 장비에 1개만 허용한다. 등급·수치가 달라도 같은 종류로 판단하며, 동일 종류를 동시에 여러 개 붙이지 않는다. 이 규칙은 드롭과 제작에 공통으로 적용한다.

접두 최대 3개·접미 최대 3개, 합계 최대 6개의 상한은 유지한다.

## 확인 근거와 범위

사용자는 1안 동일 종류는 장비당 1개와 2안 동일 종류 중복 허용 중 1안을 선택했다. 드롭·제작 공통으로 적용하며 등급·수치가 달라도 같은 종류로 본다고 명시한 질문에 대한 선택이다.

이번 결정은 한 희귀 장비의 추가 옵션 중 동일 종류가 동시에 존재할 수 있는지에 관한 것이다. 다른 종류의 추가 옵션으로 조합을 구성하고, 각 옵션의 등급·수치를 완성하는 기존 방향과 함께 적용한다.

서로 다른 추가 옵션이 일부 능력치를 함께 제공하는 경우, 기반 고정 특성이나 고유 효과와의 능력치 중첩, 서로 다른 장비에 붙은 효과의 중첩은 별도 확인한다. 실제 옵션 종류의 이름·분류·수치와 예외 목록은 아직 정하지 않았다.

교체로 제거한 종류가 새 옵션의 추첨 후보에 다시 포함될지는 별도로 확인한다. 동일 종류의 동시 중복을 제한하는 이번 선택만으로 제거된 종류의 재등장을 금지하지 않는다.

기존 교체의 같은 접두·접미 그룹 처리와 무작위 결과, 재료 구성은 유지한다. 개별 추첨 가중치·확률, 후보 부족과 실행 불가 상황의 처리는 미정이다. 실제 옵션 데이터나 게임 코드는 추가하지 않는다.
