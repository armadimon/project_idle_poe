# 파밍 던전의 패널티는 무작위 부여

파밍에 적용하는 던전 변화 시스템의 **패널티는 플레이어가 고르지 않고 무작위로 부여**한다.

## 확인 근거와 범위

사용자는 1안 무작위 후보 중 선택, 2안 무작위 부여, 3안 원하는 패널티 직접 지정 중 **2안**을 선택했다. 사용자 답변은 “2”다. 후보 수·재추첨·비용·보상 수치는 이후 따로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 패널티 부여 방식까지다. 재추첨은 후속 [DEC-0064](DEC-0064-reroll-one-selected-dungeon-penalty.md)에서 지정한 한 개를 무작위 교체하고 나머지를 보존하는 것으로 확인했다. 각 줄 우측의 잠금 토글은 [DEC-0065](DEC-0065-right-side-lock-checkbox-for-dungeon-penalty-rows.md)에서 확인했다. 잠금과 교체 대상의 연동 방식, 패널티 종류·개수·수치·중첩과 추첨 확률, 삭제·취소 및 추가 통제 수단의 도입 여부는 별도로 확인한다. 모든 패널티를 같은 확률로 뽑거나 빌드에 유리한 결과를 보장하는 규칙은 정하지 않는다.

재화의 종류·소모량·소모 시점, 보상 강화의 종류·수치와 지급 조건, 변화의 지속 범위와 파밍 실패 후 재시도·유지·재소모·환급도 미정이다. 무작위 부여를 전투마다 자동으로 새로 추첨한다는 규칙으로 확대하지 않는다.

던전 변화는 파밍에만 적용하고 최고 도달 단계 경쟁은 공통 도전 조건을 유지한다. 장비 제작의 통제·재료·실패 판정 규칙을 던전 변화에 자동 적용하지 않는다. 이번 기록에는 기능·수치·화면 구현을 추가하지 않는다.
