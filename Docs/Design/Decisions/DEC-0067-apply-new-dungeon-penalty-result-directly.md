# 패널티 교체의 새 결과는 즉시 적용

파밍 던전의 패널티 한 줄을 교체할 때 **추첨한 새 결과를 바로 적용**한다. 빌드에 더 불리한 결과여도 기존 결과를 대체한다.

## 확인 근거와 범위

사용자는 1안 새 결과 바로 적용, 2안 기존·새 결과 중 선택 중 1안을 선택했다. 사용자 답변은 “1”이다. 1안은 조작이 단순하지만 빌드에 더 불리한 결과도 적용되는 선택지였다. 비용·횟수와 기본 잠금 상태는 별도로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 교체 결과의 적용 방식까지다. 기존 결과와 새 결과 중 하나를 고르는 단계는 두지 않는다. 교체 대상 한 줄의 새 결과만 적용하며 잠긴 나머지 줄은 보존한다. 한 줄만 잠금 해제하고 다른 줄을 해제하면 기존 줄이 자동 잠금되는 규칙은 유지한다.

재화의 종류·소모량·소모 시점과 교체 횟수·실행 조건·비용 증가 여부, 추첨 확률·중복·같은 패널티 재등장, 보상 변화·취소·되돌리기·환급은 별도로 확인한다. 기본 잠금 상태·전체 잠금 처리와 교체 뒤 잠금 상태 유지·변화 지속 범위도 미정이다.

던전 변화는 파밍에만 적용하고 최고 도달 단계 경쟁은 공통 도전 조건을 유지한다. 기존 장비 제작의 결과 적용을 자동 확장한 것이 아니라 이번 사용자 선택으로 확인한 던전 규칙이다. 이번 기록에는 기능·수치·화면 구현이나 실제 전투·경제 검증을 추가하지 않는다.
