# 모바일을 주력 플랫폼으로 기획

모바일을 주력 플랫폼으로 기획한다.

## 확인 근거와 범위

사용자가 주력 플랫폼을 묻는 질문에서 모바일 우선을 선택했다. 화면 방향, 지원 운영체제와 기기, 입력 배치, PC 지원 여부는 아직 결정하지 않았다.
