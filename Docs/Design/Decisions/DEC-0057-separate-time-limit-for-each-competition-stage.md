# 단계 도전에 각 단계별 제한 시간 적용

최고 도달 단계를 비교하는 경쟁의 도전에는 각 단계에 별도의 제한 시간을 적용한다. 각 단계를 주어진 시간 안에 돌파해야 한다.

## 확인 근거와 범위

사용자는 1안 단계마다 제한 시간, 2안 도전 전체에 공통 제한 시간, 3안 시간 제한 없음 중 1안을 선택했다. 구체적인 시간과 실패 처리는 선택 후 따로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 시간 제한을 적용하는 단위까지다. 도전 전체에 공통 제한 시간을 함께 두는 구성은 채택하지 않는다. 구체적인 제한 시간 수치와 모든 단계의 시간을 같게 둘지, 시간 측정의 시작·정지 조건은 미정이다.

시간 초과 시 기록을 인정하는 범위와 실패 후 행동, 재도전의 시작 지점·비용·횟수·보상, 체력·적·스킬 재사용 시간 등의 재설정은 별도로 확인한다. 단계 기록·동률·시즌·초기화·보상도 이번 선택으로 정하지 않는다.

자동 전투 성과 중심과 최고 도달 단계 지표, 기존 장비·스킬 조합의 승인 범위는 유지한다. 시간 수치나 경쟁 시스템 코드는 이 기록에 추가하지 않는다.
