# 종결 장비 경쟁의 주 지표는 최고 도달 단계

종결 장비 경쟁에서 자동 전투 성과를 비교하는 주 지표는 최고 도달 단계다. 같은 도전에서 점점 강해지는 단계를 어디까지 돌파했는지 비교한다.

## 확인 근거와 범위

사용자는 1안 최고 도달 단계, 2안 제한 시간 내 누적 피해량, 3안 같은 도전의 클리어 시간 중 1안을 선택했다. 세부 조건과 동률 처리는 선택 후 따로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 경쟁의 주 평가 지표까지다. 기록으로 인정하는 세부 조건과 단계의 구성·수·상한, 시간 제한과 실패 처리, 동일 단계 기록의 동률 처리는 미정이다. 무한 단계나 특정 보스·던전 구성을 자동으로 채택하지 않는다.

피해량·클리어 시간을 보조 지표나 동률 기준으로 제공할지, 여러 지표를 합산하거나 여러 경쟁 모드를 함께 제공할지는 별도 확인한다. 평가 조건과 공식·보상도 이번 결정으로 정하지 않는다.

자동 전투 성과 중심과 기존 장비·스킬 조합의 승인 범위는 유지한다. 장비·스킬 외 캐릭터 성장 차이의 취급, 순위표·시즌·초기화·직접 PvP·매칭·거래 규칙도 별도 확인한다. 이번 기록에는 실제 경쟁 수치나 시스템 코드를 추가하지 않는다.
