# 기본 제작의 재료·비용·확률·종료 처리

사용자는 직전 응답의 요약과 링크한 상세 조건 전체를 “오케이 진행해줘”로 확인했다. 현행 규칙은 [희귀 장비 기본 제작 기획서](../Systems/Equipment-Crafting.md)에 통합한다.

| 항목 | 확정 규칙 |
| --- | --- |
| 재료·비용 | 부여석·제거석·교체석·조율석은 해당 작업에 1개, 접두/접미 지정에 집중석 1개 추가 |
| 공통 비용 | 별도 골드·대기 시간·성급별 비용 증가·반복 할증 없음 |
| 대상·보존 | 전투 밖의 소유 희귀 장비, 장착 중도 허용. 기반·성급·희귀도·고정 특성 보존, 옵션 0개여도 희귀 유지 |
| 추가 | 유효 그룹 균등 선택 후 그 안의 유효 종류 균등 |
| 제거·교체 대상 | 무통제는 기존 옵션 전체에서, 통제는 지정 그룹 안에서 균등 |
| 교체 생성 | 제거한 그룹의 유효 종류 균등, 제거한 종류 재등장 허용·나머지 옵션 보존 |
| 단계·값 | 성급별 허용 3단계 각각 1/3, 단계 내 정수값 균등 |
| 조율 | 모든 현재 옵션의 종류·단계 유지, 각 값 독립 균등 재추첨 |
| 통제·무효 | 좁힐 그룹이 하나뿐이면 집중석 사용 비활성·추가 소모 없음. 무효 실행 비활성·사유 안내·차감 없음 |
| 결과·중단 | 실행 확정과 차감/적용을 함께 처리. 같거나 나빠진 결과도 적용·환급/되돌리기 없음. 실행 전 취소 무료, 확정 뒤 재접속은 같은 결과/차감 복원 |
| 장착 중 제작 | 능력치 재계산, 조건 미달 젬은 연결 유지·사용 비활성, 조건 회복 시 재활성 |

작업별 유효/무효 상태, 무통제 기본 선택과 장비/작업 전환 시 초기화, 같은 작업 통제 유지/조건 변화 처리, 조건부 확률 공개와 중복 적용 방지의 상세 기준도 기능 기획서와 같다. 장비당 횟수 제한 없음·기본 세 작업의 별도 성공/실패 판정 없음과 기존 파밍 공급 비율·던전 소모량은 유지한다.

## 확인 범위와 후속 작업

이번 확인은 첫 제작 재료 이름·비용·추첨·실행과 종료 처리다. 재료 교환·분해 수급·판매/과금 공급, 장비 보관·비교·교체·분해/처분과 투자 회수, 자동/일괄 제작·보호/특수 제작·직접 옵션 지정·장비 요구 능력치·정식 스킬/성장은 후속 확인 사항이다.

숫자는 첫 제작 실험의 초기값이다. 변경은 다시 확인받고, 문서 형식/산술 검사를 실제 제작·저장·전투·경제 검증으로 취급하지 않는다. 이번에 Unity 데이터·게임 코드를 구현하거나 수정하지 않았다. 구현 전 조사·적용 범위·검증 계획은 기능 기획서에서 이어간다.
