# 장비와 스킬 조합 중심의 방치형 액션 RPG

장비·스킬 조합이 핵심인 방치형 액션 RPG로 기획을 시작한다.

## 확인 근거와 범위

사용자가 기획의 출발점을 묻는 질문에서 해당 선택지를 골랐다. 장르와 중심 요소를 정한 결정이다. 구체적인 장비 체계, 스킬 연결 방식, 화면과 성장 규칙은 별도 확인 대상이다.
