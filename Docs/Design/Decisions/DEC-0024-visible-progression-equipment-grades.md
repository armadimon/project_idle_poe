# 제작 잠재력은 진행 구간별 소수의 장비 등급으로 구분

세분화된 숫자 아이템 레벨 대신 진행 구간에 따른 소수의 장비 등급을 사용한다. 성급 같은 직관적인 구분을 장비 자체에 표시하여, 어느 구간의 장비이고 종결 제작에 투자할 출발점인지 게임 안에서 파악할 수 있게 한다.

제작 가능 범위를 가르는 장비 구간도 표시되는 등급과 일치시키는 방향으로 기획한다. 같은 등급 안에 사용자에게 드러나지 않는 세밀한 레벨 경계를 다시 두어 외부 자료를 찾아야 하는 구조를 도입하지 않는다.

## 확인 근거와 범위

사용자는 본인의 PoE 플레이에서 제작 조건을 파악하려고 외부 정보를 찾아야 했던 불편을 설명하고, 진행 구간별로 명확하게 알아볼 수 있는 성급 방식의 대안을 제시했다. 이 경험은 설계 이유로 기록하며 원작의 현재 규칙이나 숫자 범위를 검증한 자료로 취급하지 않는다.

이번 결정은 구분 방식의 방향과 게임 안에서 제작 투자 대상을 알아볼 수 있어야 한다는 요구다. 단계 수는 후속 [DEC-0025](DEC-0025-five-equipment-grades.md)에서 5단계로 확인했다. 각 단계의 역할과 명칭·표기, 획득 구간, 등급별 제작 가능 범위와 옵션 최고 등급의 대응은 미정이다. 장비 등급의 상승·변경 가능 여부, 기존 장비나 투자 재료의 이전 여부도 별도로 확인한다.

앞서 제안한 숫자 아이템 레벨에 따른 옵션 등급 상한은 승인된 사양이 아니다. 이번 방향만으로 그 상한 규칙이나 특정 성급 수, 최고 성급의 결과 보장을 확정하지 않는다. 실제 화면·아이콘·배치와 게임 코드도 이번 결정의 구현 범위에 포함하지 않는다.
