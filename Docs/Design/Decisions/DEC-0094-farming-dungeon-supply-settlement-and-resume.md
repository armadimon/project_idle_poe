# 파밍 수급·정산과 접속 중단 처리

사용자는 아래 **파밍 수급·정산 묶음 전체**에 “오케이 진행해줘”라고 답했다. 수량과 공급 비율을 포함한 초기 규칙으로 기록하고 [기능 기획서](../Systems/Farming-Dungeon-Modification.md)에 통합한다.

## 입장·보상·공급

| 항목 | 확정 규칙 |
| --- | --- |
| 입장 | 해금된 파밍 대상의 최초·반복·재도전 입장 무료, 횟수 제한·대기 시간 없음 |
| 성공 기본 보상 | 희귀 장비 1회·제작재료 2회 독립 추첨, 각 추첨에서 해당 보상 1개 생성 |
| 모딩 보너스 | 각 기본 추첨에 기존 패널티 수 × 20% 확률의 추가 1회 추첨 적용 |
| 실패·직접 포기 | 해당 도전의 기본·추가 보상 모두 지급하지 않음 |
| 정보 | 입장 전에 기본 보상·재료별 공급 확률·모딩 추가 확률과 소모량 표시 |

| 제작재료 종류 | 각 재료 추첨의 공급 확률 |
| --- | --- |
| 옵션 추가 기본 재료 | 30% |
| 옵션 제거 기본 재료 | 15% |
| 옵션 교체 기본 재료 | 35% |
| 수치 재추첨 기본 재료 | 15% |
| 접두·접미 공통 통제 재료 | 5% |

두 기본 재료 추첨은 독립이며 같은 재료가 두 번 나올 수 있다. 모딩 추가 추첨도 같은 범주의 기본 테이블을 쓰고 추가 추첨에 보너스를 다시 적용하지 않는다. 장비의 세부 후보·성급·옵션 분포는 다음 득템·파밍 대상 구성 묶음에서 확인한다.

## 소비·종료·복귀

| 상황 | 확정 처리 |
| --- | --- |
| 최초 부여·한 줄 교체 | 결과 확정 시 해당 재료 1개 차감. 무효 동작은 차감하지 않음 |
| 사용한 재료 | 최초 부여·교체에 이미 사용한 재료는 환급하지 않음 |
| 준비 취소·대상 변경 | 안내·확인 후 설정 초기화, 사용 재료 환급 없음 |
| 준비 중 앱 종료·접속 중단 | 대상·설정과 사용 재료 내역 보관, 복귀 시 준비 재개 |
| 전투 중 앱 종료·접속 중단 | 해당 파밍 도전 일시정지, 복귀 시 같은 상태에서 이어하기 |
| 복귀와 정산 | 재추첨·재소모·보상 중복 없이 같은 도전을 한 번만 정산 |
| 성공·실패 후 | 기존대로 패널티·연결된 보상 강화 설정 초기화 |

접속 중단 자체를 실패·직접 포기로 처리하지 않는다. 닫혀 있는 동안 해당 파밍 전투는 진행하지 않으며 계정 전체의 오프라인 보상 도입·폐지를 결정한 것은 아니다. 보상 미지급은 해당 미완주 도전에 한정하고 기존 인벤토리 보상을 회수하지 않는다.

## 확인 범위와 검증

이번 확인은 파밍의 수급·정산 흐름과 표의 초기 수치다. 대상 해금 조건·장비 성급과 기반 후보·옵션 분포·재료 이름·장비 제작 소모량·자동 반복 입장·계정의 오프라인 성장과 다른 콘텐츠 보상은 별도로 확인한다. 실험 결과로 수치 변경이 필요하면 변경 묶음을 다시 확인받는다.

이번 변경은 문서 반영까지다. 드롭·차감·정산·저장·접속 중단 복원을 구현하지 않았고 난도·진행 속도·경제 균형을 검증한 결과도 아니다. 구현 전에 관련 공식 기술 문서·오픈소스와 현재 저장·실행 환경을 조사하고 구현·검증 계획을 제안한다.

승인된 기능을 구현할 때 공급 비율 합계·분포, 추가 추첨의 독립성·비재귀, 결과 확정과 차감, 성공·실패·직접 포기·준비 취소·대상 변경·중단·복귀를 연결한 정산을 검증한다. 동일 도전의 중복 보상과 재추첨이 없는지 확인하고, 파밍 시간과 제작 비용을 정한 뒤 실제 수급을 비교한다.
