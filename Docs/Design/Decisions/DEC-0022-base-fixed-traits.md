# 장비 기반의 고정 특성은 추가 옵션 6칸과 별도 제공

장비 기반에는 기본 성능 외에 기반 종류마다 정해진 고정 특성을 제공한다. 해당 특성은 접두 최대 3개·접미 최대 3개의 추가 옵션 칸과 별도로 적용한다.

추가 옵션 조합뿐 아니라 기반의 특성과 빌드의 조합도 장비를 고르는 판단에 포함하는 방향이다.

## 확인 근거와 범위

사용자는 기반 고정 특성 있음, 고정 특성 없이 기본 성능과 추가 옵션으로 구성하는 두 대안 중 1번을 선택했다.

이번 결정은 기반 고정 특성의 존재와 추가 옵션 6칸과의 구분에 관한 것이다. 고정 특성의 구체적인 효과·수치·개수, 수치의 변동과 특성 변경 가능 여부는 미정이다. 기반 종류와 추가 옵션 후보군의 관계도 별도로 확인한다.

고정은 기반 종류에 정해진 특성이라는 의미이며 수치의 고정 여부를 결정한 것은 아니다. 고유 장비의 특수 효과와 기반 고정 특성의 구체적인 관계도 후속 기획에서 확인한다.
