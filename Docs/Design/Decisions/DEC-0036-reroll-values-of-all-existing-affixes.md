# 현재 붙은 모든 추가 옵션의 수치를 함께 재추첨

수치 재추첨 한 번에 희귀 장비에 현재 붙어 있는 모든 추가 옵션의 수치를 함께 재추첨한다. 각 옵션의 종류와 등급은 유지하고 해당 등급의 수치 범위에서 다시 추첨한다.

## 확인 근거와 범위

사용자는 붙어 있는 모든 추가 옵션의 수치를 함께 재추첨하는 1안과 한 옵션의 수치만 바꾸는 2안 중 1안을 선택했다. 이번 결정은 수치 재추첨 작업의 대상 범위다. 이미 좋은 수치도 대상에 포함된다.

추가 옵션이 일부만 붙어 있는 장비는 현재 붙은 옵션만 대상이다. 빈 칸에 새 옵션을 추가하거나 옵션을 제거하는 작업은 아니며, 기반 고정 특성과 고유 장비 효과는 이 대상에 포함하지 않는다.

재료·비용과 실행 조건, 추첨 분포·확률과 결과 적용 방식은 미정이다. 기존 수치와 새 수치 중 선택할 수 있는지, 추가 통제·보호 경로를 제공할지도 별도로 확인한다. 현재의 추가·제거·교체에 허용한 접두·접미 통제를 수치 재추첨까지 자동으로 확장하지 않는다.

장비 성급 고정과 옵션 이전 없음, 성급별 허용 옵션 등급 범위와 수치 범위 안의 추첨은 기존 결정을 따른다. 이번 단계에는 게임 코드와 실제 옵션·재료 데이터를 추가하지 않는다.
