# 종결 장비 제작을 핵심 재미로 기획

아이템 제작과 장비 득템의 재미에 무게를 두고, 종결 장비 제작을 게임의 핵심으로 삼는다. 전투는 확인된 완전 자동 방식으로 기획한다.

## 확인 근거와 범위

사용자가 게임의 목표를 설명하면서 종결 장비 제작이 핵심이라고 명시했다. 이 결정은 [빌드 실험을 최우선으로 뒀던 초기 결정](DEC-0004-core-experience.md)의 우선순위를 대체한다.

종결 장비의 의미는 후속 [혼합형 기준 결정](DEC-0010-endgame-definition.md)에서 확인했다. 제작과 완제품 드롭의 비중, 제작 실패 처리, 획득 확률과 완성까지의 시간은 별도로 확인한다. 빌드 실험의 역할도 이 목표에 맞춰 구체화한다.
