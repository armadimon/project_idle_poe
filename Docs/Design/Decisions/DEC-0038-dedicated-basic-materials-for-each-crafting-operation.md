# 네 제작 작업에 각각 전용 기본 재료 배정

추가·제거·교체·수치 재추첨에 각각 한 종류씩 서로 다른 전용 기본 제작 재료를 사용한다. 기본 제작 재료는 4종으로 구성한다.

| 작업 | 전용 기본 재료의 용도 |
| --- | --- |
| 옵션 추가 | 옵션 추가 작업에 사용 |
| 옵션 제거 | 옵션 제거 작업에 사용 |
| 옵션 교체 | 옵션 교체 작업에 사용 |
| 수치 재추첨 | 옵션 종류·등급을 유지하는 수치 재추첨 작업에 사용 |

## 확인 근거와 범위

사용자는 작업별 전용 기본 재료 4종을 두는 1안과 네 작업에 공통 기본 재료 1종을 쓰는 2안 중 1안을 선택했다. 이번 결정은 네 작업의 기본 제작 재료를 작업별로 구분하는 범위다.

접두·접미 통제에 기본 비용 외의 추가 재료를 쓰는 기존 결정은 유지한다. 통제 재료는 기본 재료 4종과 별도다. 후속 [DEC-0039](DEC-0039-shared-material-for-prefix-suffix-control.md)에서 공통 통제 재료 1종을 추가·제거·교체가 공유하는 범위를 확인했다. 이 결정을 수치 재추첨에 대한 접두·접미 통제 도입으로 확장하지 않는다.

표는 재료의 용도를 설명하며 실제 이름을 정한 것이 아니다. 재료 이름, 한 번의 소모량, 공급 경로·양과 희소성, 재료 간 교환·전환과 공통 추가 비용의 도입 여부는 미정이다. 한 작업에 한 종류를 배정했다는 것은 한 번에 한 개를 소모한다는 뜻이 아니다.

기존 작업의 효과와 적용 범위는 유지한다. 수치 재추첨은 현재 붙은 모든 추가 옵션의 종류·등급을 유지하고 수치를 함께 다시 뽑으며 새 결과를 바로 적용한다. 이 단계에는 실제 재료 데이터나 게임 코드를 추가하지 않는다.
