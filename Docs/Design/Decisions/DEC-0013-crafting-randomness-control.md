# 무작위 제작에 제한적인 통제 수단 제공

희귀 장비의 추가 옵션 제작 결과는 기본적으로 무작위로 정한다. 재료나 제작 작업을 통해 추첨 범위를 제한적으로 좁힐 수 있게 한다.

목표 옵션을 향한 선택과 예상 밖의 유효한 결과를 함께 남기고, 중간 결과를 보고 다음 제작을 판단하는 방향이다.

## 확인 근거와 범위

사용자는 무작위와 제한적 통제, 원하는 옵션 종류 직접 지정, 통제 없는 완전 무작위의 세 대안 중 1번을 선택했다.

통제의 기본 단위는 후속 [DEC-0014](DEC-0014-prefix-suffix-control.md)에서 접두·접미 선택으로 확인했다. 어떤 제작 작업과 재료를 제공할지, 각 작업에 통제를 어떻게 적용할지는 미정이다. 특정 옵션을 보장하는 예외, 옵션 보존·손실과 실패 처리, 비용·확률·등급·수치 규칙도 별도로 확인한다.

이번 결정만으로 특정 옵션을 자유롭게 고르는 기능이나 기존 옵션을 보호하는 기능을 도입하지 않는다.
