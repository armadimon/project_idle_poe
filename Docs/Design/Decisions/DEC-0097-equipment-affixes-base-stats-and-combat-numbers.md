# 장비 옵션·기본 성능과 전투 계산의 초기 수치표

사용자는 직전 응답의 핵심 규칙과 링크한 상세 수치표 전체에 “오케이 진행해줘”라고 답했다. 현재 규칙·표는 [장비 옵션·기본 성능과 전투 계산 기획서](../Systems/Equipment-Affixes-and-Combat-Numbers.md)에 통합한다.

| 확정 범위 | 내용 |
| --- | --- |
| 기반 성능·고정 특성 | 성급별 기본 성능 계산과 계열·역할별 고정 특성의 실제 효과·수치 |
| 옵션 목록 | 접두 19종·접미 15종, 총 34종과 11계열의 후보 |
| 단계·범위 | 1→7단계 상승, 9개 범위군의 7단계 정수 1단위 범위와 인접 단계 일부 겹침 |
| 적용·피해 | 무기 자체/캐릭터 적용 구분, 공격/주문과 증가 합산·별도 증폭/감폭 곱셈 |
| 치명타·속도 | 기본 배율 150%, 확률 증가/%p 추가 구분, 공격·시전 동작과 별도 재사용 회복 |
| 능력치 | 명중도 생략, 힘·민첩·지능은 우선 젬 요구 조건에 사용 |
| 방어 | 방어도 A/(A+1000) 최대 75%, 회피 E/(E+1000) 최대 60%, 방패 기본 막기 15%·상한 50%, 원소 저항 0~75% |
| 보호막·회복 | 방어 후 보호막→생명력 차감, 무피해 3초 뒤 초당 최대 보호막 20% 재충전, 생명력 재생과 기존 회복 약화 적용 |

상세 기준은 기능 기획서의 전체 기반 표·고정 특성 표·34종 옵션 표·계열별 후보 표와 7단계 범위 표다. 첫 시험용 초기 수치로 확인했으며 이후 변경도 사용자에게 다시 확인한다.

## 승인 범위와 미정 사항

수치 범위와 단위는 드롭·기본 제작의 공통 데이터지만 제작 작업별 종류·단계·값의 추첨 확률과 비용·실행·취소/종료 처리는 다음 묶음으로 명시했다. 드롭 확률은 기존 승인 규칙을 유지한다.

비교용 캐릭터의 장비 외 생명력 1000·능력치 각 10과 주문 비교 치명타 5%는 계산 사례의 기준이다. 이를 실제 캐릭터 성장·직업·모든 젬의 확정 기본값으로 확대하지 않는다. 개별 스킬·몬스터·성장/맵·운영 수치, 지속피해·혼돈·상태이상·소환 등 후속 빌드 기능은 별도로 확인한다.

이번 변경은 문서 반영이며 Unity 데이터·전투 계산을 구현하거나 수정하지 않았다. 문서 정합성과 산술 확인을 실제 게임 실행·밸런스 검증으로 취급하지 않는다. 구현 전 조사·제안과 실제 검증은 기능 기획서의 계획을 따른다.
