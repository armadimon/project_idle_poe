# 파밍 던전 패널티·보상 콘텐츠

사용자는 아래 **패널티·보상 콘텐츠 묶음 전체**에 “오케이 진행해줘”라고 답했다. 현행 규칙은 [파밍 던전 변화 기획서](../Systems/Farming-Dungeon-Modification.md)에 통합한다.

## 초기 패널티 6종

각 종류는 고정 강도 하나로 시작한다.

| 패널티 | 효과 |
| --- | --- |
| 몬스터 생명력 강화 | 최대 생명력 +30% |
| 몬스터 공격 강화 | 주는 피해 +20% |
| 몬스터 공격 가속 | 공격속도 +15% |
| 플레이어 회복 약화 | 받는 생명력 회복량 ×0.7 |
| 플레이어 치명타 약화 | 치명타 확률 ×0.7 |
| 플레이어 지속 피해 약화 | 주는 지속 피해 ×0.7 |

효과 적용 전 계산값에 해당 배율을 한 번 곱한다. 치명타 확률을 30%p 차감하는 방식이 아니다. 이번 승인은 이 패널티 콘텐츠까지며 정식 스킬·성장·빌드 시스템 전체의 구현 승인은 아니다.

## 추첨·보상·표시

| 항목 | 확정 규칙 |
| --- | --- |
| 최초 종류 추첨 | 6종을 같은 확률로 중복 없이 추첨 |
| 한 줄 교체 | 잠긴 나머지 줄의 종류를 제외한 후보에서 균등 추첨. 방금 제거한 종류도 재등장 가능 |
| 보상 | 장비·제작재료의 기본 드롭 추첨마다 패널티 수 × 20% 확률로 추가 추첨 1회 |
| 개수와 확률 | 0~4줄의 추가 확률은 각각 0%·20%·40%·60%·80% |
| 교체 뒤 보상 | 줄 수가 유지되므로 보상 확률 유지 |
| 정산 | 추가 보상은 클리어 성공 시 지급. 실패하면 그 추가분은 지급하지 않음 |
| 표시 | 준비 화면에 실제 패널티 효과와 추가 드롭 확률을 함께 표시 |

추가 추첨은 같은 범주의 기본 테이블에서 독립적으로 한 번 수행하며 추가 추첨에 보너스를 다시 적용하지 않는다. 현재 6종에서는 종류 중복 외 별도 조합 금지를 두지 않는다. 장비 성급·옵션 등급·희귀도와 후보 가중치는 기본 테이블을 따른다. 이 보너스를 경험치·골드·랭킹 등 다른 보상에 확대하지 않는다.

최초 부여 개수별 확률과 재료 소모, 한 줄 교체·잠금 연동·새 결과 즉시 적용, 성공·실패 후 설정 초기화 등 선행 규칙은 유지한다.

## 확인 범위와 후속 검증

기본 장비·재료 드롭 테이블과 공급량·입장 비용·기본 실패 보상·최초 부여 재료 환급·취소·중단·재접속·대상 전환·재도전 조건은 다음 파밍 수급·정산 묶음에서 확인한다.

이번 변경은 기획 확정과 문서 반영이다. 개인 파밍 모딩의 Unity 기능·화면·확률 구현이나 정식 밸런스 검증 완료로 확대하지 않는다. 구현 승인 후 종류 추첨·중복 방지·같은 결과 재등장·나머지 줄 보존과 추가 추첨의 비재귀·성공 정산을 검증한다. 수급과 정식 빌드를 정한 뒤 완주 성과·재료 순소비·시간당 획득을 비교한다.
