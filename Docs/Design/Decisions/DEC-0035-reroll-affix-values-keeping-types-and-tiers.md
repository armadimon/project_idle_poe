# 추가 옵션 종류와 등급을 유지하는 별도 수치 재추첨 작업 도입

희귀 장비의 추가 옵션 종류·등급을 유지하고 수치만 다시 추첨하는 별도 제작 작업을 제공한다. 해당 옵션 등급의 수치 범위에서 다시 추첨하며, 재추첨한 수치가 현재보다 나빠질 수도 있다.

## 확인 근거와 범위

사용자는 수치 재추첨 작업을 추가하는 1안과 추가하지 않는 2안 중 1안을 선택했다. 이번 결정은 작업의 도입, 옵션 종류·등급 유지와 해당 등급 범위 내 수치 재추첨까지다. 수치 향상을 보장하는 작업으로 채택한 것은 아니다.

대상 옵션의 개수와 선택 방식, 재료의 종류·수량·공급과 비용·실행 조건, 추첨 분포·확률은 미정이다. 기존 수치와 새 수치 중 선택할 수 있는지, 최고 수치 보장이나 보호 재료도 별도로 확인한다.

기존 추가·제거·교체 규칙과 각 작업에 확인한 접두·접미 통제 및 실행 규칙은 유지한다. 기존 세 작업에 관한 통제·실행 결정을 새 수치 재추첨 작업까지 자동으로 확장하지 않는다. 다른 기본 작업의 옵션 보호, 기반 고정 특성이나 고유 장비 효과의 재추첨도 이번 범위에 포함하지 않는다.

성급 고정과 추가 옵션 이전 없음, 성급별 허용 옵션 등급과 등급 안의 여러 수치 추첨은 기존 결정을 따른다. 이번 단계에는 게임 코드나 실제 옵션·재료 데이터를 추가하지 않는다.
