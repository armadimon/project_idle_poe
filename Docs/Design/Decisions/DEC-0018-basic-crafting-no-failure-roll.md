# 기본 제작에는 별도의 성공·실패 판정을 두지 않음

기본 제작의 추가·제거·교체에는 별도의 성공·실패 판정을 두지 않는다. 실행 조건을 만족하고 필요한 재료를 지불하면 해당 작업을 실행한다.

어떤 옵션이 추가되거나 어떤 기존 옵션이 제거되는지는 확인된 무작위 결과와 접두·접미 통제 규칙을 따른다. 제거·교체로 좋은 옵션을 잃거나 원하는 새 옵션을 얻지 못할 수 있다.

## 확인 근거와 범위

사용자는 별도 실패 판정 없음, 실패 시 재료만 소모, 실패 시 추가 손실 가능의 세 대안 중 1번을 선택했다.

이번 결정은 기본 세 작업의 실행에 관한 것이다. 원하는 옵션을 보장하거나 기존 옵션을 보호하는 별도 수단을 승인한 것은 아니다. 잘못된 대상이나 빈자리 부족으로 실행할 수 없는 작업의 처리, 비용과 재료, 추첨 후보·가중치와 등급·수치 규칙은 별도로 확인한다. 후속 특수 제작의 도입 여부와 위험도 미정이다.
