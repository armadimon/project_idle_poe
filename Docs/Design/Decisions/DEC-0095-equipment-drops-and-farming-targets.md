# 장비 득템·파밍 대상 구성

사용자는 아래 기능 묶음 전체에 “응 진행해줘”라고 답했다. 현재 규칙은 [장비 득템·파밍 대상 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)에 통합한다.

| 항목 | 확인된 규칙 |
| --- | --- |
| 구간·해금 | 1~5성 다섯 구간. 1성부터 시작하고 해당 구간 첫 완주 시 다음 구간 해금. 모딩 여부 무관, 이전 구간 선택 유지 |
| 드롭 성급 | 구간과 같은 성급 장비만 드롭 |
| 목표 부위 | 입장 전 하나 선택. 기본·모딩 추가 장비 추첨 모두 같은 부위 |
| 기반 | 선택 부위·구간의 유효 기반 후보에서 균등 추첨 |
| 옵션 개수 | 4개 60%·5개 30%·6개 10% |
| 옵션 종류 | 유효 접두·접미 그룹을 균등 선택하고 그룹 안 유효 종류를 균등 추첨. 기존 상한·중복 금지 유지 |
| 등급·수치 | 성급별 허용 범위의 유효 등급과 정의한 표시 단위·간격에 맞는 유효 수치를 각각 균등 추첨 |
| 공개 정보 | 성급·기반과 옵션 후보·등급·수치 범위·추첨 확률을 게임 안에서 확인 |

제작 출발 장비를 얻는 범위를 부위와 성급으로 명확히 하고, 기반·옵션 조합·등급·수치의 무작위 차이는 유지한다. 기본/추가 보상의 횟수·재료 공급·정산은 DEC-0094와 기존 모딩 규칙을 따른다.

## 승인 범위와 남은 사항

승인은 파밍의 희귀 장비 드롭에 적용한다. 장비 제작 작업의 확률, 고유 장비와 추가 옵션 없는 기반 장비, 다른 보상 경로를 같은 값으로 확정하지 않는다.

실제 장비 부위·슬롯 수·무기·기반과 고정 특성, 개별 옵션 목록·분류·7등급 수치표·표시 단위와 복합 수치 관계, 적 수치·전투 시간·진행 속도·자동 반복 입장·계정 오프라인 보상은 후속 확인 사항이다. 표의 초기 수치 변경도 사용자에게 다시 확인한다.

이번 변경은 기획 문서 반영이며 드롭·해금·정보 화면 구현이나 확률·난도·경제의 실행 검증은 수행하지 않았다. [기능 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)의 계획에 따라 구현 전 조사와 적용 범위를 제안하고 실제 검증을 진행한다.
