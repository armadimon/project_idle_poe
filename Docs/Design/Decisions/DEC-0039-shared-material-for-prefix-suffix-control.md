# 세 작업이 공유하는 접두·접미 통제 재료 1종

추가·제거·교체의 접두·접미 지정에는 공통 통제 재료 한 종류를 사용한다. 세 작업이 같은 통제 재료를 공유하며, 해당 재료로 접두 또는 접미를 선택한다.

작업별 전용 기본 재료 4종과 이 공통 통제 재료 1종은 별도다. 통제한 작업에는 해당 작업의 기본 재료 외에 공통 통제 재료를 추가로 사용한다. 통제 재료 없이 무작위로 진행하는 제작도 유지한다.

## 확인 근거와 범위

사용자는 공통 통제 재료 1종을 쓰는 1안과 작업별 통제 재료 3종을 두는 2안 중 1안을 선택했다. 두 안 모두 해당 재료로 접두 또는 접미를 선택한다고 명시한 질문에 대한 선택이다.

이번 결정은 추가·제거·교체 세 작업의 통제 재료를 공유하는 범위다. 접두 전용과 접미 전용 재료를 나누지 않는다. 선택한 그룹 안의 결과는 무작위이며, 통제한 교체의 제거와 추가는 모두 선택한 그룹 안에서 진행한다.

공통 재료 한 종류라는 것은 작업 한 번에 한 개를 소모하거나 세 작업의 통제 비용이 같다는 뜻이 아니다. 재료의 실제 이름·소모량·공급과 희소성, 교환·전환과 공통 추가 비용의 도입 여부는 미정이다.

수치 재추첨에 접두·접미 통제를 제공할지는 별도 확인한다. 통제 없는 교체에서 제거와 추가의 그룹 관계, 실행 불가 상황의 처리, 개별 옵션·등급·수치의 확률도 이번 결정으로 정하지 않는다. 실제 조작·화면이나 게임 코드를 추가하지 않는다.
