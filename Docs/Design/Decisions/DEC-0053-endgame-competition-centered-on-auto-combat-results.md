# 종결 장비 경쟁은 자동 전투 성과 중심

종결 장비 경쟁은 같은 도전에서 제작한 장비·스킬 조합이 낸 자동 전투 성과를 중심으로 평가한다. 제작한 장비가 실제 전투에서 얼마나 유효한지를 경쟁과 연결한다.

## 확인 근거와 범위

사용자는 1안 자동 전투 성과와 2안 장비 자체의 완성도 점수 중 1안을 선택했다. 구체적인 평가 지표·공식과 보상은 선택 후 별도로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 경쟁의 중심 평가 기준까지다. 주 평가 지표를 최고 도달 단계로 정한 범위는 후속 [DEC-0054](DEC-0054-highest-stage-as-primary-competition-metric.md)에서 확인했다. 지표의 합산 공식이나 장비 자체 점수를 보조 지표로 함께 제공할지는 별도 확인한다.

같은 도전에서 비교하되 구체적인 도전 구성과 평가 조건, 장비·스킬 외 캐릭터 성장 차이를 취급하는 방식, 측정 시간·실패·동률 처리는 미정이다. 특정 보스·던전, 능력치 정규화나 성장 요소의 배제를 자동으로 채택하지 않는다.

순위표 형식과 시즌·초기화·보상, 직접 PvP·매칭과 거래소는 별도 확인한다. 기존 자동 전투·장비 제작·스킬 조합의 승인 범위는 유지한다. 이번 기록에는 실제 평가 수치나 경쟁 시스템 코드를 추가하지 않는다.
