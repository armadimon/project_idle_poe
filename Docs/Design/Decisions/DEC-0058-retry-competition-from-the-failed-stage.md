# 경쟁 재도전은 실패한 단계부터 시작

최고 도달 단계를 비교하는 경쟁에서 실패 후 재도전은 **실패한 단계부터 시작**한다. 이미 돌파한 단계를 처음부터 다시 등반하지 않고 막힌 단계를 다시 시험할 수 있다.

## 확인 근거와 범위

사용자는 1안 실패한 단계부터 재도전, 2안 처음부터 다시 등반 중 1안을 선택했다. 장비·스킬을 바꾼 효과를 바로 시험하고 이미 넘긴 단계의 반복 부담을 줄이는 선택지였다. 재도전 비용·보상·체력 등의 초기화는 별도로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 재도전의 시작 지점까지다. 자동 재도전 여부나 재도전 횟수·비용·대기 시간, 체력·적·스킬 재사용 시간·제한 시간 등의 재설정, 보상과 기록 인정은 별도로 확인한다. 단계 접근 권한과 해금 유지 기간·시즌 초기화도 이번 선택으로 정하지 않는다.

자동 전투 성과 중심과 최고 도달 단계 지표, 각 단계별 제한 시간은 유지한다. 실제 도전 조건의 수치나 경쟁 시스템 코드는 이 기록에 추가하지 않는다.
