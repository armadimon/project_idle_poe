# 완전 자동 전투와 전투 사이의 선택

전투는 완전 자동으로 진행한다. 플레이어는 전투 사이에 장비·스킬·도전 대상을 선택한다.

## 확인 근거와 범위

사용자가 전투 중 직접 하는 일의 범위를 묻는 질문에서 해당 선택지를 골랐다. 자동 전투의 이동·공격·대상 선택 알고리즘, 전투 중 일시정지나 편성 변경 가능 여부, 보스 도전 조건은 아직 결정하지 않았다.
