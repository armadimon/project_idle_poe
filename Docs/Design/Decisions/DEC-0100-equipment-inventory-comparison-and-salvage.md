# 장비 보관·비교·교체·분해

사용자는 직전 요약과 링크한 상세 제안서 전체를 “오케이”로 확인했다. 현행 규칙은 [장비 관리 기획서](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)에 통합한다. 같은 기능·개념의 연결된 규칙을 이 결정 하나에 기록한다.

| 항목 | 확정 규칙 |
| --- | --- |
| 보관 | 무료 미장착 장비 500칸, 장비 1개=1칸. 장착 장비와 제작재료 수량 별도 |
| 선택·비교 | 선택은 비교만 바꾸고 장착은 별도 입력. 장비 상세·전체 가상 교체의 스킬/생존/능력치·젬 조건을 요약/상세로 표시, 미정 데이터는 사유 안내 |
| 장착 | 전투 밖 무료, 첫 희귀 장비는 부위·양손 관계를 검사하고 별도 성급/레벨/능력치 착용 조건 없음 |
| 반지·양손 | 반지 교체 칸 선택·같은 희귀 기반 두 칸 허용. 양손도끼 장착 시 방패 포함 기존 장비 반환, 빈 칸 부족 시 실행 비활성 |
| 젬·제작 복귀 | 교체/제작 뒤 능력치 재평가, 조건 미달 젬은 연결 보존·사용 비활성. 제작 왕복 시 선택/필터/정렬/위치 유지·값 갱신 |
| 분해 보호 | 획득 시 기본 해제. 보호/장착 장비 분해 제외, 보호 장비 장착·제작 허용 |
| 찾기·선택 | 부위/성급/무기 계열/보호/옵션 필터, 최신/성급/옵션 수치 정렬. 전체 선택은 필터 결과 전체의 분해 가능한 희귀만, 필터/정렬 변경 시 선택 초기화 |
| 분해 | 미장착·보호 해제 희귀 장비의 무료 단건/선택 일괄 분해. 고유 제외, 확정 전 대상/개수/보상 규칙·확률 확인 |
| 보상·회수 | 장비당 기존 제작재료 1회 독립 추첨·1개, 부여/제거/교체/조율/집중석 30/15/35/15/5%. 성급·옵션·제작 이력 무관·모딩 보너스 재적용 없음·과거 제작재료 추가 환급 없음 |
| 파밍 공간 | 패널티 없는 입장은 빈 칸 1개, 모딩 추가 장비 가능 시 2개. 부족 시 정리 안내·같은 준비의 대상/모딩/이미 쓴 재료 유지 |
| 취소·중단 | 확정 전 취소 무료·변경 없음. 장착/분해 확정 결과 저장·복원, 장비/재료 중복 및 분해 재추첨 없음·분해 되돌리기 없음 |

전투 중 장착·제작·분해 금지, 종합 장비 점수/자동 장착을 첫 비교에 넣지 않는 범위와 UI 정보 단위·선택/무효 상태·제작 왕복 상세 조건도 기능 기획서를 따른다. 기존 파밍 드롭·모딩 비용/확률·기본 제작 소모량은 바꾸지 않으며 분해 수급을 추가한다.

## 확인 범위와 후속 검증

보관·비교·교체·보호·분해와 수급/복원의 기능 기획 승인이다. 자동 분해·프리셋·판매/거래·고유 분해·젬 보관·보관 확장·직업/무기와 스킬의 후속 호환성은 별도 확인 사항이다. 다음 미승인 묶음은 [보존과 손실·특수 제작의 초기 범위](../Proposals/Crafting-Preservation-and-Special-Scope.md)다.

[조사](../../Research/2026-11-18-equipment-inventory-comparison-and-salvage.md)의 문헌·산술 확인과 실제 Unity 검증을 구분한다. 이번에는 기획 문서만 반영했으며 실제 정식 가방·분해·저장·교체 코드와 경제/사용성을 검증하지 않았다. 구현 전 기술 조사와 적용·검증 계획을 제안한다. 후속 수치 변경도 다시 확인받는다.
