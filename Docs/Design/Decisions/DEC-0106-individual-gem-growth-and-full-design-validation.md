# 젬별 성장 선택과 전체 기획·수치 검증 요청

사용자의 첫 답변 원문은 **“2안으로 가고, 액티브랑 보조젬 좀 더 늘려서 다양성 확보와 빌드 컨셉 여러가지 확보하는게 필요할 것 같네”**다.

직전 선택지의 2안은 **목록 제공 + 액티브별 경험치 성장**, 기존 무료 제공·캐릭터 3×2 연결을 유지하는 방향이었다. 이 방향과 젬 종류/빌드 다양성의 확대 필요를 확인했다. 1안의 전 액티브 공통 구간 성장이나 3안의 장비 소켓/실물 젬을 승인한 것으로 처리하지 않는다.

후속 요청은 **“여기는 아마 기획 길어질거라, poe 원본을 면밀하게 조사해서 확인하고 경량화된 버전에 맞춰서 최대한 다양한 조합이 나오도록 기획 문서 전체 작성하도록해.”**, **“만들어진 기획을 기준으로 정적 분석과 테스트 돌려서 수치적으로 검증도 해보고”**였다.

이에 따라 전체 초안 작성과 오프라인 검증 도구·테스트·분석 실행을 진행한다. 새 개수·성장량·보조 성장 여부·개별 수치·발동·비용·상태이상 등은 작성된 **검토용 초안**에 두고 이 요청만으로 최종 규칙 승인을 기록하지 않는다. Unity 구현 승인을 뜻하지도 않는다.
