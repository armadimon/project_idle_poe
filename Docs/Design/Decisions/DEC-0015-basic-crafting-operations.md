# 기본 제작은 옵션 한 개씩 추가·제거·교체

희귀 장비의 기본 제작은 다음 세 작업을 각각 제공하는 방식으로 구성한다.

| 작업 | 변경 단위 |
| --- | --- |
| 추가 | 빈 자리에 옵션 한 개를 더함 |
| 제거 | 기존 옵션 한 개를 없앰 |
| 교체 | 기존 옵션 한 개를 빼고 새 옵션 한 개를 넣음 |

플레이어가 중간 결과를 보고 다음 제작 작업과 투자를 판단하는 방향이다. 그룹 전체를 한꺼번에 다시 뽑는 작업은 이번 기본 구성에 포함하지 않는다.

## 확인 근거와 범위

사용자는 개별 옵션 추가·제거·교체, 접두·접미 그룹 전체 재추첨, 두 방식 모두 제공의 세 대안 중 1번을 선택했다.

접두·접미 통제를 세 작업 중 어디에 적용할지와 작업별 대상 선정·실행 조건은 미정이다. 비용과 확률, 기존 옵션의 보존·손실과 실패 처리도 별도로 확인한다.

옵션 수치만 다시 뽑거나 옵션 등급을 올리는 별도 작업, 희귀도 승급과 제작 재료의 종류는 이번 결정에 포함하지 않는다.
