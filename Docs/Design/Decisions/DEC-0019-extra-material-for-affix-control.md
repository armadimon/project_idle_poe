# 접두·접미 지정에는 추가 재료 사용

접두 또는 접미를 지정하는 통제를 사용하려면 기본 제작 비용 외에 추가 재료를 사용한다. 추가 통제 재료를 쓰지 않고 무작위로 진행하는 제작도 제공한다.

플레이어가 현재 장비의 옵션과 남은 자리를 보고 재료를 아낄지, 추첨 범위를 좁히는 데 추가 투자할지 판단하는 방향이다. 통제한 작업의 개별 결과는 계속 무작위이며, 기본 작업에는 별도의 성공·실패 판정을 두지 않는다.

## 확인 근거와 범위

사용자는 그룹 지정에 추가 재료 사용, 기본 제작 비용으로 그룹 지정의 두 대안 중 1번을 선택했다.

이번 결정은 추가 통제 재료의 유무와 통제를 쓰지 않는 제작의 제공에 관한 것이다. 기본 재료의 작업별 구분은 후속 [DEC-0038](DEC-0038-dedicated-basic-materials-for-each-crafting-operation.md)에서 확인했다. 공통 통제 재료 1종을 세 작업이 공유하는 범위는 후속 [DEC-0039](DEC-0039-shared-material-for-prefix-suffix-control.md)에서 확인했다. 기본·통제 재료의 이름·소모량·공급, 작업별 무통제 제작의 세부 범위와 추첨 규칙은 미정이다. 통제 없는 교체도 제거한 옵션의 그룹을 유지하는 규칙은 후속 [DEC-0040](DEC-0040-keep-affix-group-in-uncontrolled-replacement.md)에서 확인했다.
