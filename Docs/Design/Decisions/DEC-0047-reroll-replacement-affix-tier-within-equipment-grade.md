# 교체할 새 옵션 등급은 성급 허용 범위에서 재추첨

교체할 새 추가 옵션의 성능 등급은 해당 장비 성급의 허용 범위에서 다시 추첨한다. 제거한 옵션의 등급을 유지하지 않으며 기존보다 높은 등급이나 낮은 등급이 나올 수 있다. 같은 등급이 다시 나올 가능성도 제외하지 않는다.

통제한 교체와 통제 재료를 쓰지 않는 교체에 공통으로 적용한다. 방금 제거한 옵션 종류가 다시 나와도 등급은 이 규칙에 따라 다시 추첨한다.

## 확인 근거와 범위

사용자는 1안 장비 성급의 허용 범위에서 새로 추첨과 2안 제거한 옵션의 등급 유지 중 1안을 선택했다. 통제 여부와 같은 옵션 종류의 재등장 여부에 관계없이 적용한다고 명시한 질문에 대한 선택이다.

이번 결정은 교체 작업에서 새 추가 옵션의 성능 등급을 정하는 원칙이다. 장비의 성급은 고정하며, 성급별 허용 옵션 등급의 기존 범위를 따른다. 같은 성급 안의 숨은 세밀한 아이템 레벨 조건을 추가하지 않는다.

추첨 가능한 등급이 같은 확률로 나오는지와 개별 확률·가중치, 새 옵션 수치의 상세 추첨, 특정 옵션에 해당 등급이 없거나 유효 후보가 부족한 상황의 처리는 미정이다. 해당 성급의 허용 범위 밖 등급이나 성능 향상을 보장하는 규칙을 채택하지 않는다.

접두·접미 그룹 유지, 동일 종류의 동시 중복 제한과 제거한 종류의 재등장 허용은 유지한다. 추가·드롭 등 다른 경로의 등급 분포와 개별 옵션의 등급 적용 범위·예외는 별도 확인한다.

옵션 종류·등급을 유지하는 별도 수치 재추첨 작업은 기존 결정을 따른다. 이번 기록에는 실제 확률·수치 데이터나 게임 코드를 추가하지 않는다.
