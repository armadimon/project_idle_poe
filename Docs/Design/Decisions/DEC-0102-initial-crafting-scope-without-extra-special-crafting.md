# 기본 제작부터 검증하는 첫 제작 범위 A안

사용자는 직전 응답의 첫 선택지 A안을 “1번으로 가자”로 확인했다. 요약과 링크한 A 전체 조건을 한 묶음으로 기록하며 현행 규칙은 [기본 제작 기획서](../Systems/Equipment-Crafting.md)의 ‘첫 제작 검증 범위’에 통합한다.

| 항목 | 확정 규칙 |
| --- | --- |
| 첫 제작 구성 | 추가·제거·교체·전체 수치 재추첨과 접두/접미 통제까지. 재료는 기존 부여석·제거석·교체석·조율석·집중석 5종 |
| 특정 옵션 보호 | 개별 줄 잠금·영구 고정·접두/접미 전체 보존·특정 옵션 확정 부여는 첫 범위에서 제외 |
| 결과 복구 | 제작 결과 선택·되돌리기·보험·투자 재료 환급 없이 기존 즉시 적용 규칙 유지 |
| 아이템 자체 위험 | 파괴·성급 하락·영구 제작 불가·타락과 같은 추가 위험 제작은 도입하지 않음 |
| 수치·자리 상한 | 기존 성급별 허용 3단계와 7단계 수치 범위·접두 3+접미 3 유지. 초과 수치·일곱 번째 옵션·기반/고정 특성 변경을 주는 별도 제작 없음 |
| 종결 이후 | ‘완성 확정’ 비용·봉인·강제 제작 종료 상태를 두지 않으며 사용자가 멈추거나 계속 제작 가능. 별도 완성 보너스 없음 |
| 보호 표시 | 승인된 ‘분해 보호’는 분해만 차단하며 제거·교체·조율로부터 옵션을 보호하지 않음. 집중석도 그룹 내 특정 줄을 보호하지 않음 |
| 변경 판단 | 목표 빌드와 파밍 시간을 정한 뒤 기본 제작의 완성 비용·중간 결과 손실·최악에 가까운 연속 시도를 평가하고 특수 제작 필요성 재검토 |

분해 보호한 장비도 교체로 좋은 옵션을 잃거나 조율로 값이 낮아질 수 있다. 접미 지정 교체에서 접두가 보존되는 것은 해당 실행의 범위이며 접두의 영구 고정 상태를 만들지 않는다. 장비 자체의 파괴와 추가 옵션을 잃는 위험을 구분한다.

## 승인 범위·후속 검토

첫 제작 모델의 범위 승인이다. 추가 특수 제작을 향후 모든 버전에서 영구 배제하거나 기존 제작의 재미·수급·종결 비용이 검증됐다고 해석하지 않는다. 추가 보호/되돌릴 수 없는 강화의 세부 수치·새 재료, 자동/일괄 제작·교환/판매/과금·고유 제작·젬 성장·직업/패시브는 이번에 확정하지 않는다.

추가할 필요가 생기면 조건·비용·확률·종료 처리와 기존 조율·중복·그룹·단계/수급의 변경을 기능 단위로 제안해 다시 확인받는다. 다음 미승인 묶음은 [고유 장비의 역할·획득·착용·처분](../Proposals/Unique-Equipment-Role-Acquisition-and-Handling.md)이다.

[조사](../../Research/2026-11-18-crafting-preservation-and-special-scope.md)의 문헌과 실제 실행을 구분한다. 이번에는 기획 문서만 반영했으며 제작 시뮬레이터·Unity 전투/저장·경제 실험을 실행하지 않았다. 구현 전 기술 조사와 적용 범위·검증 계획을 제안한다.
