# 추가 옵션은 접두 최대 3개와 접미 최대 3개

기본 제작 장비의 추가 옵션은 접두 최대 3개와 접미 최대 3개, 합계 최대 6개를 기준으로 기획한다. 접두와 접미는 서로 다른 옵션 그룹이다.

## 확인 근거와 범위

사용자는 접두 3개·접미 3개, 접두 2개·접미 2개, 구분 없이 6개를 비교한 질문에서 1번을 선택했다.

어떤 옵션이 각 그룹에 속하는지, 같은 계열 옵션의 중복 여부, 옵션 등급과 수치, 추첨 확률은 별도로 확인한다. 추가 옵션 제작 대상과 고유 장비의 역할은 후속 [DEC-0012](DEC-0012-crafting-equipment-scope.md)에서 확인했다. 기반 고정 특성의 존재와 추가 옵션 6칸과의 구분은 후속 [DEC-0022](DEC-0022-base-fixed-traits.md)에서 확인했다. 제작 출발점의 아이템 등급과 소켓 효과의 취급은 미정이다.
