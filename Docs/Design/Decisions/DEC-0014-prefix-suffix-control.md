# 추첨 범위의 통제는 접두·접미 선택으로 구성

제작의 추첨 범위를 좁히는 통제 수단은 접두 또는 접미를 대상으로 선택하는 방식으로 구성한다. 선택한 그룹 안의 개별 결과는 무작위다.

공격·방어 등 옵션 계열을 고르는 통제 수단은 이번 구성에 포함하지 않는다.

## 확인 근거와 범위

사용자는 접두·접미 선택, 옵션 계열 선택, 두 종류 모두 제공의 세 대안 중 1번을 선택했다.

접두를 선택하는 것은 원하는 접두 옵션 하나를 정확히 지정한다는 뜻이 아니다. 제공할 제작 작업의 종류, 각 작업에 통제를 적용하는 방법과 비용, 통제 없이 실행할 수 있는 작업의 범위는 별도로 확인한다.

기존 옵션의 보존·손실, 실패 처리와 추첨 확률, 옵션 등급·수치 규칙도 미정이다. 이번 결정은 특정 제작 작업이나 옵션 보호 기능을 추가하는 승인이 아니다.
