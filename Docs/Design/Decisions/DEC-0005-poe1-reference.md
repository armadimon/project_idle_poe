# 장비와 스킬은 PoE 1의 방식을 기준으로 기획

장비와 스킬은 Path of Exile 1의 방식을 기준으로 기획한다. PoEDB와 커뮤니티 기록을 통해 빌드의 상호작용과 공략의 축적 과정을 조사한 뒤 세부 기획을 진행한다.

이후 사용자가 지정한 [아이템 제작의 PoE 2 기준](DEC-0009-poe2-crafting-reference.md)을 함께 적용한다. 장비·스킬의 작동 구조와 아이템 제작 작업의 참조 기준을 구분한다.

## 확인 근거와 범위

사용자는 장비·스킬에 PoE 방식을 따르겠다고 지시했고, 기준을 묻는 질문에 PoE 1을 선택했다. 이 결정은 장비·스킬 기획의 참조 체계를 정한다.

특정 패치 전체의 복제, 아이템·젬·패시브 수량, 슬롯과 링크 수, 색상 규칙, 제작·거래·확률·수치, 캐릭터 구성과 개별 빌드의 채택은 별도로 확인한다. 원본의 명칭·아트·문구·데이터를 게임 자산으로 옮기는 결정도 포함하지 않는다.
