# 성급마다 세 옵션 등급을 허용하고 범위를 한 단계씩 상승

성급별 허용 옵션 등급 범위는 다음과 같다. 숫자는 성능이 낮은 쪽부터 높은 쪽까지의 비교용 순서이며, 실제 등급 명칭이나 표기 방향을 확정한 것은 아니다.

| 장비 성급 | 허용 옵션 등급 |
| --- | --- |
| 1성 | 1~3 |
| 2성 | 2~4 |
| 3성 | 3~5 |
| 4성 | 4~6 |
| 5성 | 5~7 |

## 확인 근거와 범위

사용자는 성급마다 세 옵션 등급을 허용하는 1안과 5성만 상위 두 등급으로 제한하는 2안 중 1안을 선택했다. 표 전체의 성급별 허용 범위와 범위의 겹침을 확인한 결정이다.

성급이 오르면 허용 옵션 등급의 하한과 상한이 함께 오른다. 기본 범위상 최상위 성능 등급은 5성에서 허용하며, 5성의 최상위 등급을 드롭과 제작 모두 허용하는 기존 결정을 따른다. 같은 성급 안에 숨은 숫자 아이템 레벨 경계를 다시 두지 않는다.

각 등급이 같은 확률로 나오거나 최고 수치를 보장한다는 뜻은 아니다. 등급 안의 범위에서 여러 수치를 추첨하는 원칙은 후속 [DEC-0033](DEC-0033-random-values-within-affix-tier-ranges.md)에서 확인했다. 실제 수치 범위·값의 간격·분포, 추첨 확률·비용·완성 시간은 별도 확인한다. 1~4성의 경로별 제한과 개별 옵션의 적용 범위·예외, 실제 명칭·표기도 미정이다. 모든 옵션 종류에 일곱 등급의 실제 데이터를 일괄 적용한 것은 아니다.

장비의 성급 고정과 옵션 이전 없음, 추가 옵션 최대 개수와 기본 제작 작업에 관한 기존 결정은 유지한다. 이번 단계에는 실제 옵션 데이터나 게임 구현을 추가하지 않는다.
