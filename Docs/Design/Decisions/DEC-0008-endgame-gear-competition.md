# 종결 장비를 통해 경쟁하는 게임

종결 장비를 통해 다른 플레이어와 경쟁하는 형태로 기획한다.

## 확인 근거와 범위

사용자가 종결 장비로 경쟁하겠다고 지정했다. 자동 전투 성과를 중심으로 평가하는 범위는 후속 [DEC-0053](DEC-0053-endgame-competition-centered-on-auto-combat-results.md)에서 확인했다. 구체적인 평가 지표·조건·공식·보상과 순위표·시즌·직접 PvP·매칭·거래 규칙은 아직 결정하지 않았다.
