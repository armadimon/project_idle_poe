# 종결 장비를 통해 경쟁하는 게임

종결 장비를 통해 다른 플레이어와 경쟁하는 형태로 기획한다.

## 확인 근거와 범위

사용자가 종결 장비로 경쟁하겠다고 지정했다. 경쟁을 직접 PvP, 자동 전투 기록, 장비 평가, 순위표, 거래 중 어떤 방식으로 표현할지와 시즌·보상·매칭 규칙은 아직 결정하지 않았다.
