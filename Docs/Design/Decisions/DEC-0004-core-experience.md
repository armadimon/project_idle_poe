# 핵심 재미의 우선순위는 빌드 실험

이 결정의 최우선 순위는 이후 사용자가 지정한 [종결 장비 제작 중심](DEC-0007-endgame-crafting.md)으로 대체됐다. 아래에는 당시 확인 내용을 남긴다. 빌드 실험의 구체적인 비중과 역할은 제작 중심 기획에서 다시 확인한다.

장비·스킬 조합 중심의 방치형 액션 RPG에서 빌드 실험을 핵심 재미의 최우선에 둔다.

## 확인 근거와 범위

사용자가 빌드 실험, 장비 파밍, 보스 공략 중 가장 무게를 둘 요소를 묻는 질문에 빌드 실험을 선택했다. 이후 기획 대안은 빌드를 바꾸고 비교하며 조합을 탐색하는 경험에 얼마나 기여하는지 검토한다.

캐릭터 한 명과 파티 중 빌드의 기본 단위, 장비·스킬의 조합 규칙, 변경 비용, 결과 비교 방법과 플레이 흐름은 별도로 확인한다. 장비 파밍과 보스 공략의 구체적인 역할도 아직 결정하지 않았다.
