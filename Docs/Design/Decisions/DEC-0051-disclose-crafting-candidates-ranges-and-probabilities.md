# 제작 후보·등급·수치 범위와 확률의 게임 내 공개

제작에서 가능한 옵션 후보·허용 옵션 등급·수치 범위와 옵션 종류별·등급별 추첨 확률을 게임 안에서 공개한다. 현재 장비와 선택한 작업·통제 조건에 실제로 적용되는 정보를 기준으로 한다.

## 확인 근거와 범위

사용자는 1안 후보·등급·수치 범위와 옵션별·등급별 확률까지 공개와 2안 후보·등급·수치 범위만 공개 중 1안을 선택했다. 실제 확률 수치와 화면 구성은 별도로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 제작 결과 정보의 공개 범위다. 실제 확률 수치·분포·가중치나 균등 추첨을 채택한 것이 아니다. 각 작업의 기존 효과와 추첨 규칙, 재료·비용의 승인 범위는 유지한다.

수치 범위 안의 개별 값별 확률 공개, 여러 추첨 단계가 연결된 복합 결과와 조건부 확률의 표시, 기대 비용 계산 기능은 별도 확인한다. 수치 재추첨처럼 종류·등급을 유지하는 작업에는 실제로 변하는 정보에 맞춰 구체적인 적용 범위를 정한다.

구체적인 정보 배치·화면·조작·시안은 이번 승인 범위에 포함하지 않는다. 아직 정하지 않은 후보와 확률을 임의로 실제 게임 정보처럼 채우지 않는다. 실제 확률 데이터나 게임 코드는 이 기록에 추가하지 않는다.
