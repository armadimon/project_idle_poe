# 경쟁 재도전 입장 자체의 별도 비용 없음

최고 도달 단계를 비교하는 경쟁에서 실패한 단계에 재도전할 때 **입장 자체에는 별도 재료·재화를 소모하지 않는다.**

## 확인 근거와 범위

사용자는 1안 무료, 2안 입장 재료·재화 소모 중 1안을 선택했다. 재도전 횟수와 체력 등의 초기화는 별도 확인한다고 명시한 질문에 대한 선택이다.

같은 답변에서 사용자가 요청한 던전 변화 시스템의 도입 방향은 [DEC-0060](DEC-0060-currency-funded-dungeon-penalties-and-better-rewards.md)에 따로 기록한다. 재도전 입장 비용과 던전 변화에 쓰는 재화는 서로 다른 결정이다.

이번 결정은 재도전 입장 자체의 비용 유무까지다. 횟수·대기 시간·자동 반복 여부, 최초 입장 조건, 소모품·부활 비용, 체력·적·스킬 재사용 시간·제한 시간의 재설정과 보상·기록 인정은 별도 확인한다. 던전 변화의 적용 대상은 후속 [DEC-0061](DEC-0061-dungeon-modification-for-farming-only.md)에서 파밍에만 적용하는 것으로 확인했다. 파밍의 입장·재시도 조건과 변화의 지속 범위·재화 재소모·환급 여부는 이 경쟁 재도전 결정으로 정하지 않는다.
