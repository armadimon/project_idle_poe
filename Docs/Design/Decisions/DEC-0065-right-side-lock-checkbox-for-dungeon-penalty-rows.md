# 패널티 줄 우측의 잠금 체크박스 토글

파밍 던전의 **각 패널티 줄 우측에 잠금 버튼을 체크박스 토글로 배치**한다. 체크한 줄은 보존할 패널티를 표시한다.

## 확인 근거와 범위

사용자는 한 개를 지정해 무작위 교체하는 2안을 선택하면서 “간단하게 페널티 줄 우측에 잠금 버튼 체크박스 토글로 하면 단순할듯”이라고 제안했다. 이번 확인은 조작 요소의 형태·위치와 보존을 나타내는 잠금의 의미까지다.

[DEC-0064](DEC-0064-reroll-one-selected-dungeon-penalty.md)의 한 개 교체·나머지 보존 범위를 유지한다. 잠금 해제할 수 있는 줄 수와 교체 대상 선택의 연동 방식은 후속 확인한다. 잠금 해제한 모든 줄이 함께 교체되는 동작을 자동으로 채택하지 않는다.

기본 체크 상태·전체 잠금 시 처리·잠금 유지 기간·잠금에 따른 비용 변화·조작 중 상태와 새 결과 적용은 미정이다. 화면 전체 구성, 토글 크기·터치 영역·색·아이콘·연출은 아직 승인받지 않았다.

이번 기록은 UI 조작 기획이다. 화면 시안·리소스 제작·엔진 구현·입력 및 가독성 검증을 수행한 기록으로 취급하지 않는다.
