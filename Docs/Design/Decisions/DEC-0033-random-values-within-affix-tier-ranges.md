# 같은 옵션 등급 안에서도 최솟값과 최댓값 범위의 여러 수치를 추첨

같은 옵션 등급 안에서도 최솟값~최댓값 범위의 여러 수치를 추첨한다. 같은 성급과 옵션 등급을 얻은 뒤에도 수치 완성을 추구할 여지를 둔다.

## 확인 근거와 범위

사용자는 범위 안의 여러 수치를 추첨하는 1안과, 낮음·중간·최대의 세 수치만 추첨하는 2안 중 1안을 선택했다. 이번 결정은 옵션 등급 안에서 수치를 추첨하는 방식의 원칙이다.

실제 최솟값·최댓값과 값의 간격·단위, 정수·소수 처리와 추첨 분포·확률은 미정이다. 가능한 모든 실수 값을 연속적으로 추첨하거나 각 값을 같은 확률로 추첨한다고 정하지 않는다. 인접 옵션 등급 간 수치 범위의 겹침과 개별 옵션의 적용 범위·예외도 별도로 확인한다.

수치만 다시 뽑는 별도 제작 작업, 기존 옵션의 보호, 최고 수치 보장이나 보호 재료는 이번 결정에 포함하지 않는다. 장비의 성급과 옵션 등급 수, 성급별 허용 등급 범위와 기존 추가·제거·교체 작업의 결정은 유지한다. 실제 옵션 데이터나 게임 코드는 이번 단계에 추가하지 않는다.
