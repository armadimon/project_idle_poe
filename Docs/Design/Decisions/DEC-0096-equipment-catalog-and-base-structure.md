# 장비 편성·기반 구조

사용자는 아래 묶음 전체에 “오케이 진행해줘”라고 답했다. 현행 규칙을 [장비 편성·기반 구조 기획서](../Systems/Equipment-Catalog-and-Base-Structure.md)에 통합한다.

| 항목 | 확정 내용 |
| --- | --- |
| 장비 칸 | 주무기·보조 장비·머리·갑옷·장갑·장화·허리띠·목걸이·반지 2개, 총 10칸 |
| 첫 무기 계열 | 한손검·양손도끼·마법봉 3종 |
| 장착 조합 | 한손검·마법봉은 방패 사용 가능. 양손도끼는 보조 장비와 동시 사용 불가 |
| 무기 기반 | 계열마다 피해형·속도형·치명형 3종. 마법봉은 주문 피해·시전 속도 기준 |
| 방어구 기반 | 머리·갑옷·장갑·장화·방패마다 방어도형·회피형·보호막형 |
| 장신구 기반 | 목걸이 힘·민첩·지능, 반지 화염·냉기·번개 저항, 허리띠 생명력·방어도·보호막 각 3종 |
| 고정 특성 | 기반당 1개. 같은 기반·성급에서 수치 고정, 기본 제작 4종으로 변경하지 않음 |
| 성급 | 모든 기반 역할을 1~5성에 제공. 성급은 잠재력, 기반은 빌드 역할 |
| 후보 공유 | 같은 무기 계열·방어구 부위·장신구 종류끼리 공유. 반지 두 칸도 같은 후보 |
| 파밍 연결 | 무기 부위 선택 시 기반 9종을 균등 추첨. 기존 기본·추가 보상 부위 선택 규칙 유지 |

## 승인 범위

이번 승인은 첫 장비 칸·분류·기반 역할·특성 개수와 고정 방식·계열별 후보 공유다. 실제 기반 성능·특성 수치와 접두/접미 옵션의 7등급 수치표는 다음 묶음이라고 명시했다.

개별 옵션 목록·수치·전투 계산, 장비 요구 능력치와 무기별 스킬 호환성, 장비 교체 시 처리·정식 젬 슬롯·성장, 다른 장비 계열·획득 경로는 별도로 확인한다. 공개 제안 문서의 후속 논의나 예시를 이번 승인 범위 밖의 확정 규칙으로 확대하지 않는다.

이번 변경은 기획 문서 반영이다. 정식 장비 데이터·장착·전투를 구현하지 않았고 실제 확률·난도·경제 검증도 수행하지 않았다. [기능 기획서](../Systems/Equipment-Catalog-and-Base-Structure.md)의 조사·검증 계획을 따른다.
