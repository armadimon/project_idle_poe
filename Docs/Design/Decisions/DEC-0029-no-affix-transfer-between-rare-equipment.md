# 희귀 장비의 추가 옵션은 다른 장비로 이전하지 않음

희귀 장비의 추가 옵션은 다른 장비로 이전하지 않는다. 새 장비에 이미 붙은 옵션을 보고 제작을 시작하고, 확인된 추가·제거·교체 작업으로 다듬는다.

## 확인 근거와 범위

사용자는 기존 옵션을 다른 장비로 옮기는 경로를 제공하는 안과 비교해 1안인 옵션 이전 없음을 선택했다. 이번 결정은 희귀 장비의 추가 옵션 자체를 다른 장비로 옮기는 기능의 부재다. 이동·복사·추출 등을 통해 기존 옵션을 다른 장비에 그대로 적용하는 경로를 두지 않는다.

이 결정은 같은 장비 안에서 진행하는 추가·제거·교체의 범위나 기존 옵션 보호 여부를 바꾸지 않는다. 성급을 획득 시 고정하는 기존 결정도 유지한다.

분해 보상, 제작 재료 회수와 투자 비용 환급 여부는 미정이다. 이전 경로가 없다는 이유로 기존 장비가 자동으로 소멸하거나 제작 재료를 모두 잃는다고 정하지 않는다. 고유 장비의 성장 규칙과 기반 고정 특성의 변경도 별도 확인한다.
