# 라이트한 PoE를 목표로 기획

게임의 목표 방향성은 라이트한 PoE다. 사용자가 직접 이 방향을 지정했다.

## 적용 범위

이미 확인한 모바일 우선과 완전 자동 전투를 유지한다. 라이트함을 재료 종류, 절차, 정보량, 실패 부담 중 어디에서 구현할지는 별도로 확인한다.

토치라이트 인피니트는 사용자가 유사 방향의 사례로 언급했다. 해당 게임의 구체 시스템을 채택한 결정은 아니다.
