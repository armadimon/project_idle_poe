# 통제 없는 교체도 제거한 옵션의 그룹 유지

공통 통제 재료를 쓰지 않는 옵션 교체에서도 제거한 옵션의 접두·접미 그룹을 유지한다. 접두를 제거하면 같은 그룹의 새 접두, 접미를 제거하면 새 접미를 추첨한다.

제거할 기존 옵션과 새로 붙을 개별 옵션은 무작위다. 정상적으로 교체가 완료되면 접두·접미의 개수가 각각 유지된다. 각 그룹 최대 3개와 전체 최대 6개인 기존 상한을 따른다.

## 확인 근거와 범위

사용자는 1안 제거한 옵션의 그룹 유지와 2안 그룹 변경 허용 중 1안을 선택했다. 두 안 모두 제거할 기존 옵션과 새로 붙을 개별 옵션이 무작위라고 명시한 질문에 대한 선택이다.

이번 결정은 통제 없는 교체에서 제거와 추가가 같은 접두·접미 그룹에 속한다는 범위다. 예를 들어 접두 2개·접미 1개인 장비에서 접두를 제거하면 새 접두를 추가해 접두 2개·접미 1개의 구성을 유지한다. 예시의 개수는 드롭 배치나 최소 옵션 개수를 새로 정한 것이 아니다.

통제 재료를 사용할 때는 기존 결정대로 접두 또는 접미를 선택하고 해당 그룹 안에서 제거와 추가를 진행한다. 작업별 기본 재료 4종과 공통 통제 재료 1종의 구성은 유지한다.

그룹 유지와 옵션 종류·등급·수치의 보존은 별개다. 이번 선택은 원하는 개별 옵션을 지정하거나 옵션 성능을 보장하는 결정이 아니다. 동일 종류의 추가 옵션을 희귀 장비당 1개로 제한하는 범위는 후속 [DEC-0041](DEC-0041-one-affix-of-each-kind-per-rare-equipment.md)에서 확인했다. 제거한 옵션의 재등장, 개별 추첨 가중치와 등급·수치 분포, 소모량·공급과 실행 불가 상황의 처리는 미정이다.

실제 옵션·재료 데이터나 게임 코드는 추가하지 않는다.
