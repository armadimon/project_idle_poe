# 고유 장비 공통 규칙과 복수 착용 2안

사용자는 직전 요약과 상세 제안의 **2안(B), 부위가 맞는 여러 고유의 동시 착용**을 “2안으로 가자”로 확인했다. 고유 총수 1개 제한을 채택하지 않고 나머지 공통 조건을 유지한다. 현행 규칙은 [고유 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합한다.

| 항목 | 확정 규칙 |
| --- | --- |
| 역할 | 전투 규칙·스킬 활용을 바꾸는 선택형 장비. 고유 획득을 입장·성급 해금의 필수 조건으로 두지 않음 |
| 첫 목록 | 목걸이·반지·허리띠에 각각 1종, 총 3종. 각 고유를 4성·5성으로 제공 |
| 옵션 구조 | 고유별 정해진 기반 성능과 일반 옵션 2개+특수 효과 1개. 같은 고유·성급의 모든 값 고정, 무작위 접두/접미 추첨 없음 |
| 성급·제작 | 획득 성급 고정·승급/옵션 이전 없음. 5성은 일반 성능을 높이고 특수 효과의 규칙·수치는 4성과 동일. 기본 4종 제작과 집중석 사용 불가 |
| 장착 | 부위 관계가 맞는 여러 고유를 함께 착용, 고유 총수 1개 제한 없음. 전투 밖 무료 장착·해제, 별도 성급/레벨/능력치 착용 제한 없음. 동일 고유 중복/중첩은 후속 확인 |
| 획득 | 4~5성의 목걸이·반지·허리띠 파밍 장비 보상 1개마다 희귀 97%·해당 부위 고유 3%. 기본·모딩 추가 장비 추첨에 동일 적용 |
| 보상 개수 | 희귀 보상의 일부를 고유로 대체. 별도 추가 장비 지급 없음·기존 최대 장비 2개와 입장 공간 1/2칸 유지 |
| 추첨·정보 | 추첨별 독립, 중복 획득 허용·천장 없음. 대상/성급·97/3%·특수 효과와 고정값을 게임 안에 공개 |
| 보관·보호 | 기존 무료 500칸 안에서 1개=1칸. 획득 시 분해 보호 기본 해제, 장착/보호 장비는 분해 금지 |
| 분해 | 미장착·보호 해제된 고유는 무료 단건 분해만. 기존 제작재료 1회 추첨·1개, 30/15/35/15/5%. 일괄 분해·전체 선택에서는 고유 제외 |

서로 다른 고유를 함께 사용할 수 있다는 결정이다. 동일한 고유 반지 두 개를 쓰는지와 동일 효과의 중복/중첩·무효 우선순위를 임의로 확정하지 않는다. 개별 이름·성능·특수 효과/수치와 함께 [다음 미승인 묶음](../Proposals/Unique-Equipment-Effects-and-Build-Cases.md)에서 확인한다.

## 선행 규칙과 후속 범위

DEC-0095의 희귀 드롭은 4/5성의 대상 3부위에 한해 희귀 97%·고유 3% 판정을 먼저 적용하도록 갱신한다. 희귀가 선택된 뒤의 기반·옵션 조건부 분포, 장비 보상 최대 2개와 입장 공간 1/2칸, 재료 기본/모딩 공급·비용과 실패/중단 정산은 유지한다.

DEC-0100의 고유 분해 제외는 단건 분해를 허용하도록 갱신하고 일괄/전체 선택에서는 계속 제외한다. 분해 보호·장착 제외·확인 전 취소·삭제/보상 동시 처리·1회 복원과 기존 5종 확률을 따른다.

고유 목록 확장·다른 획득 경로·교환/거래·오프라인 지급·자동 분해·후속 고유 강화·정식 스킬/성장과 패시브는 이번 공통 승인으로 확정하지 않는다. [첫 제작 모델](../Systems/Equipment-Crafting.md)에 고유 제작을 추가하지 않는다.

[조사](../../Research/2026-11-19-unique-equipment-role-acquisition-and-handling.md)의 문헌·산술 확인과 실제 실행을 구분한다. 이번은 기획 문서 반영이며 Unity 고유 데이터/드롭/장착/분해/저장·PoB 실행·경제/사용성 검증을 수행하지 않았다. 개별 효과/수치 확인 후 구현 전 기술 조사·적용·검증 계획을 제안한다.
