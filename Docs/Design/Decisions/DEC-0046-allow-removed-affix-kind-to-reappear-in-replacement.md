# 교체에서 제거한 옵션 종류의 재등장 허용

교체에서 방금 제거한 추가 옵션 종류도 새 옵션의 추첨 후보에 포함한다. 통제한 교체와 통제 재료를 쓰지 않는 교체 모두에서 재등장을 허용한다. 재료를 써도 새 옵션의 종류가 제거한 옵션과 같을 수 있다.

새 옵션은 기존 결정대로 제거한 옵션과 같은 접두·접미 그룹에서 추첨한다. 장비에 남아 있는 다른 추가 옵션과 동일 종류가 동시에 중복되는 것은 허용하지 않는다.

## 확인 근거와 범위

사용자는 1안 재등장 허용과 2안 이번 교체에서는 제외 중 1안을 선택했다. 통제 여부에 관계없이 교체에 적용하며, 이번에는 재등장 여부만 정하고 등급·수치 추첨 규칙은 별도로 확인한다고 명시한 질문에 대한 선택이다.

이번 결정은 방금 제거한 종류를 새 추첨 후보에 포함하는 범위다. 제거한 기존 옵션의 등급·수치를 복원하거나 성능 향상을 보장하는 결정은 아니다. 종류의 재등장을 이유로 별도 성공·실패 판정을 추가하지 않는다.

새 옵션의 등급·수치 추첨 방식과 확률·가중치, 유효 후보가 부족한 상황의 처리, 소모량·공급과 별도 보호·되돌리기는 미정이다. 이 결정을 별도 수치 재추첨 작업이나 고유 장비 효과의 변경 규칙으로 확장하지 않는다.

장비 성급과 성급별 허용 옵션 등급, 작업별 기본 재료 4종과 공통 통제 재료 1종의 기존 구성을 유지한다. 실제 옵션·재료 데이터나 게임 코드는 이 결정 기록에 추가하지 않는다.
