# 개별 추가 옵션의 성능 등급은 7단계로 구성

개별 추가 옵션의 성능 등급은 장비의 진행 구간을 뜻하는 다섯 성급과 별개로 7단계로 구성한다.

## 확인 근거와 범위

사용자는 7단계와 10단계의 두 대안 중 1안인 7단계를 선택했다. 이번 결정은 옵션의 성능 등급 체계의 전체 단계 수다.

성급별 실제 허용 등급과 범위의 겹침은 후속 [DEC-0032](DEC-0032-three-affix-tiers-per-equipment-grade.md)에서 성급마다 세 등급을 한 단계씩 옮기는 안으로 확인했다. 이로써 최상위 성능 등급은 5성의 허용 범위에 포함된다. 등급의 명칭·표기 방향과 개별 옵션의 적용 범위·예외는 미정이다.

각 옵션 등급의 실제 수치와 등급 안의 변동 범위, 추첨 확률·비용도 별도로 확인한다. 모든 옵션 종류에 일곱 등급의 실제 데이터를 일괄 적용하는 결정은 아니며, 개별 옵션의 적용 범위와 예외는 후속으로 확인한다. 7단계라는 수만으로 제작 난도나 완성 시간을 정하지 않는다.

장비 성급이 높아지면 허용 옵션 등급의 하한과 상한을 함께 높이고, 5성 희귀 장비의 최상위 등급은 드롭과 제작 모두 허용한다는 기존 결정을 유지한다. 이번 단계에는 실제 옵션 데이터나 게임 코드를 추가하지 않는다.
