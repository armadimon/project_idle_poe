# 장비 성급은 성장 초중후반과 엔드게임 진입·종결 제작으로 배분

진행 구간별 장비 등급 다섯 단계의 역할은 성장 구간 중심으로 배분한다.

| 성급 | 역할 |
| --- | --- |
| 1성 | 성장 초반 |
| 2성 | 성장 중반 |
| 3성 | 성장 후반 |
| 4성 | 엔드게임 진입 |
| 5성 | 종결 제작 |

## 확인 근거와 범위

사용자는 1안 엔드게임 중심과 2안 성장 구간 중심 중 2안을 선택했다. 이번 결정은 다섯 등급의 역할 배분이며, 성장 중 장비 교체 목표를 세 구간으로 나누고 엔드게임은 진입과 종결 제작으로 구분한다.

성급별 허용 옵션 등급의 하한과 상한을 함께 높이는 원칙은 후속 [DEC-0027](DEC-0027-rising-affix-tier-floor-and-ceiling.md)에서 확인했다. 정확한 콘텐츠·난도·드롭 조건, 각 성급의 기본 성능과 실제 허용 옵션 등급·수치는 별도로 확인한다. 5성이라는 역할만으로 최고 옵션의 접근 조건이나 원하는 종결 장비의 완성을 보장하지 않는다.

희귀 장비의 성급은 후속 [DEC-0028](DEC-0028-fixed-rare-equipment-star-grade.md)에서 획득 시 고정하는 것으로 확인했다. 장비 간 기존 옵션·제작 투자 이전, 정식 명칭과 별의 시각적 형태는 미정이다. 희귀·고유 장비의 구분, 추가 옵션 최대 개수와 기반 고정 특성에 관한 기존 결정은 바꾸지 않는다.
