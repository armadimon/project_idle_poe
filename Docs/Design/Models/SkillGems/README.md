# 스킬·젬 검토용 수치 데이터

[전체 기획](../../Proposals/Skill-Gems-and-Build-Diversity.md) · [검증 요약](../../Analysis/SkillGems/SUMMARY.md) · [catalog.json](catalog.json)

이 데이터는 **proposed**인 독립 분석 입력이다. Unity Assets나 최종 게임/서버 데이터가 아니며 자동 반입하지 않는다.

- 액티브 24종의 공격 계수/주문 기본 피해·동작·재사용·범위·명중 차례, 보조 24종의 효과와 조건.
- 13개 예시 편성, 기본 4개와 별도 4개 비교 적 조건.
- 젬별 XP·배경 성장·보조 성장의 초안.
- 승인된 장비 표의 34옵션·단계 범위·후보를 출처 SHA256과 함께 기록한 스냅샷. 활/망치 기본 성능과 후보 적용은 비교용 제안이다.

모델은 같은 성급·허용 단계의 중앙 정수값으로 합법 희귀 장비를 만들고 접두·접미 예산을 검사한다. 실제 시작 장비나 파밍 드롭 분포의 대체가 아니다. 기본 생명력 1000·능력치 각 10도 기존 비교 기준이며 최종 시작 수치를 확정하지 않는다.

새 규칙을 승인받으면 정본과 실제 구현 계획을 갱신한다. 데이터를 변경할 때 결과 파일을 그대로 두지 말고 분석/테스트를 다시 실행하고 해석 문서도 대조한다.

```sh
python3 Tools/analyze_skill_gems.py --write-report
```

Python 3.9.6에서 실행했으며 표준 라이브러리만 사용한다. 새 외부 패키지·네트워크·Unity 실행은 필요하지 않다.
