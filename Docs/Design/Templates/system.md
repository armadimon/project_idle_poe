# 시스템 기획 제목

## 플레이어의 목적

이 시스템이 어떤 선택과 결과를 제공하는지 설명한다.

## 승인된 전제

관련 결정 파일을 연결한다. 미정인 전제는 먼저 사용자에게 확인한다.

## 작동 규칙

시작 조건, 입력과 선택, 처리, 결과, 예외를 기술한다. 세부 규칙과 수치는 확인받은 범위만 작성한다.

## 다른 시스템과의 관계

받는 입력, 내보내는 결과와 변경 시 영향받는 문서를 기록한다.

## 확인할 질문

미정 사항은 질문으로 남긴다.

## 검증 방법

규칙을 확인할 사례와 플레이 경험을 평가할 방법을 구분한다.
