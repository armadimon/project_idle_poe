# 방치형 액션 RPG의 초기 방향

장비·스킬 조합이 핵심인 방치형 액션 RPG를 모바일 우선으로 기획한다. 전투는 완전 자동으로 진행하며, 플레이어는 전투 사이에 장비·스킬·도전 대상을 선택한다.

## 사용자 확인을 마친 사항

| 항목 | 확인된 내용 | 근거 |
| --- | --- | --- |
| 장르와 중심 요소 | 장비·스킬 조합이 핵심인 방치형 액션 RPG | [DEC-0001](Decisions/DEC-0001-genre.md) |
| 전투 조작 | 완전 자동 전투이며 전투 사이에 장비·스킬·도전 대상을 선택 | [DEC-0002](Decisions/DEC-0002-combat-control.md) |
| 주력 플랫폼 | 모바일 우선 | [DEC-0003](Decisions/DEC-0003-platform.md) |

## 사용자 확인이 필요한 범위

화면 방향과 시점, 한 번 접속했을 때의 플레이 흐름, 세계관과 아트 방향, 전투의 진행·실패·재도전 규칙, 장비와 스킬의 조합 방식, 성장과 파밍 구조, 오프라인 보상, 과금, 첫 프로토타입의 범위는 미정이다. 확인 순서는 [기획 순서](01-Decision-Queue.md)에 둔다.

모바일 우선이라는 결정만으로 세로 화면, 짧은 접속, 특정 운영체제 지원 범위를 확정하지 않는다. 방치형이라는 장르만으로 오프라인 보상 공식이나 반복 파밍 방식을 정하지 않는다.
