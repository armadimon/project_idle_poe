# 장비 보관·비교·교체·분해 확인 결과

상태: 직전 요약과 상세 조건 전체를 사용자가 “오케이”로 확인했다. 승인 기록은 [DEC-0100](../Decisions/DEC-0100-equipment-inventory-comparison-and-salvage.md), 현행 규칙은 [장비 관리 기획서](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)에 통합했다.

무료 500칸·가상 교체 비교·전투 밖 무료 장착·반지/양손 처리·분해 보호·필터/정렬/선택 분해·기존 5종 재료의 1회 추첨과 투자 환급 없음·파밍 1/2칸·취소/복원을 한 묶음으로 확인했다. 보호/장착/고유 제외, 선택 초기화·제작 복귀·조건 미달 젬의 연결 보존 등 상세 조건도 기능 기획서를 따른다.

[조사](../../Research/2026-11-18-equipment-inventory-comparison-and-salvage.md)에 출처·버전·권리·호환성과 재사용 범위를 기록했다. 현재 변경은 기획 문서이며 정식 규칙의 Unity 구현·실행·경제/사용성 검증은 수행하지 않았다. 구현 전 조사와 적용·검증 계획은 별도로 제안한다.

[DEC-0102](../Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md)에서 첫 제작은 기본 4종과 집중석부터 검증하는 A안으로 확인했다. 고유 공통 규칙은 [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)의 2안(B)으로 확인했고 [기능 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다. 첫 고유 효과·수치·중복과 빌드 검증 목표는 [DEC-0105](../Decisions/DEC-0105-first-unique-effects-stacking-and-build-goals.md)에서 확인했고 [고유 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다. 후속 정식 스킬·젬 성장과 콘텐츠는 [기획 순서](../01-Decision-Queue.md)에서 확인한다. 자동 분해·프리셋·판매/거래·고유 분해·젬 보관·보관 확장은 별도 확인 사항이다.
