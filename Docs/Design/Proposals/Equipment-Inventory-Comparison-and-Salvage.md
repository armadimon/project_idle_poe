# 장비 보관·비교·교체·분해 묶음 제안

상태: **전체 미승인**. [장비 구성](../Systems/Equipment-Catalog-and-Base-Structure.md), [옵션·전투 수치표](../Systems/Equipment-Affixes-and-Combat-Numbers.md), [기본 제작](../Systems/Equipment-Crafting.md)을 전제로, 얻은 장비를 찾아 비교하고 장착·제작·보호·분해하는 흐름을 묶어 확인한다.

## 추천 묶음 요약

| 항목 | 제안 |
| --- | --- |
| 장비 보관 | 무료 500칸, 미장착 장비 1개가 1칸 사용. 장착 장비와 제작재료 수량은 별도 집계 |
| 선택·비교 | 목록에서 장비를 선택하면 같은 교체 대상과 비교. 별도 장착 입력으로 확정 |
| 비교 정보 | 성급·기반·고정 특성·접두/접미와 수치 범위, 선택 스킬의 명중 피해/동작/CD·생존·능력치·젬 조건의 변화 |
| 장착 시점·비용 | 전투 밖에서 무료 교체. 첫 희귀 장비는 부위·양손 관계를 검사하고 별도 성급/레벨/능력치 장착 조건을 추가하지 않음 |
| 반지·양손 처리 | 반지는 바꿀 칸을 선택. 양손도끼 장착 시 방패가 가방으로 돌아오며, 필요한 빈 칸 부족 시 실행 비활성 |
| 보호 | 장비의 ‘분해 보호’ 설정. 보호/장착 장비는 분해 대상에서 제외, 장착·제작은 가능 |
| 찾기 | 부위·성급·무기 계열·보호 여부·옵션 종류 필터, 최신 획득/성급/선택 옵션 수치 정렬 |
| 분해 | 미장착·보호 해제된 희귀 장비만, 무료 단건/선택 일괄 분해. 대상·수량·보상 규칙 확인 후 실행 |
| 분해 보상 | 장비당 제작재료 1회 추첨·1개 지급. 부여/제거/교체/조율/집중석 비율은 30/15/35/15/5% |
| 투자 회수 | 성급·옵션 개수·제작 이력과 무관하게 위 보상만 지급, 과거 소모한 제작 재료 추가 환급 없음 |
| 파밍 공간 | 기본 장비 보상 1칸, 모딩 보너스 가능 시 최대 보상 2칸을 입장 전에 확보. 부족하면 가방 정리로 안내 |
| 취소·복귀 | 확정 전 변경 없음. 장착·분해 확정 후 종료/재접속은 같은 상태를 복원하고 중복 장비·보상 생성 없음 |

보관·조작·분해 수량/확률은 이번에 확인할 자체 제안이다. 기존 파밍의 기본 보상·모딩 확률·제작 공급 비율은 그대로 두며 분해를 새 재료 획득 경로로 추가하는 안이다.

## 보관 단위와 파밍 공간

장비 크기에 따른 칸 조합 대신 미장착 장비 1개=1칸으로 두는 안이다. 첫 장비 보관 한도는 500개다. 장착한 장비 10칸과 제작재료 5종의 보유 수량은 이 500칸에 넣지 않는다. 젬 보관·확장 방법과 다른 보관 시설은 해당 기능 묶음에서 별도로 확인한다.

파밍은 성공하면 희귀 장비 기본 1개, 모딩으로 추가되면 최대 1개를 더 얻는 확정 규칙을 따른다. 패널티 없는 도전은 빈 칸 1개, 패널티가 있어 추가 보상 가능성이 있으면 빈 칸 2개를 입장 전에 확보하게 하는 안이다. 모딩 추가 보상을 항상 받는다는 뜻은 아니다.

공간이 부족하면 입장을 비활성화하고 필요한 칸 수와 가방 정리 경로를 안내한다. 같은 준비 대상에서 가방을 정리하고 돌아올 때 기존 파밍 대상·모딩 설정은 보관하며 사용 재료를 다시 소모하지 않는다. 전투 중에는 장착·제작·분해를 실행하지 않아 확보한 보상 공간을 유지한다. 가방이 찼다는 이유로 획득 장비를 임의 삭제하거나 다른 장비로 바꾸지 않는 안이다.

이번 확인은 첫 보관 한도와 입장 전 공간 조건이며 입장 비용·재도전 횟수·대기 시간을 추가하지 않는다.

## 장비 선택과 비교

장비를 선택하는 입력은 비교 대상을 바꾸는 동작이다. 장착 버튼을 별도로 실행하기 전에는 실제 장비·젬 사용 상태를 바꾸지 않는다. 초기 흐름은 목록 선택→비교→장착 또는 제작 이동이며, 드래그를 필수 조작으로 요구하지 않는 안이다.

같은 부위에서 교체할 현재 장비와 새 장비의 성급·기반·고정 특성, 접두/접미 종류·개수·단계·값·범위를 보여 준다. 반지는 어느 칸을 바꿀지 지정하고 그 칸 기준으로 비교한다. 첫 희귀 반지는 같은 기반을 두 칸에 각각 장착할 수 있게 하며 고유 장비의 중복 제한은 별도다.

비교는 현재 전체 장비 구성을 가상으로 바꿨을 때의 차이를 계산한다. 양손도끼를 골라 한손검+방패를 바꾸면 방패가 빠지는 영향도 함께 반영한다. 종합 장비 점수로 교체를 자동 권장하거나 자동 장착하는 기능은 첫 비교에 넣지 않는 안이다.

| 비교 범위 | 보여 줄 항목 |
| --- | --- |
| 선택한 스킬 | 일반/치명타 1회 명중 피해·치명타 확률·동작 시간·재사용 대기시간 |
| 생존 | 최대 생명력·보호막·물리 경감률·회피율·막기·화염/냉기/번개 저항 |
| 조건 | 힘·민첩·지능 변화와 사용 가능/조건 미달로 바뀌는 젬 |
| 장비 상세 | 기반 성능·고정 특성·접두/접미·단계·정수 범위와 적용 대상 |

기본 요약에서는 스킬 피해·생명력/보호막·젬 조건 변화를 보고 상세에서 다른 수치를 확인하는 안이다. %와 %p, 피해량과 시간의 단위를 구분하고 문자·부호도 함께 표시한다. 동작 시간처럼 낮아지는 것이 유리한 값의 방향을 올바르게 표시한다.

비교하는 스킬 데이터·무기 호환성·조건이 아직 정의되지 않았으면 계산 불가/미정 사유를 보여 주며 임의 기본값이나 0으로 대체하지 않는다. 여러 자동 스킬을 합친 실제 전투 DPS·클리어 보장과 비교 예시는 구분한다. 정식 스킬·전투 데이터는 후속 묶음에서 확인한다.

## 장착·제작 이동과 복귀

첫 희귀 장비의 장착에는 부위와 양손 사용 관계를 검사하고 별도 성급·레벨·힘/민첩/지능 조건은 추가하지 않는 안이다. 이미 등록된 젬의 요구 조건은 별도로 유지한다. 실제 직업·무기/스킬 호환성과 고유 장비 제한의 후속 규칙은 승인된 범위에서 추가한다.

장착 교체는 전투 밖에서 무료로 실행한다. 기존 장비는 가방으로 돌려보내고 새 장비를 장착하는 변경을 함께 처리한다. 양손도끼 장착 시 기존 주무기와 방패가 모두 가방으로 돌아가며 필요한 빈 칸이 없으면 사유와 함께 실행을 막는다. 방패가 자동 분해되거나 사라지지 않는다.

예를 들어 가방이 500개로 가득 차 있고 가방의 양손도끼를 장착하면, 양손도끼가 빠져 1칸이 생기지만 기존 한손검+방패가 2칸을 차지하므로 추가 빈 칸 1개가 필요하다. 한손검과 마법봉으로 바꿀 때 방패는 함께 유지할 수 있다.

장비 교체 뒤 전체 능력치를 다시 계산한다. 제작에서 확인한 것과 같이 조건 미달 젬은 연결/장착 위치를 보존한 채 사용 비활성으로 두고 조건 회복 시 재활성화한다. 새 장비가 주는 능력치도 최종 구성 계산에 포함한다.

가방에서 제작으로 이동하면 선택한 장비를 전달한다. 복귀 시 같은 장비·필터·정렬·스크롤 위치를 유지하고 제작으로 바뀐 값과 젬 조건을 갱신한다. 분해 등으로 선택 장비가 사라졌으면 선택을 해제하고 이유를 안내한다.

## 분해 보호·필터·선택

‘분해 보호’는 장비 처분을 막기 위한 설정으로, 장착·제작은 허용한다. 보호 표시는 문자/아이콘으로 구분하고 획득 장비는 기본 해제 상태로 두는 안이다. 장착 중인 장비는 보호 토글 상태와 무관하게 분해할 수 없다.

필터는 부위·성급·무기 계열·보호 상태·추가 옵션 종류를 조합해 찾게 한다. 기본 정렬은 최신 획득순이며 성급순과 선택한 옵션의 수치순도 제공하는 안이다. 필터링만으로 장비를 분해하거나 처분 대상으로 자동 선택하지 않는다.

분해 모드에서는 단건 또는 여러 개를 선택한다. 전체 선택은 현재 필터 결과 안의 분해 가능한 희귀 장비에 적용하며 화면에 보이는 일부만을 뜻하지 않는다. 보호/장착 장비와 고유 장비는 제외하고 선택 수량을 보여 준다. 필터나 정렬을 바꾸면 분해 선택은 초기화해 보이지 않는 선택이 남지 않게 하는 안이다. 대상이 없으면 실행 비활성·사유를 표시한다.

## 분해 보상·소비와 중단

분해 실행 전에 대상 장비·총 개수·장비당 제작재료 1회 추첨 규칙·재료별 확률을 보여 주고 확인받는다. 확인 전에는 장비를 삭제하거나 보상을 추첨하지 않는다. 확정하면 장비 삭제와 재료 보상을 한 번의 처리로 함께 적용하며 되돌리기·투자 비용 환급은 제공하지 않는 안이다.

| 분해 재료 추첨 | 확률 |
| --- | --- |
| 부여석 1개 | 30% |
| 제거석 1개 | 15% |
| 교체석 1개 | 35% |
| 조율석 1개 | 15% |
| 집중석 1개 | 5% |

장비마다 독립 추첨하며 같은 재료가 연속 나올 수 있다. 성급·옵션 개수·종류·값·제작 횟수와 사용 재료 이력에 따라 보상 개수나 확률을 올리지 않는다. 분해 보상에 던전 모딩 추가 드롭 보너스를 다시 적용하지 않는다. 과거 제작 재료는 별도 환급하지 않고 위 분해 보상만 지급한다.

앱 종료·접속 중단 후에는 확정한 장착/분해 결과를 복원한다. 같은 분해를 재추첨하거나 이미 삭제된 장비에서 보상을 중복 지급하지 않는다. 확정 전 취소·뒤로가기는 장비와 재료를 그대로 보존한다. 저장 방식·서버 구조는 구현 전 기술 조사에서 정한다.

## 대안·이유·조사와 검증

대안은 장비 보관을 무제한으로 두고 처분을 선택 사항으로 남기는 방식이다. 보관 압박은 줄지만 오래 쌓인 장비에서 제작 대상을 찾고 정리할 범위를 검토해야 한다. 분해를 새 재료로 보상하는 대안도 있으나 재료 종류·교환 경로가 늘어난다.

위 **500칸·필터와 항목별 비교·분해 보호·기존 재료 1회 추첨**을 권한다. 장비를 유지/교체/제작/처분할 판단을 한 흐름에서 다루고 새 제작 재료 종류를 늘리지 않으려는 안이다. 보관 한도와 분해 추가 수급은 실제 파밍 시간·완성 비용 검증 뒤 변경 필요성을 다시 확인한다.

[장비 비교·보관·분해 조사](../../Research/2026-11-18-equipment-inventory-comparison-and-salvage.md)에 공식 필터 문서·고정 PoB·기존 로컬 화면, 버전·라이선스·호환성과 재사용 범위를 기록했다. 기존 game-ui-standard 0.2.0의 정보/조작·현재/교체/조건 표시 원칙을 따르며 이번에는 기능과 정보 흐름만 제안한다. 화면 시안·새 아트·프레임·Unity 적용은 이 문서로 승인된 것으로 확대하지 않는다.

승인 후 500칸 경계·파밍 1/2칸 조건, 단일/반지/양손 교체의 가방 수량 보존, 가상 비교와 실제 결과·젬 조건, 제작 왕복 선택 유지, 보호/필터/전체 선택과 분해 제외, 확정/취소·보상 분포·중단/복원의 사례를 검증한다. 파밍 시간·몬스터/스킬을 정한 뒤 분해 추가 수급과 제작 소모를 연결해 종결 제작 비용과 최적 파밍 구간을 비교한다.

현재 제안은 문서까지다. 실제 가방 용량·분해·저장·비교·장착 코드를 구현하지 않았다. 구현 전에 기술 조사와 적용 범위·검증 계획을 제안한다. 자동 분해·장비 세트/프리셋·판매/거래·고유 장비 분해·젬 보관·보관 확장과 후속 직업/스킬 규칙은 별도 묶음에서 확인한다.
