# 종결 장비 제작 중심 게임의 적용 제안

확인된 방향은 **라이트한 PoE, 모바일 우선, 완전 자동 전투, 제작과 득템 중심, 종결 장비 제작과 이를 통한 경쟁**이다. 장비·스킬의 작동 구조는 PoE 1, 제작은 PoE 2를 참조한다. 아래는 [제작 조사](../../Research/Crafting/README.md)에 따른 제안이며 사용자 확인 전까지 세부 사양은 미정이다.

## 확인된 종결 장비의 기준

사용자는 **빌드별 좋은 옵션 조합을 찾고, 그 조합의 등급·수치까지 완성하는 혼합형**을 선택했다. 확인 근거는 [DEC-0010](../Decisions/DEC-0010-endgame-definition.md)에 기록했다.

옵션의 종류, 등급 체계와 수치 범위는 미정이다. 공통 점수나 랭킹 공식도 별도로 확인한다.

## 확인된 추가 옵션의 구조

기본 제작 장비의 추가 옵션은 **접두 최대 3개와 접미 최대 3개**, 합계 최대 6개다. 확인 근거는 [DEC-0011](../Decisions/DEC-0011-affix-slots.md)에 기록했다. 어떤 옵션이 각 그룹에 들어갈지와 중복·등급·추첨 규칙은 별도로 확인한다.

## 확인된 제작 대상과 고유 장비의 역할

추가 옵션 제작은 **희귀 장비 중심**이다. **고유 장비는 정해진 특수 효과를 제공하며 추가 옵션 제작에서 제외**한다. 확인 근거는 [DEC-0012](../Decisions/DEC-0012-crafting-equipment-scope.md)에 기록했다.

고유 장비의 개별 효과, 수치 변경·강화 여부, 장착 제한과 획득 방법은 미정이다. 희귀 장비 제작의 기반 장비와 하위 등급 처리도 별도로 확인한다.

## 다음 확인인 원하는 옵션을 고르는 범위

제작에서 원하는 옵션을 얼마나 직접 고를 수 있는지 먼저 확인하길 제안한다. 아래는 서로 다른 방향이며 아직 승인되지 않았다. 옵션의 등급과 수치를 완성하는 세부 규칙은 각 방향을 선택한 뒤 별도로 논의한다.

| 선택지 | 제작 경험 | 장단점 |
| --- | --- | --- |
| 1. 무작위 제작에 제한적인 통제 수단 제공 | 기본 결과는 무작위로 정하고, 일부 재료나 작업으로 접두·접미 또는 옵션 계열 등 추첨 범위를 좁힘 | 결과를 살려 다음 작업을 고르는 판단과 우연한 득템을 남길 수 있음. 통제 수단의 종류와 설명을 간결하게 설계해야 함 |
| 2. 원하는 옵션을 직접 지정 | 플레이어가 개별 옵션 종류를 고르고 등급·수치의 완성을 추구 | 제작 목표를 이해하기 쉬움. 옵션 조합을 찾아가는 과정의 변화를 별도로 마련해야 함 |
| 3. 통제 없이 무작위 제작 | 개별 옵션 지정이나 추첨 범위를 좁히는 수단 없이 결과를 얻음 | 작업 규칙은 단순해짐. 목표 조합을 향한 선택이 적고 반복 부담이 커질 수 있음 |

**1번**을 권장한다. 종결 장비를 만드는 과정에서 목표를 향한 선택과 예상 밖의 좋은 결과를 함께 남길 수 있어서다. 접두·접미와 옵션 계열은 가능한 통제 대상의 예시이며, 모두 도입한다는 뜻은 아니다. 어떤 통제를 허용할지, 특정 옵션을 보장하는 예외가 있을지, 비용·확률·보존 범위는 추가 확인이 필요하다. 이 방향만으로 특정 재료나 제작 작업을 구현하지 않는다.

## 제작에서 남길 판단의 후보

1. 획득한 아이템을 사용할지, 제작의 출발점으로 삼을지 판단한다.
2. 핵심 옵션과 남은 자리를 보고 다음 제작 작업을 고른다.
3. 추가 재료로 무작위 범위를 좁힐지, 결과를 받아들일지 판단한다.
4. 중간 결과를 쓰거나 다른 목표로 전환할지, 더 높은 완성도에 도전할지 판단한다.

위 순서는 제작의 판단을 검토하기 위한 예시다. 모든 단계가 매 제작에 반드시 등장하는 규칙으로 확정하지 않는다.

## 라이트함을 만들 수 있는 지점

| 지점 | 후보 접근 | 별도로 확인할 내용 |
| --- | --- | --- |
| 입력과 반복 | 여러 재료의 반복 사용을 이해하기 쉬운 작업 단위로 정리 | 수동·반복·일괄 제작 범위 |
| 정보 | 현재 가능한 옵션, 작업 대상과 보존 범위를 설명 | 확률 공개와 예상 결과 표시 범위 |
| 재료 관리 | 기본 작업에 쓰는 재료 종류를 제한 | 통화 종류, 획득과 교환 규칙 |
| 실패 부담 | 단계에 따라 기존 결과를 잃는 범위를 조정 | 재료만 소모, 옵션 손실, 장비 파괴·최종 가공 여부 |
| 종결 깊이 | 좋은 조합과 최고 완성도의 차이를 유지 | 옵션 수, 등급, 수치 범위와 희소성 |

현재는 조작·정보 부담을 줄이면서 제작 판단을 남기는 접근을 우선 검토하길 권한다. 실패 손실 완화는 별도 선택이다. 라이트하다는 이유로 확정 성공이나 장비 보존을 자동 채택하지 않는다.

## 경쟁 방식의 미정 항목

사용자가 확인한 내용은 종결 장비로 경쟁한다는 방향이다. 아래는 서로 다른 후보이며 실제 채택 여부를 확인해야 한다.

- 같은 조건의 자동 전투 결과로 장비·빌드 성능을 비교
- 특정 목표를 달성하는 기록이나 시즌 순위로 비교
- 장비 자체의 옵션 구성·등급·수치 완성도를 평가

직접 PvP, 거래소, 장비 점수, 시즌 초기화와 보상은 아직 결정하지 않았다.

## 다음 확인 순서

원하는 옵션을 고르는 범위 → 장비와 옵션의 종류 및 기본 제작 작업 → 보존과 실패 규칙 → 재료·득템 구조 → 경쟁의 평가 방식 순서로 논의를 제안한다. 화면과 소켓 색상은 이 구조를 정한 뒤 다룬다.

## 검증 계획

규칙을 확인받은 뒤 서로 다른 목표 장비를 예로 들어 획득부터 제작·중단·완성까지 가능한 경로를 검토한다. 비용과 확률을 합의하면 완성 비용의 분포, 중간 결과의 가치, 반복 제작의 판단 빈도를 검증한다. 경쟁 방식은 확정한 평가 조건에서 따로 확인한다. 이번 단계에는 게임 구현이나 확률·경제 수치를 추가하지 않는다.
