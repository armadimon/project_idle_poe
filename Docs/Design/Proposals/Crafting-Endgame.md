# 종결 장비 제작 중심 게임의 적용 제안

확인된 방향은 **라이트한 PoE, 모바일 우선, 완전 자동 전투, 제작과 득템 중심, 종결 장비 제작과 이를 통한 경쟁**이다. 장비·스킬의 작동 구조는 PoE 1, 제작은 PoE 2를 참조한다. 아래는 [제작 조사](../../Research/Crafting/README.md)에 따른 제안이며 사용자 확인 전까지 세부 사양은 미정이다.

## 확인된 종결 장비의 기준

사용자는 **빌드별 좋은 옵션 조합을 찾고, 그 조합의 등급·수치까지 완성하는 혼합형**을 선택했다. 확인 근거는 [DEC-0010](../Decisions/DEC-0010-endgame-definition.md)에 기록했다.

개별 옵션의 종류와 실제 등급별 수치 범위는 미정이다. 공통 점수나 랭킹 공식도 별도로 확인한다.

## 확인된 추가 옵션의 구조

기본 제작 장비의 추가 옵션은 **접두 최대 3개와 접미 최대 3개**, 합계 최대 6개다. 확인 근거는 [DEC-0011](../Decisions/DEC-0011-affix-slots.md)에 기록했다. 같은 종류의 추가 옵션은 드롭·제작 공통으로 희귀 장비당 1개로 제한한다. 어떤 옵션이 각 그룹에 들어갈지와 등급·추첨 규칙은 별도로 확인한다.

## 확인된 제작 대상과 고유 장비의 역할

추가 옵션 제작은 **희귀 장비 중심**이다. **고유 장비는 정해진 특수 효과를 제공하며 추가 옵션 제작에서 제외**한다. 확인 근거는 [DEC-0012](../Decisions/DEC-0012-crafting-equipment-scope.md)에 기록했다.

고유 장비의 개별 효과, 수치 변경·강화 여부, 장착 제한과 획득 방법은 미정이다. 희귀 장비 제작의 기반 장비와 하위 등급 처리도 별도로 확인한다.

## 확인된 무작위 제작과 제한적 통제

제작 결과는 **기본적으로 무작위이며 재료나 작업으로 추첨 범위를 제한적으로 좁힌다**. 사용자는 원하는 옵션 종류를 직접 지정하거나 통제 없이 완전 무작위로 제작하는 대안과 비교해 이 방향을 선택했다. 확인 근거는 [DEC-0013](../Decisions/DEC-0013-crafting-randomness-control.md)에 기록했다.

기본 재료는 작업별 4종이며 추가·제거·교체의 통제 재료는 공통 1종으로 확인했다. 재료 이름·소모량·공급과 실행 조건은 미정이다. 특정 옵션을 보장하는 예외, 비용·확률·등급·수치, 기존 옵션의 보존·손실도 추가 확인이 필요하다.

## 확인된 통제의 기본 단위

추첨 범위를 좁히는 통제는 **접두 또는 접미를 대상으로 선택하는 방식**이다. 선택한 그룹 안의 개별 결과는 무작위이며, 공격·방어 등 옵션 계열을 고르는 통제는 이번 구성에 포함하지 않는다. 확인 근거는 [DEC-0014](../Decisions/DEC-0014-prefix-suffix-control.md)에 기록했다.

접두를 선택하는 것과 원하는 접두 옵션 하나를 정확히 지정하는 것은 다르다. 정확한 통제 비용과 기존 옵션의 보존·손실 규칙은 별도로 확인한다.

## 확인된 기본 제작 작업

희귀 장비의 기본 제작은 **옵션 한 개씩 추가·제거·교체하는 세 작업을 각각 제공**한다. 교체는 기존 옵션 한 개를 빼고 새 옵션 한 개를 넣는 작업이다. 그룹 전체 재추첨은 이번 기본 구성에 포함하지 않는다. 확인 근거는 [DEC-0015](../Decisions/DEC-0015-basic-crafting-operations.md)에 기록했다.

추첨 후보와 가중치, 작업별 실행 조건과 기존 옵션의 보존·손실, 비용·추첨 확률은 미정이다. 수치만 다시 뽑는 작업은 후속 [DEC-0035](../Decisions/DEC-0035-reroll-affix-values-keeping-types-and-tiers.md)에서 옵션 종류·등급을 유지하는 별도 작업으로 도입을 확인했다. 옵션 등급을 올리는 별도 작업과 희귀도 승급은 아직 채택하지 않았다.

## 확인된 통제를 적용할 작업

추가·제거·교체 **세 작업 모두 접두·접미 선택을 허용**한다. 통제한 교체의 제거와 추가는 모두 선택한 그룹 안에서 진행한다. 선택한 그룹 안의 개별 결과는 계속 무작위다. 확인 근거는 [DEC-0016](../Decisions/DEC-0016-control-all-basic-operations.md)에 기록했다.

통제 재료는 세 작업이 공유하는 공통 1종으로 확인했다. 정확한 소모량과 공급, 작업별 무통제 제작의 세부 범위, 대상이나 빈자리가 없는 경우의 처리는 별도로 확인한다.

## 확인된 기본 작업의 실행

기본 추가·제거·교체에는 **별도의 성공·실패 판정을 두지 않는다**. 실행 조건을 만족하고 재료를 지불하면 작업을 실행한다. 어떤 옵션이 추가되거나 제거될지는 무작위이며, 통제한 작업은 확인된 접두·접미 범위를 따른다. 확인 근거는 [DEC-0018](../Decisions/DEC-0018-basic-crafting-no-failure-roll.md)에 기록했다.

작업이 실행되어도 좋은 옵션을 잃거나 원하는 새 옵션을 얻지 못할 수 있다. 원하는 결과의 보장이나 별도 보호 수단은 아직 채택하지 않았다. 실행할 수 없는 작업의 처리와 후속 특수 제작의 위험도 별도 확인한다.

## 확인된 접두·접미 지정의 추가 재료

접두 또는 접미를 지정하려면 **기본 제작 비용 외에 추가 재료를 사용**한다. 추가 통제 재료를 쓰지 않고 무작위로 진행하는 제작도 제공한다. 확인 근거는 [DEC-0019](../Decisions/DEC-0019-extra-material-for-affix-control.md)에 기록했다.

추가 재료를 언제 투자할지 판단하는 구조이며, 통제해도 그룹 안의 개별 결과는 무작위다. 기본 제작 재료의 구분은 아래와 같이 확인했다. 통제 재료의 공유 범위도 아래와 같이 확인했다. 통제 없는 교체도 제거한 옵션의 그룹을 유지하는 것으로 확인했다. 기본·통제 재료의 이름·소모량·공급, 무통제 추가·제거의 세부 추첨과 교체할 새 옵션 수치의 상세 추첨·등급별 확률은 별도로 확인한다.

## 확인된 주력 제작 경로

주력 제작은 **전투에서 얻은 장비의 기반과 기존 옵션을 보고 제작할 대상을 선별해 다듬는 경로**다. 확인 근거는 [DEC-0020](../Decisions/DEC-0020-drop-equipment-crafting-start.md)에 기록했다.

빈 기반 장비부터 시작하는 보조 경로의 허용 여부와 공급 방식은 미정이다. 기반 장비의 종류, 드롭 시 옵션 개수와 배치·등급·수치·분포, 완제품 드롭의 범위와 재료 공급도 별도로 확인한다.

## 확인된 희귀 장비 드롭의 빈 옵션 칸

전투 드롭에는 **추가 옵션이 일부만 붙은 희귀 장비와 6개가 모두 찬 희귀 장비를 함께 제공**한다. 접두 최대 3개·접미 최대 3개의 상한을 따른다. 확인 근거는 [DEC-0021](../Decisions/DEC-0021-partial-and-full-affix-drops.md)에 기록했다.

최소 옵션 개수와 접두·접미 배치, 각 구성의 출현 비율과 옵션 종류·등급·수치 분포는 미정이다. 추가 옵션이 없는 기반 장비의 보조 경로, 고유 장비와 다른 보상 경로는 별도로 확인한다. 6개가 찬 장비의 종결 여부는 빌드별 조합과 등급·수치의 완성 기준으로 판단한다.

## 확인된 기반 장비의 고정 특성

장비 기반에는 기본 성능 외에 **기반 종류마다 정해진 고정 특성을 접두·접미 6칸과 별도로 제공**한다. 확인 근거는 [DEC-0022](../Decisions/DEC-0022-base-fixed-traits.md)에 기록했다.

구체적인 효과·수치·개수, 수치의 변동과 특성 변경 가능 여부는 미정이다. 고정은 기반 종류에 정해진 특성이라는 뜻이며 수치의 고정 여부를 정한 것은 아니다. 고유 장비의 특수 효과와의 구체적인 관계도 별도로 확인한다.

## 확인된 추가 옵션 후보군의 공유 범위

**같은 장비 계열에 속하는 기반들은 추가 옵션 종류의 후보를 공유**한다. 기반별 차이는 기본 성능과 고정 특성으로 제공한다. 확인 근거는 [DEC-0023](../Decisions/DEC-0023-shared-affix-pool-by-equipment-family.md)에 기록했다.

계열과 기반의 실제 목록, 개별 옵션과 접두·접미 분류, 가중치와 등급·수치 범위, 후보를 제한하는 추가 조건은 미정이다. 후보 공유만으로 추첨 확률과 모든 등급·수치 조건까지 동일하게 정한 것은 아니다.

## 확인된 진행 구간별 장비 등급

사용자는 세분화된 아이템 레벨을 파악하기 위해 외부 자료를 찾아야 하는 부담을 지적하고, **진행 구간별 소수의 장비 등급을 성급 같은 방식으로 장비에 직접 표시**하는 방향을 제시했다. 확인 근거는 [DEC-0024](../Decisions/DEC-0024-visible-progression-equipment-grades.md)에 기록했다.

표시되는 장비 등급과 실제 제작 가능 범위의 구간을 일치시키고, 장비를 얻었을 때 종결 제작에 투자할 대상인지 게임 안에서 파악할 수 있게 한다. 같은 등급 안에 숨은 세밀한 레벨 경계를 다시 두지 않는다.

성급별 허용 옵션 등급의 하한과 상한을 함께 높이는 원칙과 구체적인 범위를 확인했다. 구체적인 표기와 획득 구간, 개별 옵션의 적용 범위·예외, 제작 재료 회수·투자 비용 환급 여부는 미정이다. 5성 희귀 장비의 최상위 등급 추가 옵션은 드롭과 제작 모두 허용한다. 희귀 장비의 추가 옵션은 다른 장비로 이전하지 않으며 성급은 획득 시 고정한다. 앞서 제안한 세분화된 숫자 아이템 레벨에 따른 옵션 상한은 승인된 사양이 아니다.

## 확인된 장비 등급의 단계 수

장비 등급은 **5단계**로 구성한다. 확인 근거는 [DEC-0025](../Decisions/DEC-0025-five-equipment-grades.md)에 기록했다. 각 단계의 역할은 아래와 같이 확인했으며, 이름과 정확한 획득 구간, 개별 옵션의 적용 범위·예외와 제작 재료 회수·투자 비용 환급 여부는 미정이다. 희귀 장비의 성급은 획득 시 고정한다.

## 확인된 5단계 장비 등급의 역할 배분

사용자는 성장 구간에 세 단계를 배분하는 **2안**을 선택했다. 확인 근거는 [DEC-0026](../Decisions/DEC-0026-growth-focused-equipment-grade-roles.md)에 기록했다.

| 성급 | 역할 |
| --- | --- |
| 1성 | 성장 초반 |
| 2성 | 성장 중반 |
| 3성 | 성장 후반 |
| 4성 | 엔드게임 진입 |
| 5성 | 종결 제작 |

성장 중에는 다음 성급의 장비로 교체하는 목표를 나누고, 엔드게임은 진입과 종결 제작으로 구분한다. 역할명은 진행 목적을 설명하며 콘텐츠의 정식 명칭이나 정확한 획득 조건을 뜻하지 않는다. 5성 획득이 원하는 옵션 조합과 최고 수치의 완성을 보장하는 것은 아니다.

각 성급의 정확한 드롭 구간·기본 성능, 개별 옵션의 적용 범위·예외와 제작 재료 회수·투자 비용 환급 여부는 별도 확인한다. 성급은 진행 구간의 구분이며 희귀·고유 구분이나 추가 옵션 개수를 바꾸는 결정이 아니다.

## 확인된 성급별 허용 옵션 등급의 범위 원칙

성급이 높아질수록 붙을 수 있는 옵션 등급의 **하한과 상한을 함께 높인다**. 높은 성급에서는 낮은 등급 옵션 일부를 후보에서 제외한다. 사용자는 상한만 높이는 안과 비교해 이 2안을 선택했다. 확인 근거는 [DEC-0027](../Decisions/DEC-0027-rising-affix-tier-floor-and-ceiling.md)에 기록했다.

장비의 성급과 개별 옵션의 등급은 별개다. 같은 장비 계열의 기반이 옵션 종류 후보를 공유한다는 기존 결정은 유지하며, 이번 결정은 그 옵션에 허용할 등급 범위에 관한 원칙이다. 성급별 허용 옵션 등급과 겹치는 범위는 아래와 같이 확인했다. 1~4성의 경로별 제한, 개별 옵션의 적용 범위·예외와 수치·확률은 미정이다. 5성 희귀 장비는 아래와 같이 드롭과 제작 모두 최상위 등급 옵션을 허용한다.

하한이 높아져도 원하는 옵션 종류나 조합, 최고 등급·최고 수치를 보장하지 않는다. 기존 옵션의 보호나 옵션 등급을 직접 올리는 작업은 이번 결정으로 채택하지 않는다. 희귀 장비의 성급은 후속 결정에 따라 획득 시 고정한다. 드롭 시 초기 옵션 등급 분포와 제작 시 추첨 가중치의 관계는 별도로 확인한다.

## 확인된 희귀 장비의 성급 고정

획득한 희귀 장비의 성급은 고정한다. 다음 성급의 장비를 새로 얻어 제작 대상을 교체한다. 사용자는 같은 장비의 성급 상승을 허용하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0028](../Decisions/DEC-0028-fixed-rare-equipment-star-grade.md)에 기록했다.

이번 결정은 희귀 장비의 성급 변경 여부다. 추가 옵션은 후속 결정에 따라 장비 간 이전하지 않는다. 분해 보상과 제작 재료 회수·투자 비용 환급, 고유 장비의 성장 규칙은 별도 확인한다. 새로운 장비를 얻는 구체적인 콘텐츠와 보상 경로도 미정이다.

## 확인된 희귀 장비의 추가 옵션 이전 없음

희귀 장비의 추가 옵션은 다른 장비로 이전하지 않는다. 새 장비에 이미 붙은 옵션을 보고 제작을 시작한다. 사용자는 이전 경로를 제공하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0029](../Decisions/DEC-0029-no-affix-transfer-between-rare-equipment.md)에 기록했다.

이번 결정은 추가 옵션 자체의 장비 간 이전 여부다. 추가 옵션을 이동·복사·추출하여 다른 장비에 그대로 적용하는 경로를 두지 않는다. 분해 보상, 제작 재료 회수와 투자 비용 환급은 별도 확인한다. 고유 장비의 성장 규칙이나 기반 고정 특성의 변경도 이번 결정에 포함하지 않는다.

## 확인된 5성 장비의 최상위 옵션 획득 경로

5성 희귀 장비는 **드롭과 제작 모두 최상위 등급의 추가 옵션을 허용**한다. 사용자는 최상위 등급을 제작에만 허용하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0030](../Decisions/DEC-0030-top-tier-affixes-from-drops-and-crafting.md)에 기록했다.

드롭에서 최상위 등급 옵션을 얻고 기존 제작 규칙에 따라 조합을 다듬는 경로를 허용한다. 원하는 옵션 종류·조합, 최상위 옵션의 개수나 최고 수치를 보장하는 결정은 아니다. 경로별 추첨 확률과 분포, 최상위 등급의 수치 범위, 완성 장비의 드롭 분포는 미정이다. 드롭과 제작의 확률이 같다고 정한 것도 아니다.

이번 확인 범위는 5성 희귀 장비의 최상위 추가 옵션 등급이다. 옵션 등급은 후속 결정에 따라 7단계로 구성한다. 성급별 허용 범위는 아래와 같이 확인했다. 개별 옵션의 적용 범위·예외와 1~4성의 경로별 제한은 별도 확인한다. 같은 성급 안에 숨은 세밀한 아이템 레벨 경계를 다시 두지 않는 방향은 유지한다.

## 확인된 개별 옵션 등급의 단계 수

개별 추가 옵션의 성능 등급은 장비의 다섯 성급과 별개로 **7단계**로 구성한다. 사용자는 10단계 안과 비교해 1안인 7단계를 선택했다. 확인 근거는 [DEC-0031](../Decisions/DEC-0031-seven-affix-performance-tiers.md)에 기록했다.

이번 결정은 성능 등급의 전체 단계 수다. 성급별 허용 범위와 범위의 겹침은 아래와 같이 확인했다. 등급 안의 범위에서 여러 수치를 추첨하는 원칙은 아래와 같이 확인했다. 등급의 명칭·표기 방향과 실제 수치 범위·값의 간격·분포·확률은 미정이다. 모든 옵션 종류에 일곱 등급의 실제 데이터를 일괄 적용한다는 뜻도 아니다. 옵션별 적용 범위와 예외는 개별 옵션을 구체화할 때 확인한다.

## 확인된 성급별 허용 옵션 등급 범위

성급마다 세 옵션 등급을 허용하고 성급이 오를 때 범위를 한 단계씩 높인다. 사용자는 5성만 상위 두 등급으로 제한하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0032](../Decisions/DEC-0032-three-affix-tiers-per-equipment-grade.md)에 기록했다.

아래 숫자는 낮은 성능부터 높은 성능까지의 비교용 순서로, **7이 최상위**다. 실제 등급 명칭이나 표기 방향은 별도로 확인한다.

| 장비 성급 | 허용 옵션 등급 |
| --- | --- |
| 1성 | 1~3 |
| 2성 | 2~4 |
| 3성 | 3~5 |
| 4성 | 4~6 |
| 5성 | 5~7 |

허용 범위와 범위의 겹침을 확인한 결정이며, 세 등급을 같은 확률로 추첨하거나 최고 수치를 보장한다는 뜻은 아니다. 5성의 최상위 등급은 드롭과 제작 모두 허용한다. 1~4성의 경로별 제한, 개별 옵션의 적용 범위·예외와 실제 수치·확률은 별도로 확인한다. 같은 성급 안에 숨은 숫자 레벨 경계를 두지 않는 기존 방향을 유지한다.

## 확인된 같은 옵션 등급 안의 수치 추첨 방식

같은 옵션 등급 안에서도 **최솟값~최댓값 범위의 여러 수치를 추첨**한다. 사용자는 낮음·중간·최대의 세 수치로 제한하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0033](../Decisions/DEC-0033-random-values-within-affix-tier-ranges.md)에 기록했다.

옵션 조합과 등급을 맞춘 뒤에도 수치의 완성을 추구할 수 있는 방식이다. 인접 등급 간 수치 범위는 아래와 같이 일부 겹치도록 설계한다. 실제 최솟값·최댓값과 겹침 폭, 값의 간격·단위와 분포·확률은 미정이다. 수치만 다시 뽑는 별도 작업은 후속 결정에 따라 아래와 같이 도입한다. 균등 확률이나 최고 수치 보장, 다른 기본 작업의 기존 옵션 보호 수단은 이번 결정에 포함하지 않는다.

## 확인된 같은 옵션의 인접 등급 간 수치 범위

같은 옵션의 인접 성능 등급은 **수치 범위가 일부 겹치도록 설계**한다. 하위 등급의 좋은 결과가 상위 등급의 낮은 결과보다 좋은 수치를 제공할 수 있다. 사용자는 수치 범위가 겹치지 않는 안과 비교해 이 2안을 선택했다. 확인 근거는 [DEC-0034](../Decisions/DEC-0034-overlapping-value-ranges-between-adjacent-affix-tiers.md)에 기록했다.

옵션 등급과 실제 수치를 함께 비교하고, 중간 등급의 좋은 결과를 활용할 여지를 두는 방식이다. 실제 겹침 폭과 각 등급의 최솟값·최댓값, 값의 간격·분포·확률과 개별 옵션의 적용 범위·예외는 미정이다. 모든 옵션에 같은 겹침 비율을 일괄 적용하는 결정은 아니다.

성급별 허용 옵션 등급 표와 등급 안의 여러 수치 추첨은 기존 결정을 따른다. 이번 결정은 같은 옵션의 인접 등급 간 수치 범위에 관한 것으로, 서로 다른 옵션이나 장비 전체의 빌드 가치를 등급 하나로 평가하는 규칙이 아니다.

## 확인된 수치 재추첨 작업 도입

희귀 장비의 추가 옵션 **종류·등급을 유지하고 수치만 다시 추첨하는 별도 작업을 제공**한다. 해당 등급의 범위에서 다시 추첨하며 수치가 나빠질 수도 있다. 사용자는 작업을 추가하지 않는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0035](../Decisions/DEC-0035-reroll-affix-values-keeping-types-and-tiers.md)에 기록했다.

이번 결정은 수치 재추첨 작업의 도입과 옵션 종류·등급 유지까지다. 대상 범위는 후속 [DEC-0036](../Decisions/DEC-0036-reroll-values-of-all-existing-affixes.md)에서 현재 붙은 모든 추가 옵션으로 확인했다. 기본 재료의 작업별 구분은 아래와 같이 확인했으며, 재료 이름·소모량·공급과 실행 조건·추첨 분포·확률은 미정이다. 새 결과를 바로 적용하는 방식은 후속 [DEC-0037](../Decisions/DEC-0037-apply-new-rerolled-values-directly.md)에서 확인했다. 최고 수치 보장·보호 재료는 별도 확인한다. 기존 추가·제거·교체에 대한 접두·접미 통제와 실행 규칙을 수치 재추첨에 자동으로 적용하지 않는다.

## 확인된 수치 재추첨 대상 옵션의 범위

수치 재추첨 한 번에 장비에 **현재 붙어 있는 모든 추가 옵션의 수치를 함께 재추첨**한다. 사용자는 한 옵션의 수치만 바꾸는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0036](../Decisions/DEC-0036-reroll-values-of-all-existing-affixes.md)에 기록했다.

옵션 종류와 등급은 유지하고 각 옵션 등급의 수치 범위에서 다시 추첨한다. 이미 좋은 수치도 대상에 포함된다. 일부 옵션만 붙어 있는 장비는 현재 존재하는 추가 옵션만 대상이며, 빈 칸에 새 옵션을 추가하지 않는다. 기반 고정 특성과 고유 장비 효과는 이 대상에 포함하지 않는다.

이번 결정은 작업의 대상 범위까지다. 새 결과를 바로 적용하는 방식은 아래와 같이 확인했다. 비용·실행 조건, 분포·확률과 추가 통제·보호 경로의 도입 여부는 미정이다. 추가·제거·교체에 허용한 접두·접미 통제를 수치 재추첨에 자동 적용하지 않는다.

## 확인된 수치 재추첨 결과 적용 방식

수치 재추첨의 **새 결과를 바로 적용**한다. 수치가 나빠져도 기존 값을 대체하며, 재추첨 후 기존 결과와 새 결과 중 하나를 고르는 방식은 제공하지 않는다. 사용자는 한 세트를 선택하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0037](../Decisions/DEC-0037-apply-new-rerolled-values-directly.md)에 기록했다.

옵션 종류·등급을 유지하고 현재 붙은 모든 추가 옵션의 수치를 함께 재추첨하는 기존 결정을 따른다. 이번 결정은 작업 실행 뒤의 결과 적용 규칙이다. 기본 재료는 아래와 같이 작업별로 구분한다. 구체적인 비용과 실행 조건, 분포·확률과 추가 통제·보호 경로의 도입 여부, 실행 전 확인 방법과 구체적인 화면·조작은 별도로 확인한다.

## 확인된 기본 제작 재료의 작업별 구분

추가·제거·교체·수치 재추첨에 **각각 한 종류씩 서로 다른 전용 기본 재료를 배정해 4종으로 구성**한다. 사용자는 공통 기본 재료 한 종류를 쓰는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0038](../Decisions/DEC-0038-dedicated-basic-materials-for-each-crafting-operation.md)에 기록했다.

후속 [DEC-0070](../Decisions/DEC-0070-share-equipment-replacement-material-with-dungeon-penalty-replacement.md)에 따라 이 중 **옵션 교체의 기본 재료를 파밍 던전의 패널티 교체에도 사용**한다. 기본 제작 재료 4종과 별도 통제 재료의 구분은 유지한다. 재료 공유만으로 두 작업의 소모량·실행 조건·추첨 확률·횟수 규칙을 같게 정하지 않는다.

| 작업 | 기본 재료의 용도 |
| --- | --- |
| 옵션 추가 | 추가 작업 전용 |
| 옵션 제거 | 제거 작업 전용 |
| 옵션 교체 | 교체 작업 전용 |
| 수치 재추첨 | 수치 재추첨 작업 전용 |

표는 용도를 구분한 것이며 재료의 정식 이름이나 한 번의 소모량을 정한 것이 아니다. 작업별 재료 공급을 따로 조정할 수 있으나 실제 공급과 희소성·교환은 미정이다. 접두·접미 지정에 드는 공통 통제 재료 1종은 기본 재료 4종과 별도로 유지한다. 공통 추가 비용의 도입 여부도 별도로 확인한다.

## 확인된 접두·접미 통제 재료의 공유 범위

**공통 통제 재료 1종을 추가·제거·교체가 공유**한다. 같은 통제 재료로 접두 또는 접미를 선택한다. 사용자는 작업별 통제 재료 3종을 두는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0039](../Decisions/DEC-0039-shared-material-for-prefix-suffix-control.md)에 기록했다.

기본 재료 4종과 공통 통제 재료 1종은 별도다. 기본 재료는 작업별로 사용하고, 접두·접미를 지정할 때 공통 통제 재료를 추가로 사용한다. 선택한 그룹 안의 개별 결과는 무작위이며 통제한 교체의 제거와 추가는 모두 선택한 그룹 안에서 진행한다.

이번 결정은 세 작업의 통제 재료를 공유하는 범위다. 재료 이름·소모량·공급·교환과 작업별 소모량의 동일 여부는 미정이다. 공통 재료 한 종류를 쓴다는 것이 한 번에 한 개를 소모하거나 세 작업의 비용이 같다는 뜻은 아니다. 수치 재추첨의 추가 통제와 구체적인 조작·화면도 별도 확인한다.

## 확인된 통제 없는 교체의 접두·접미 그룹 관계

통제 재료 없이 교체할 때도 **제거한 옵션의 그룹을 유지**한다. 접두를 제거하면 새 접두, 접미를 제거하면 새 접미를 추첨한다. 사용자는 그룹 변경을 허용하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0040](../Decisions/DEC-0040-keep-affix-group-in-uncontrolled-replacement.md)에 기록했다.

제거할 기존 옵션과 새로 붙을 개별 옵션은 무작위다. 교체 전후의 접두·접미 개수는 유지하며 각 그룹 최대 3개의 기존 상한을 따른다. 공통 통제 재료를 쓰면 기존 규칙대로 제거와 추가를 진행할 그룹을 직접 선택한다.

이번 결정은 통제 없는 교체의 그룹 관계다. 동일한 옵션 종류의 중복 제한은 아래와 같이 확인했다. 제거한 옵션 종류의 재등장은 아래와 같이 허용한다. 개별 옵션·등급·수치의 추첨 가중치와 실행 불가 상황의 처리는 별도 확인한다. 옵션 종류·등급·수치를 유지하는 보호 규칙을 채택한 것은 아니다.

## 확인된 같은 장비의 동일 옵션 종류 중복 제한

**동일 종류의 추가 옵션은 희귀 장비당 1개만 허용**한다. 같은 종류는 등급·수치가 달라도 동시에 여러 개 붙이지 않는다. 드롭과 제작에 공통으로 적용한다. 사용자는 동일 종류의 중복을 허용하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0041](../Decisions/DEC-0041-one-affix-of-each-kind-per-rare-equipment.md)에 기록했다.

접두 최대 3개·접미 최대 3개의 상한은 유지한다. 서로 다른 추가 옵션이 일부 능력치를 함께 제공하는 경우와 기반 고정 특성·고유 효과·다른 장비와의 능력치 중첩은 별도 확인한다. 실제 옵션 이름·분류·수치는 아직 정하지 않았다.

이번 결정은 같은 종류가 한 장비에 동시에 붙는지에 관한 것이다. 교체로 제거한 옵션 종류를 새 추첨 후보에 다시 포함하는 규칙은 아래와 같이 확인했다.

## 확인된 교체에서 제거한 옵션 종류의 재등장

교체에서 **방금 제거한 옵션 종류도 새 추첨 후보에 포함**한다. 사용자는 이번 교체의 후보에서 제외하는 안과 비교해 이 1안을 선택했다. 통제 여부에 관계없이 적용하며 확인 근거는 [DEC-0046](../Decisions/DEC-0046-allow-removed-affix-kind-to-reappear-in-replacement.md)에 기록했다.

같은 접두·접미 그룹에서 새 옵션을 추첨하고 장비에 남아 있는 다른 추가 옵션과 동일한 종류의 동시 중복은 허용하지 않는다. 방금 제거한 종류는 다시 나올 수 있으므로 재료를 써도 옵션 종류가 그대로일 수 있다.

이번 결정은 제거한 종류의 후보 포함 여부다. 새 옵션의 등급을 다시 추첨하는 원칙은 아래와 같이 확인했다. 새 옵션 수치의 상세 추첨과 확률, 후보 부족과 실행 불가 상황의 처리, 별도 보호·되돌리기와 소모량은 별도 확인한다. 기존 등급·수치의 보존이나 성능 향상을 보장한 것은 아니다.

## 확인된 교체할 새 옵션의 등급

교체할 새 추가 옵션의 성능 등급은 **장비 성급의 허용 범위에서 다시 추첨**한다. 기존보다 높거나 낮은 등급이 나올 수 있으며 성능 향상을 보장하지 않는다. 사용자는 제거한 옵션의 등급을 유지하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0047](../Decisions/DEC-0047-reroll-replacement-affix-tier-within-equipment-grade.md)에 기록했다.

통제한 교체와 통제 없는 교체 모두에 적용하며, 제거한 옵션과 같은 종류가 다시 등장해도 등급은 다시 추첨한다. 같은 등급이 다시 나올 가능성을 제외하는 결정도 아니다. 장비 성급 고정, 같은 접두·접미 그룹 및 동일 종류의 동시 중복 제한을 따른다.

이번 결정은 교체 작업의 새 옵션 등급을 정하는 원칙이다. 등급별 확률·가중치, 새 옵션 수치의 상세 추첨과 특정 옵션에 해당 등급이 없거나 후보가 부족한 상황의 처리는 미정이다. 추가·드롭 등 다른 경로의 등급 분포와 별도 수치 재추첨 작업은 기존 승인 범위를 따른다.

## 확인된 장비당 제작 횟수 제한 없음

희귀 장비의 **추가·제거·교체·수치 재추첨에 장비당 제작 횟수 제한을 두지 않는다**. 사용자는 네 작업이 공통 횟수 한도를 소모하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0048](../Decisions/DEC-0048-no-per-equipment-crafting-attempt-limit.md)에 기록했다.

현재 옵션 칸과 대상 등 각 작업의 실행 조건을 만족하고 필요한 비용을 지불하면 같은 장비를 계속 다듬을 수 있다. 횟수 제한 없음은 무료 제작이나 원하는 결과 보장을 뜻하지 않는다.

이번 결정은 네 작업의 장비당 횟수 제한 여부다. 비용·공급과 작업별 세부 실행 조건, 실행할 수 없는 작업의 처리와 별도 특수 제작·보호 수단은 미정이다.

## 확인된 게임 안의 제작 정보 공개 범위

제작에서 **가능한 옵션 후보·허용 옵션 등급·수치 범위와 옵션 종류별·등급별 추첨 확률을 게임 안에서 공개**한다. 사용자는 후보와 범위만 공개하는 안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0051](../Decisions/DEC-0051-disclose-crafting-candidates-ranges-and-probabilities.md)에 기록했다.

현재 장비와 선택한 작업·통제 조건에 실제로 적용되는 정보를 기준으로 한다. 이번 결정은 공개 범위이며 실제 확률·분포나 균등 추첨을 채택한 것은 아니다. 실제 확률 수치와 화면 구성은 별도 확인한다.

수치 범위 안의 개별 값별 확률, 복합 결과와 조건부 확률의 표시 방식, 반복 제작의 기대 비용 계산 기능은 미정이다. 수치 재추첨처럼 옵션 종류·등급이 고정된 작업에는 실제로 변하는 정보에 맞춰 세부 적용 범위를 구체화한다. 구체적인 조작과 시안은 이 결정에 포함하지 않는다.

## 제작에서 남길 판단의 후보

1. 획득한 아이템을 사용할지, 제작의 출발점으로 삼을지 판단한다.
2. 핵심 옵션과 남은 자리를 보고 다음 제작 작업을 고른다.
3. 추가 재료로 무작위 범위를 좁힐지, 결과를 받아들일지 판단한다.
4. 중간 결과를 쓰거나 다른 목표로 전환할지, 더 높은 완성도에 도전할지 판단한다.

위 순서는 제작의 판단을 검토하기 위한 예시다. 모든 단계가 매 제작에 반드시 등장하는 규칙으로 확정하지 않는다.

## 라이트함을 만들 수 있는 지점

| 지점 | 후보 접근 | 별도로 확인할 내용 |
| --- | --- | --- |
| 입력과 반복 | 여러 재료의 반복 사용을 이해하기 쉬운 작업 단위로 정리 | 수동·반복·일괄 제작 범위 |
| 정보 | 확인된 후보·등급·수치 범위와 옵션 종류별·등급별 확률 공개 | 개별 수치의 확률·복합 결과와 세부 표현 |
| 재료 관리 | 기본 작업에 쓰는 재료 종류를 제한 | 통화 종류, 획득과 교환 규칙 |
| 보존과 특수 제작 | 기본 작업의 무작위 옵션 손실과 후속 특수 제작의 위험을 구분 | 별도 보호 수단, 특수 제작 도입 여부와 손실 범위 |
| 종결 깊이 | 좋은 조합과 최고 완성도의 차이를 유지 | 옵션 수, 등급, 수치 범위와 희소성 |

현재는 조작·정보 부담을 줄이면서 제작 판단을 남기는 접근을 우선 검토하길 권한다. 기본 세 작업에는 별도 실패 판정을 두지 않는 것으로 확인했다. 원하는 옵션의 보장이나 별도 보호 수단은 아직 채택하지 않았다.

[파밍 수급·정산 묶음](../Decisions/DEC-0094-farming-dungeon-supply-settlement-and-resume.md)을 확인했다. [장비 득템·파밍 대상 묶음](../Decisions/DEC-0095-equipment-drops-and-farming-targets.md)을 확인했고 현행 규칙은 [기능 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)에 모았다. [장비 편성·기반 구조 묶음](../Decisions/DEC-0096-equipment-catalog-and-base-structure.md)을 확인했고 현행 목록은 [장비 구성 기획서](../Systems/Equipment-Catalog-and-Base-Structure.md)에 모았다. 다음에는 [옵션·전투 적용·7등급 수치표](Equipment-Affixes-and-Combat-Numbers.md)를 한 묶음으로 확인한다. 경쟁 재도전의 횟수·초기화·보상과 파밍의 실제 장비 후보·구간별 전투 구성, 장비 제작 등 다른 작업의 환급·종료 처리는 후속 확인 사항이다.

직접 PvP, 거래소, 장비 점수, 순위표·시즌·초기화와 보상은 아직 결정하지 않았다.

## 다음 확인 순서

던전 준비의 입장 조건·재료 소모·조정 범위·잠금 동작은 [DEC-0090](../Decisions/DEC-0090-farming-dungeon-preparation-and-modification-rules.md)에서 확인했다. 패널티 종류·수치·중복·추첨과 보상 강화는 [DEC-0092](../Decisions/DEC-0092-farming-dungeon-penalties-and-bonus-drops.md)에서 확인했다. 기본 보상과 재료 공급·입장·실패·포기·재접속 처리는 [DEC-0094](../Decisions/DEC-0094-farming-dungeon-supply-settlement-and-resume.md)에서 확인했다. 성급별 파밍 구간·해금·목표 부위·드롭 옵션 생성은 [DEC-0095](../Decisions/DEC-0095-equipment-drops-and-farming-targets.md)에서 확인했다. 장비 편성·기반 구조는 [DEC-0096](../Decisions/DEC-0096-equipment-catalog-and-base-structure.md)에서 확인했다. 다음은 실제 기반 성능·특성 수치와 옵션·전투 적용·7등급 수치표를 묶어 확인한다. 작업별 실행 조건과 공개 정보의 세부 표현, 새 옵션 수치의 상세 추첨 및 장비·옵션의 종류, 보존과 손실·재료·득템 규칙은 후속 확인 항목으로 남긴다. 화면과 소켓 색상은 이 구조를 정한 뒤 다룬다.

## 검증 계획

규칙을 확인받은 뒤 서로 다른 목표 장비를 예로 들어 획득부터 제작·중단·완성까지 가능한 경로를 검토한다. 장비 등급과 제작 가능 범위를 확인한 뒤에는 게임 안의 장비 정보만 보고 현재 진행 구간과 목표 제작 가능 여부를 설명할 수 있는지도 검토한다. 드롭과 제작에서 같은 옵션 종류가 동시에 중복되지 않는지, 등급·수치 차이를 중복 판정에 잘못 쓰지 않는지도 예시로 검토한다. 교체는 통제 여부에 따라 제거 대상 그룹을 선택하는 차이와 그룹별 개수가 유지되는 결과, 같은 종류가 재등장해도 성급별 허용 범위에서 등급을 다시 추첨하는지를 예시로 점검한다. 제작 횟수를 누적했다는 이유로 네 작업의 실행이 종료되지 않는지도 실행 조건과 구분해 검토한다. 재료의 소모량과 공급을 확인한 뒤에는 네 작업의 재료 수급과 부족 상황, 통제 재료를 사용할 시점을 검토한다. 확률을 합의한 뒤 공개 정보가 현재 장비·작업·통제 조건의 실제 후보와 추첨 확률에 맞는지도 검토한다. 비용과 확률을 합의하면 완성 비용의 분포, 중간 결과의 가치, 반복 제작의 판단 빈도를 검증한다. 경쟁 방식은 확정한 평가 조건에서 따로 확인한다. 이번 단계에는 게임 구현이나 확률·경제 수치를 추가하지 않는다.
