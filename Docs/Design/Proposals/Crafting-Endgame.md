# 종결 장비 제작 중심 게임의 적용 제안

확인된 방향은 **라이트한 PoE, 모바일 우선, 완전 자동 전투, 제작과 득템 중심, 종결 장비 제작과 이를 통한 경쟁**이다. 장비·스킬의 작동 구조는 PoE 1, 제작은 PoE 2를 참조한다. 아래는 [제작 조사](../../Research/Crafting/README.md)에 따른 제안이며 사용자 확인 전까지 세부 사양은 미정이다.

## 확인된 종결 장비의 기준

사용자는 **빌드별 좋은 옵션 조합을 찾고, 그 조합의 등급·수치까지 완성하는 혼합형**을 선택했다. 확인 근거는 [DEC-0010](../Decisions/DEC-0010-endgame-definition.md)에 기록했다.

옵션의 종류, 등급 체계와 수치 범위는 미정이다. 공통 점수나 랭킹 공식도 별도로 확인한다.

## 확인된 추가 옵션의 구조

기본 제작 장비의 추가 옵션은 **접두 최대 3개와 접미 최대 3개**, 합계 최대 6개다. 확인 근거는 [DEC-0011](../Decisions/DEC-0011-affix-slots.md)에 기록했다. 어떤 옵션이 각 그룹에 들어갈지와 중복·등급·추첨 규칙은 별도로 확인한다.

## 확인된 제작 대상과 고유 장비의 역할

추가 옵션 제작은 **희귀 장비 중심**이다. **고유 장비는 정해진 특수 효과를 제공하며 추가 옵션 제작에서 제외**한다. 확인 근거는 [DEC-0012](../Decisions/DEC-0012-crafting-equipment-scope.md)에 기록했다.

고유 장비의 개별 효과, 수치 변경·강화 여부, 장착 제한과 획득 방법은 미정이다. 희귀 장비 제작의 기반 장비와 하위 등급 처리도 별도로 확인한다.

## 확인된 무작위 제작과 제한적 통제

제작 결과는 **기본적으로 무작위이며 재료나 작업으로 추첨 범위를 제한적으로 좁힌다**. 사용자는 원하는 옵션 종류를 직접 지정하거나 통제 없이 완전 무작위로 제작하는 대안과 비교해 이 방향을 선택했다. 확인 근거는 [DEC-0013](../Decisions/DEC-0013-crafting-randomness-control.md)에 기록했다.

정확한 기본 비용과 통제 재료의 종류·수량·공급, 실행 조건은 미정이다. 특정 옵션을 보장하는 예외, 비용·확률·등급·수치, 기존 옵션의 보존·손실도 추가 확인이 필요하다.

## 확인된 통제의 기본 단위

추첨 범위를 좁히는 통제는 **접두 또는 접미를 대상으로 선택하는 방식**이다. 선택한 그룹 안의 개별 결과는 무작위이며, 공격·방어 등 옵션 계열을 고르는 통제는 이번 구성에 포함하지 않는다. 확인 근거는 [DEC-0014](../Decisions/DEC-0014-prefix-suffix-control.md)에 기록했다.

접두를 선택하는 것과 원하는 접두 옵션 하나를 정확히 지정하는 것은 다르다. 정확한 통제 비용과 기존 옵션의 보존·손실 규칙은 별도로 확인한다.

## 확인된 기본 제작 작업

희귀 장비의 기본 제작은 **옵션 한 개씩 추가·제거·교체하는 세 작업을 각각 제공**한다. 교체는 기존 옵션 한 개를 빼고 새 옵션 한 개를 넣는 작업이다. 그룹 전체 재추첨은 이번 기본 구성에 포함하지 않는다. 확인 근거는 [DEC-0015](../Decisions/DEC-0015-basic-crafting-operations.md)에 기록했다.

추첨 후보와 가중치, 작업별 실행 조건과 기존 옵션의 보존·손실, 비용·추첨 확률은 미정이다. 수치만 다시 뽑는 작업이나 옵션 등급을 올리는 별도 작업, 희귀도 승급도 아직 채택하지 않았다.

## 확인된 통제를 적용할 작업

추가·제거·교체 **세 작업 모두 접두·접미 선택을 허용**한다. 통제한 교체의 제거와 추가는 모두 선택한 그룹 안에서 진행한다. 선택한 그룹 안의 개별 결과는 계속 무작위다. 확인 근거는 [DEC-0016](../Decisions/DEC-0016-control-all-basic-operations.md)에 기록했다.

정확한 통제 비용과 재료, 작업별 무통제 제작의 세부 범위, 대상이나 빈자리가 없는 경우의 처리는 별도로 확인한다.

## 확인된 기본 작업의 실행

기본 추가·제거·교체에는 **별도의 성공·실패 판정을 두지 않는다**. 실행 조건을 만족하고 재료를 지불하면 작업을 실행한다. 어떤 옵션이 추가되거나 제거될지는 무작위이며, 통제한 작업은 확인된 접두·접미 범위를 따른다. 확인 근거는 [DEC-0018](../Decisions/DEC-0018-basic-crafting-no-failure-roll.md)에 기록했다.

작업이 실행되어도 좋은 옵션을 잃거나 원하는 새 옵션을 얻지 못할 수 있다. 원하는 결과의 보장이나 별도 보호 수단은 아직 채택하지 않았다. 실행할 수 없는 작업의 처리와 후속 특수 제작의 위험도 별도 확인한다.

## 확인된 접두·접미 지정의 추가 재료

접두 또는 접미를 지정하려면 **기본 제작 비용 외에 추가 재료를 사용**한다. 추가 통제 재료를 쓰지 않고 무작위로 진행하는 제작도 제공한다. 확인 근거는 [DEC-0019](../Decisions/DEC-0019-extra-material-for-affix-control.md)에 기록했다.

추가 재료를 언제 투자할지 판단하는 구조이며, 통제해도 그룹 안의 개별 결과는 무작위다. 기본 비용과 통제 재료의 종류·수량·공급, 작업별 무통제 제작의 세부 규칙과 교체의 그룹 관계는 별도로 확인한다.

## 확인된 주력 제작 경로

주력 제작은 **전투에서 얻은 장비의 기반과 기존 옵션을 보고 제작할 대상을 선별해 다듬는 경로**다. 확인 근거는 [DEC-0020](../Decisions/DEC-0020-drop-equipment-crafting-start.md)에 기록했다.

빈 기반 장비부터 시작하는 보조 경로의 허용 여부와 공급 방식은 미정이다. 기반 장비의 종류, 드롭 시 옵션 개수와 배치·등급·수치·분포, 완제품 드롭의 범위와 재료 공급도 별도로 확인한다.

## 확인된 희귀 장비 드롭의 빈 옵션 칸

전투 드롭에는 **추가 옵션이 일부만 붙은 희귀 장비와 6개가 모두 찬 희귀 장비를 함께 제공**한다. 접두 최대 3개·접미 최대 3개의 상한을 따른다. 확인 근거는 [DEC-0021](../Decisions/DEC-0021-partial-and-full-affix-drops.md)에 기록했다.

최소 옵션 개수와 접두·접미 배치, 각 구성의 출현 비율과 옵션 종류·등급·수치 분포는 미정이다. 추가 옵션이 없는 기반 장비의 보조 경로, 고유 장비와 다른 보상 경로는 별도로 확인한다. 6개가 찬 장비의 종결 여부는 빌드별 조합과 등급·수치의 완성 기준으로 판단한다.

## 확인된 기반 장비의 고정 특성

장비 기반에는 기본 성능 외에 **기반 종류마다 정해진 고정 특성을 접두·접미 6칸과 별도로 제공**한다. 확인 근거는 [DEC-0022](../Decisions/DEC-0022-base-fixed-traits.md)에 기록했다.

구체적인 효과·수치·개수, 수치의 변동과 특성 변경 가능 여부는 미정이다. 고정은 기반 종류에 정해진 특성이라는 뜻이며 수치의 고정 여부를 정한 것은 아니다. 고유 장비의 특수 효과와의 구체적인 관계도 별도로 확인한다.

## 확인된 추가 옵션 후보군의 공유 범위

**같은 장비 계열에 속하는 기반들은 추가 옵션 종류의 후보를 공유**한다. 기반별 차이는 기본 성능과 고정 특성으로 제공한다. 확인 근거는 [DEC-0023](../Decisions/DEC-0023-shared-affix-pool-by-equipment-family.md)에 기록했다.

계열과 기반의 실제 목록, 개별 옵션과 접두·접미 분류, 가중치와 등급·수치 범위, 후보를 제한하는 추가 조건은 미정이다. 후보 공유만으로 추첨 확률과 모든 등급·수치 조건까지 동일하게 정한 것은 아니다.

## 확인된 진행 구간별 장비 등급

사용자는 세분화된 아이템 레벨을 파악하기 위해 외부 자료를 찾아야 하는 부담을 지적하고, **진행 구간별 소수의 장비 등급을 성급 같은 방식으로 장비에 직접 표시**하는 방향을 제시했다. 확인 근거는 [DEC-0024](../Decisions/DEC-0024-visible-progression-equipment-grades.md)에 기록했다.

표시되는 장비 등급과 실제 제작 가능 범위의 구간을 일치시키고, 장비를 얻었을 때 종결 제작에 투자할 대상인지 게임 안에서 파악할 수 있게 한다. 같은 등급 안에 숨은 세밀한 레벨 경계를 다시 두지 않는다.

표기와 획득 구간, 제작 가능 범위와 옵션 최고 등급의 대응, 장비 등급의 변경과 기존 투자 이전 여부는 미정이다. 앞서 제안한 숫자 아이템 레벨에 따른 옵션 상한은 승인되지 않았으며 이번 방향을 바탕으로 다시 논의한다.

## 확인된 장비 등급의 단계 수

장비 등급은 **5단계**로 구성한다. 확인 근거는 [DEC-0025](../Decisions/DEC-0025-five-equipment-grades.md)에 기록했다. 각 단계의 역할은 아래와 같이 확인했으며, 이름과 정확한 획득 구간, 제작 가능 범위와 승급·이전 규칙은 미정이다.

## 확인된 5단계 장비 등급의 역할 배분

사용자는 성장 구간에 세 단계를 배분하는 **2안**을 선택했다. 확인 근거는 [DEC-0026](../Decisions/DEC-0026-growth-focused-equipment-grade-roles.md)에 기록했다.

| 성급 | 역할 |
| --- | --- |
| 1성 | 성장 초반 |
| 2성 | 성장 중반 |
| 3성 | 성장 후반 |
| 4성 | 엔드게임 진입 |
| 5성 | 종결 제작 |

성장 중에는 다음 성급의 장비로 교체하는 목표를 나누고, 엔드게임은 진입과 종결 제작으로 구분한다. 역할명은 진행 목적을 설명하며 콘텐츠의 정식 명칭이나 정확한 획득 조건을 뜻하지 않는다. 5성 획득이 원하는 옵션 조합과 최고 수치의 완성을 보장하는 것은 아니다.

각 성급의 정확한 드롭 구간·기본 성능·허용 옵션 등급, 성급 상승과 기존 투자 이전 여부는 별도 확인한다. 성급은 진행 구간의 구분이며 희귀·고유 구분이나 추가 옵션 개수를 바꾸는 결정이 아니다.

## 다음 확인인 성급별 허용 옵션 등급의 범위

아래 두 안은 아직 승인되지 않은 제안이다. 장비의 성급과 개별 옵션의 등급은 별개다. 이번 질문은 성급이 높아질 때 붙을 수 있는 옵션의 성능 범위를 어떻게 높일지이며, 개별 옵션과 실제 수치·확률은 후속으로 확인한다.

| 대안 | 제작 결과의 차이 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 상한만 상승 | 높은 성급일수록 더 높은 등급의 옵션이 가능하지만 최하위 등급도 계속 나올 수 있음 | 고성급에서도 좋은 수치를 뽑는 목표가 길게 남음. 낮은 결과의 반복이 부담이 될 수 있음 |
| 2안: 하한과 상한 상승 — 추천 | 높은 성급일수록 더 높은 등급의 옵션이 가능하고 낮은 등급 일부는 후보에서 제외 | 다음 성급의 기본 품질을 체감하기 쉬움. 종결 제작의 깊이는 옵션 조합과 남은 등급·수치 차이로 검토해야 함 |

라이트한 PoE와 성급의 직관성을 고려해 **2안**을 권장한다. 높은 성급의 장비에 제작 재료를 썼을 때 낮은 등급 결과가 반복되는 부담을 줄일 수 있어서다. 정확히 어느 성급에서 어떤 옵션 등급을 허용할지, 범위가 얼마나 겹칠지와 최고 등급의 접근 조건은 이 질문만으로 확정하지 않는다.

같은 장비 계열의 기반이 옵션 종류 후보를 공유한다는 기존 결정은 유지한다. 이번 비교는 그 옵션에 허용할 등급 범위에 관한 제안이다. 장비 성급 상승, 옵션 등급을 직접 올리는 별도 작업, 결과 보장이나 보호 재료는 별도 확인한다.

## 제작에서 남길 판단의 후보

1. 획득한 아이템을 사용할지, 제작의 출발점으로 삼을지 판단한다.
2. 핵심 옵션과 남은 자리를 보고 다음 제작 작업을 고른다.
3. 추가 재료로 무작위 범위를 좁힐지, 결과를 받아들일지 판단한다.
4. 중간 결과를 쓰거나 다른 목표로 전환할지, 더 높은 완성도에 도전할지 판단한다.

위 순서는 제작의 판단을 검토하기 위한 예시다. 모든 단계가 매 제작에 반드시 등장하는 규칙으로 확정하지 않는다.

| 정보 | 현재 가능한 옵션, 작업 대상과 보존 범위를 설명 | 확률 공개와 예상 결과 표시 범위 |
| 재료 관리 | 기본 작업에 쓰는 재료 종류를 제한 | 통화 종류, 획득과 교환 규칙 |
| 보존과 특수 제작 | 기본 작업의 무작위 옵션 손실과 후속 특수 제작의 위험을 구분 | 별도 보호 수단, 특수 제작 도입 여부와 손실 범위 |
| 종결 깊이 | 좋은 조합과 최고 완성도의 차이를 유지 | 옵션 수, 등급, 수치 범위와 희소성 |

현재는 조작·정보 부담을 줄이면서 제작 판단을 남기는 접근을 우선 검토하길 권한다. 기본 세 작업에는 별도 실패 판정을 두지 않는 것으로 확인했다. 원하는 옵션의 보장이나 별도 보호 수단은 아직 채택하지 않았다.

## 경쟁 방식의 미정 항목

사용자가 확인한 내용은 종결 장비로 경쟁한다는 방향이다. 아래는 서로 다른 후보이며 실제 채택 여부를 확인해야 한다.

- 같은 조건의 자동 전투 결과로 장비·빌드 성능을 비교
- 특정 목표를 달성하는 기록이나 시즌 순위로 비교
- 장비 자체의 옵션 구성·등급·수치 완성도를 평가

직접 PvP, 거래소, 장비 점수, 시즌 초기화와 보상은 아직 결정하지 않았다.

## 다음 확인 순서

성급별 허용 옵션 등급의 범위 → 구간별 제작 가능 범위의 구체화 → 장비와 옵션의 종류 및 작업별 실행 조건 → 보존과 손실 규칙 → 재료·득템 구조 → 경쟁의 평가 방식 순서로 논의를 제안한다. 화면과 소켓 색상은 이 구조를 정한 뒤 다룬다.

## 검증 계획

규칙을 확인받은 뒤 서로 다른 목표 장비를 예로 들어 획득부터 제작·중단·완성까지 가능한 경로를 검토한다. 장비 등급과 제작 가능 범위를 확인한 뒤에는 게임 안의 장비 정보만 보고 현재 진행 구간과 목표 제작 가능 여부를 설명할 수 있는지도 검토한다. 비용과 확률을 합의하면 완성 비용의 분포, 중간 결과의 가치, 반복 제작의 판단 빈도를 검증한다. 경쟁 방식은 확정한 평가 조건에서 따로 확인한다. 이번 단계에는 게임 구현이나 확률·경제 수치를 추가하지 않는다.
