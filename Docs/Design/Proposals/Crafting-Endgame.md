# 종결 장비 제작의 확인 사항과 후속 제안

현재 방향은 라이트한 PoE·모바일 우선·완전 자동 전투·득템과 제작 중심·종결 장비를 통한 경쟁이다. 주력 경로는 좋은 드롭 장비를 골라 다듬고 빌드별 조합·단계·수치를 완성하는 방식이다.

현행 규칙은 아래 기능 기획서에서 읽고 각 문서에 연결된 결정에서 승인 이력을 확인한다.

| 기능 | 현행 규칙 |
| --- | --- |
| 희귀 장비 기본 제작 | [작업 4종·통제·보존과 재료 구조·횟수와 정보](../Systems/Equipment-Crafting.md) |
| 장비 편성·기반 | [10칸·첫 무기 3계열·기반 역할과 고정 특성](../Systems/Equipment-Catalog-and-Base-Structure.md) |
| 장비·전투 수치 | [기반 성능·특성·34종 옵션·7단계 범위와 계산](../Systems/Equipment-Affixes-and-Combat-Numbers.md) |
| 드롭·파밍 대상 | [성급 구간·해금·목표 부위·옵션 생성](../Systems/Equipment-Drops-and-Farming-Targets.md) |
| 파밍 던전 변화 | [준비·패널티와 보상·수급·정산과 재접속](../Systems/Farming-Dungeon-Modification.md) |

## 다음 확인 묶음

[기본 제작의 실행·비용·확률·종료](../Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)를 확인하고 [제작 기획서](../Systems/Equipment-Crafting.md)에 통합했다. 장비 보관·비교·교체·분해는 [DEC-0100](../Decisions/DEC-0100-equipment-inventory-comparison-and-salvage.md)에서 확인했고 [장비 관리 기획서](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)에 통합했다. [DEC-0102](../Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md)에서 첫 제작은 기본 4종과 집중석부터 검증하는 A안으로 확인했다. 다음은 [고유 장비의 역할·획득·착용·처분](Unique-Equipment-Role-Acquisition-and-Handling.md)을 한 묶음으로 검토한다.

보호/특수 제작·자동/일괄 제작, 재료 교환·다른 공급, 스킬/젬·캐릭터 성장과 실제 콘텐츠·경쟁의 후속 수치는 별도로 확인한다. 상세 순서는 [기획 순서](../01-Decision-Queue.md)를 따른다.

## 조사와 검증

[PoE 2 제작 연구](../../Research/Crafting/README.md)와 [출처·버전·라이선스](../../Research/Crafting/Sources.md), [제작 실행 조사](../../Research/2026-11-18-crafting-execution-costs-and-odds.md)를 연결한다. [PoE 1 장비·빌드 연구](../../Research/PoE1/README.md)는 조합·전환 조건과 공략 축적의 참조다.

현재 변경은 확인된 원칙의 문서 통합과 다음 제안 작성이다. 실제 제작·드롭·전투·저장 복원과 경제 검증은 별도이며 구현 전에 기술 조사·적용 범위·검증 계획을 제안한다. 비용·확률·콘텐츠 시간을 확인한 뒤 중간 완성과 종결 제작의 경로·소요 분포·긴 실패 연속과 다른 유효 결과의 가치를 검증한다.
