# 종결 장비 경쟁의 평가 기준과 세부 제안

확인된 방향은 [종결 장비를 통한 경쟁](../Decisions/DEC-0008-endgame-gear-competition.md)과 [빌드별 옵션 조합·등급·수치 완성](../Decisions/DEC-0010-endgame-definition.md)이다. 전투는 [완전 자동](../Decisions/DEC-0002-combat-control.md)으로 진행한다. 경쟁은 후속 [DEC-0053](../Decisions/DEC-0053-endgame-competition-centered-on-auto-combat-results.md)에 따라 자동 전투 성과를 중심으로 평가한다. 주 지표는 후속 [DEC-0054](../Decisions/DEC-0054-highest-stage-as-primary-competition-metric.md)에서 최고 도달 단계로 확인했다. 시간 제한은 후속 [DEC-0057](../Decisions/DEC-0057-separate-time-limit-for-each-competition-stage.md)에서 단계별 적용으로 확인했다. 아래에는 확인된 기준과 아직 미정인 재도전 시작 지점의 제안을 구분한다.

## 확인된 경쟁의 중심 기준

같은 도전에서 제작한 장비·스킬 조합이 낸 **자동 전투 성과를 중심으로 평가**한다. 사용자는 장비 자체의 완성도 점수와 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0053](../Decisions/DEC-0053-endgame-competition-centered-on-auto-combat-results.md)에 기록했다.

중심 기준은 자동 전투 성과이며 주 지표는 아래와 같이 최고 도달 단계로 확인했다. 구체적인 평가 조건·공식·보상과 장비 자체 점수의 보조 제공 여부는 별도 확인한다.

## 확인된 자동 전투 성과의 주 평가 지표

주 지표는 **최고 도달 단계**다. 점점 강해지는 도전을 어디까지 돌파했는지 비교한다. 사용자는 피해량·클리어 시간 대안과 비교해 최고 도달 단계를 선택했다. 확인 근거는 [DEC-0054](../Decisions/DEC-0054-highest-stage-as-primary-competition-metric.md)에 기록했다.

이번 결정은 주 지표까지다. 시간 제한을 단계별로 적용하는 원칙은 아래와 같이 확인했다. 기록으로 인정할 조건과 단계 구성·수·상한, 구체적인 시간과 실패·동률 처리 및 보조 지표의 도입 여부는 별도 확인한다. 무한 단계나 특정 보스·던전을 자동으로 채택하지 않는다.

## 확인된 단계 도전의 시간 제한 방식

**각 단계에 별도의 제한 시간을 적용**해 주어진 시간 안에 돌파해야 한다. 사용자는 세 대안 중 단계별 제한 시간을 선택했다. 확인 근거는 [DEC-0057](../Decisions/DEC-0057-separate-time-limit-for-each-competition-stage.md)에 기록했다.

이번 결정은 시간 제한의 적용 단위까지다. 구체적인 시간 수치와 모든 단계의 시간을 같게 둘지, 측정의 시작·정지 조건, 시간 초과와 실패 후 처리는 미정이다. 도전 전체의 공통 제한 시간을 함께 적용하는 구성은 채택하지 않았다.

## 다음 확인인 실패 후 재도전의 시작 지점

아래 두 안은 아직 승인되지 않은 제안이다. 시간 초과 등으로 단계를 돌파하지 못한 뒤 다시 도전할 때 어디서 시작할지 비교한다. 자동으로 재도전할지와 플레이어가 선택하는 방법은 별도로 확인한다.

| 대안 | 재도전의 시작 지점 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 실패한 단계에서 재도전 — 추천 | 막혔던 단계를 다시 도전할 수 있음 | 장비·스킬을 바꾼 효과를 빠르게 검증하고 낮은 단계 반복 부담을 줄일 수 있음. 매번 전체 등반 과정을 검증하는 구조는 아님 |
| 2안: 처음부터 다시 등반 | 재도전할 때 첫 단계부터 다시 진행 | 단계별로 다른 조건을 통과하는 전체 등반을 재검증할 수 있음. 이미 넘긴 단계를 반복하는 시간 부담이 생김 |

종결 장비 제작과 빌드 실험의 반복을 가볍게 연결하기 위해 **1안**을 권장한다. 새 조합을 준비한 뒤 막힌 단계를 곧바로 시험하는 경로를 제공할 수 있다. 2안은 전체 등반 과정의 성능을 매 도전마다 확인하는 방향이다.

이번 질문은 실패 후 재도전의 시작 지점까지다. 단계 접근 권한과 해금 유지 기간·시즌 초기화, 체력·스킬 재사용 시간 등의 초기화, 적·시간의 재설정, 재도전 비용·횟수와 보상·기록 인정은 별도 확인한다. 단계별 제한 시간의 수치와 동률 처리도 아직 정하지 않았다.

## 후속 확인 범위

도전 조건과 장비·스킬 외 캐릭터 성장 차이의 취급, 측정 구간과 입장·재도전 조건은 별도 확인한다. 같은 도전에서 비교한다는 결정만으로 캐릭터 능력치의 정규화나 특정 성장 요소의 배제를 확정하지 않는다.

순위표 형식, 시즌·초기화·보상, 직접 PvP·매칭과 거래소도 미정이다. 보조 장비 점수나 다른 경쟁 지표의 동시 제공은 별도 확인한다. 특정 게임의 경쟁 규칙이나 실제 수치를 도입하지 않는다.

## 검증 계획

재도전과 도전 조건을 확인받은 뒤 서로 다른 장비·스킬 조합의 사례를 만들고, 단계별 제한 시간 안에서 제작으로 바뀐 옵션과 최고 도달 단계의 차이를 설명할 수 있는지 검토한다. 평가 조건과 수치를 합의한 뒤에 실제 전투 실험이나 점수 비교를 수행한다. 현재는 제안 문서만 작성하며 경쟁 시스템이나 평가 수치를 구현하지 않는다.
