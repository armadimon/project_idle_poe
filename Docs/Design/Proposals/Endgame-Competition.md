# 종결 장비 경쟁의 평가 기준과 세부 제안

확인된 방향은 [종결 장비를 통한 경쟁](../Decisions/DEC-0008-endgame-gear-competition.md)과 [빌드별 옵션 조합·등급·수치 완성](../Decisions/DEC-0010-endgame-definition.md)이다. 전투는 [완전 자동](../Decisions/DEC-0002-combat-control.md)으로 진행한다. 경쟁은 후속 [DEC-0053](../Decisions/DEC-0053-endgame-competition-centered-on-auto-combat-results.md)에 따라 자동 전투 성과를 중심으로 평가한다. 주 지표는 후속 [DEC-0054](../Decisions/DEC-0054-highest-stage-as-primary-competition-metric.md)에서 최고 도달 단계로 확인했다. 아래에는 확인된 기준과 아직 미정인 도전 시간 제한의 제안을 구분한다.

## 확인된 경쟁의 중심 기준

같은 도전에서 제작한 장비·스킬 조합이 낸 **자동 전투 성과를 중심으로 평가**한다. 사용자는 장비 자체의 완성도 점수와 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0053](../Decisions/DEC-0053-endgame-competition-centered-on-auto-combat-results.md)에 기록했다.

중심 기준은 자동 전투 성과이며 주 지표는 아래와 같이 최고 도달 단계로 확인했다. 구체적인 평가 조건·공식·보상과 장비 자체 점수의 보조 제공 여부는 별도 확인한다.

## 확인된 자동 전투 성과의 주 평가 지표

주 지표는 **최고 도달 단계**다. 점점 강해지는 도전을 어디까지 돌파했는지 비교한다. 사용자는 피해량·클리어 시간 대안과 비교해 최고 도달 단계를 선택했다. 확인 근거는 [DEC-0054](../Decisions/DEC-0054-highest-stage-as-primary-competition-metric.md)에 기록했다.

이번 결정은 주 지표까지다. 기록으로 인정할 조건과 단계 구성·수·상한, 시간 제한과 실패·동률 처리, 보조 지표의 도입 여부는 별도 확인한다. 무한 단계나 특정 보스·던전을 자동으로 채택하지 않는다.

## 다음 확인인 단계 도전의 시간 제한 방식

아래 세 안은 아직 승인되지 않은 제안이다. 최고 도달 단계를 비교할 도전에서 시간 제한을 어디에 적용할지 선택한다. 서로 다른 시간 제한을 함께 적용하는 안을 자동으로 채택하지 않는다.

| 대안 | 시간 제한의 범위 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 단계별 제한 시간 — 추천 | 각 단계에 별도의 제한 시간을 적용해 시간 안에 돌파했는지 판정 | 공격과 생존을 함께 활용하는 단계 돌파를 설계하기 좋음. 단계별 시간과 초과 시 처리를 정해야 함 |
| 2안: 도전 전체 공통 시간 | 한 번의 도전에 공통 제한 시간을 두고 그 안의 최고 도달 단계 비교 | 한 번의 도전 길이를 묶을 수 있고 여러 단계를 빠르게 통과하는 성능이 중요해짐. 앞 단계의 이동·대기·전투 시간이 결과에 미치는 영향을 검토해야 함 |
| 3안: 시간 제한 없음 | 별도의 제한 시간 없이 단계 돌파를 시도 | 느리지만 튼튼한 조합도 활용할 수 있음. 긴 전투나 진행이 멈춘 상황의 처리가 필요함 |

한 단계의 돌파 성능을 기준으로 장비·스킬 조합을 검토하고, 지나치게 오래 버티는 전투를 구분하기 위해 **1안**을 권장한다. 전체 도전의 진행·재시작·이어하기 방식은 따로 확인한다.

이번 질문은 시간 제한의 적용 방식까지다. 구체적인 시간 수치, 모든 단계의 시간을 같게 둘지, 측정의 시작·정지 조건과 시간 초과·실패 후 행동은 별도 확인한다. 재도전 비용·횟수와 단계 기록 인정·동률 처리, 중단과 이어하기도 아직 정하지 않았다.

## 후속 확인 범위

도전 조건과 장비·스킬 외 캐릭터 성장 차이의 취급, 측정 구간과 입장·재도전 조건은 별도 확인한다. 같은 도전에서 비교한다는 결정만으로 캐릭터 능력치의 정규화나 특정 성장 요소의 배제를 확정하지 않는다.

순위표 형식, 시즌·초기화·보상, 직접 PvP·매칭과 거래소도 미정이다. 보조 장비 점수나 다른 경쟁 지표의 동시 제공은 별도 확인한다. 특정 게임의 경쟁 규칙이나 실제 수치를 도입하지 않는다.

## 검증 계획

도전 조건을 확인받은 뒤 서로 다른 장비·스킬 조합의 사례를 만들고, 제작으로 바뀐 옵션과 최고 도달 단계의 차이를 설명할 수 있는지 검토한다. 평가 조건과 수치를 합의한 뒤에 실제 전투 실험이나 점수 비교를 수행한다. 현재는 제안 문서만 작성하며 경쟁 시스템이나 평가 수치를 구현하지 않는다.
