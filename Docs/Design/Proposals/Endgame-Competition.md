# 종결 장비 경쟁의 평가 기준과 세부 제안

확인된 방향은 [종결 장비를 통한 경쟁](../Decisions/DEC-0008-endgame-gear-competition.md)과 [빌드별 옵션 조합·등급·수치 완성](../Decisions/DEC-0010-endgame-definition.md)이다. 전투는 [완전 자동](../Decisions/DEC-0002-combat-control.md)으로 진행한다. 경쟁은 후속 [DEC-0053](../Decisions/DEC-0053-endgame-competition-centered-on-auto-combat-results.md)에 따라 자동 전투 성과를 중심으로 평가한다. 아래에는 확인된 기준과 아직 미정인 주 평가 지표의 제안을 구분한다.

## 확인된 경쟁의 중심 기준

같은 도전에서 제작한 장비·스킬 조합이 낸 **자동 전투 성과를 중심으로 평가**한다. 사용자는 장비 자체의 완성도 점수와 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0053](../Decisions/DEC-0053-endgame-competition-centered-on-auto-combat-results.md)에 기록했다.

이번 결정은 중심 평가 기준까지다. 특정 전투 지표·평가 공식·보상이나 장비 자체 점수를 보조 지표로 제공하는 구성은 아직 채택하지 않았다.

## 다음 확인인 자동 전투 성과의 주 평가 지표

아래 세 안은 아직 승인되지 않은 제안이다. 자동 전투 성과 중 무엇을 주로 비교할지 선택한다. 서로 다른 지표를 합산하거나 여러 경쟁 모드를 함께 제공하는 안을 자동으로 채택하지 않는다.

| 대안 | 주로 비교할 성과 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 최고 도달 단계 — 추천 | 점점 강해지는 도전을 어디까지 돌파했는지 | 공격과 생존·조합을 함께 활용하는 도전으로 설계하기 좋음. 단계별 조건과 같은 단계에 도달한 기록의 처리를 정해야 함 |
| 2안: 제한 시간 내 누적 피해량 | 같은 시험 대상을 상대로 정해진 시간 안에 준 피해량 | 결과 수치가 명확하고 장비 변경의 차이를 비교하기 쉬움. 공격 성능에 비중이 쏠릴 수 있어 시험 대상과 생존 조건을 검토해야 함 |
| 3안: 같은 도전의 클리어 시간 | 동일한 도전을 얼마나 빨리 완료했는지 | 완료 속도의 개선을 직관적으로 비교할 수 있음. 실패·미완료 기록과 상위권의 작은 시간 차이를 처리해야 함 |

종결 장비 제작과 빌드 실험의 목표를 공격 성능뿐 아니라 도전 돌파로 연결하기 위해 **1안**을 권장한다. 이 장점은 실제 단계별 전투 조건을 설계하고 검증해야 확인할 수 있다.

이번 질문은 주 평가 지표의 선택까지다. 1안의 도전 시간·단계 구성·실패 처리, 2안의 대상·제한 시간·피해 계산, 3안의 도전 구성·시간 측정과 각 안의 동률 처리는 별도 확인한다. 특정 보스·던전이나 수치를 이번 제안으로 채택하지 않는다.

## 후속 확인 범위

도전 조건과 장비·스킬 외 캐릭터 성장 차이의 취급, 측정 구간과 입장·재도전 조건은 별도 확인한다. 같은 도전에서 비교한다는 결정만으로 캐릭터 능력치의 정규화나 특정 성장 요소의 배제를 확정하지 않는다.

순위표 형식, 시즌·초기화·보상, 직접 PvP·매칭과 거래소도 미정이다. 보조 장비 점수나 다른 경쟁 지표의 동시 제공은 별도 확인한다. 특정 게임의 경쟁 규칙이나 실제 수치를 도입하지 않는다.

## 검증 계획

주 평가 지표를 확인받은 뒤 서로 다른 장비·스킬 조합의 사례를 만들고, 제작으로 바뀐 옵션과 결과의 차이를 설명할 수 있는지 검토한다. 평가 조건과 수치를 합의한 뒤에 실제 전투 실험이나 점수 비교를 수행한다. 현재는 제안 문서만 작성하며 경쟁 시스템이나 평가 수치를 구현하지 않는다.
