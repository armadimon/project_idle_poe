# 종결 장비 경쟁의 중심 평가 기준 제안

확인된 방향은 [종결 장비를 통한 경쟁](../Decisions/DEC-0008-endgame-gear-competition.md)과 [빌드별 옵션 조합·등급·수치 완성](../Decisions/DEC-0010-endgame-definition.md)이다. 전투는 [완전 자동](../Decisions/DEC-0002-combat-control.md)으로 진행한다. 아래 두 안은 이 방향을 구체화하기 위한 제안이며 아직 승인되지 않았다.

## 다음 확인인 경쟁의 중심 기준

| 대안 | 주로 비교할 것 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 자동 전투 성과 — 추천 | 같은 도전 조건에서 제작한 장비와 스킬 조합이 낸 전투 성과 | 장비 제작과 빌드 조합이 실제 플레이에서 유효한지를 경쟁과 연결할 수 있음. 전투 규칙과 도전 조건의 차이를 함께 검증해야 함 |
| 2안: 장비 자체의 완성도 | 옵션 구성·등급·수치 완성도를 평가한 장비 점수 | 제작한 장비의 완성도를 직접 비교할 수 있음. 빌드마다 다른 옵션의 가치를 점수에 반영하는 기준이 필요함 |

장비·스킬 조합을 실험하고 제작한 장비의 성능을 실제 자동 전투에서 확인하는 경험을 연결하기 위해 **1안**을 권장한다. 2안은 제작 완성도를 경쟁의 직접적인 평가 대상으로 삼는 방향이다.

이번 질문은 경쟁의 중심 평가 기준까지다. 두 방식을 동시에 제공하는 안이나 보조 경쟁 지표를 자동으로 채택하지 않는다.

## 선택 후 확인할 내용

1안을 선택하면 피해량·클리어 시간·도달 단계 중 무엇을 평가할지, 도전 조건과 장비·캐릭터 성장 차이의 취급, 측정 시간과 실패 처리를 후속으로 확인한다. 이번 제안은 그중 특정 지표나 보스 콘텐츠를 채택한 것이 아니다.

2안을 선택하면 장비 한 개와 장착 구성 중 평가 단위, 빌드별 옵션 가치와 등급·수치의 가중치, 같은 점수의 처리와 평가 공식을 후속으로 확인한다. 아직 정하지 않은 공식을 임의로 구현하지 않는다.

두 안 모두 순위표 형식, 시즌·초기화·보상, 직접 PvP·매칭과 거래소는 별도 확인한다. 특정 게임의 경쟁 규칙이나 실제 수치를 도입하지 않는다.

## 검증 계획

중심 기준을 확인받은 뒤 서로 다른 장비·스킬 조합의 사례를 만들고, 제작으로 바뀐 옵션과 결과의 차이를 설명할 수 있는지 검토한다. 평가 조건과 수치를 합의한 뒤에 실제 전투 실험이나 점수 비교를 수행한다. 현재는 제안 문서만 작성하며 경쟁 시스템이나 평가 수치를 구현하지 않는다.
