# 첫 고유 3종의 효과·수치·중복과 빌드 검증 확인 결과

사용자는 직전 요약과 상세 조건 전체를 “응 진행해줘”로 확인했다. 승인 기록은 [DEC-0105](../Decisions/DEC-0105-first-unique-effects-stacking-and-build-goals.md), 현행 정의와 적용 순서는 [고유 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다.

안정의 목걸이·속행의 반지·불굴의 허리띠의 기반/일반 성능과 특수 효과, 4/5성 고정값·혼합 성급, 동일 고유 복수 착용·증가 합산/감폭 곱셈·치명타/보호막 무효·장착 상태를 한 묶음으로 확인했다. 세 빌드 검증 목표와 무고유 희귀 구성의 비교도 기능 기획서를 따른다.

[조사](../../Research/2026-11-19-unique-effects-stacking-and-build-cases.md)에 출처·버전·권리·호환성과 재사용 범위를 기록했다. 문서 구조·정의·산술 확인을 실제 고유의 Unity 전투/저장·PoB 실행·경제/모바일 사용성 검증으로 취급하지 않는다. 구현 전 기술 조사와 적용·검증 계획은 별도로 제안한다.

후속 정식 스킬·젬 성장/획득·캐릭터 구성, 몬스터·파밍 시간과 콘텐츠는 [기획 순서](../01-Decision-Queue.md)의 남은 범위다. 기존 고유 드롭·분해·제작 불가의 공통 규칙은 유지하며 추가 고유/효과와 후속 변경도 다시 확인받는다.
