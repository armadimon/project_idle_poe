# 장비 편성·기반 구조 제안 결과

사용자가 묶음 전체에 “오케이 진행해줘”라고 답했다. 승인 기록은 [DEC-0096](../Decisions/DEC-0096-equipment-catalog-and-base-structure.md)이며 현재 규칙은 [장비 편성·기반 구조 기획서](../Systems/Equipment-Catalog-and-Base-Structure.md)에 모았다.

확정 범위는 장비 10칸·첫 무기 3계열과 장착 조합, 계열별 기반 3종의 역할·고정 특성 1개와 수치 고정/기본 제작 변경 불가, 모든 성급에서 기반 역할 유지·같은 계열 후보 공유와 파밍 연결이다.

[옵션·전투 계산과 수치표](../Systems/Equipment-Affixes-and-Combat-Numbers.md)는 [DEC-0097](../Decisions/DEC-0097-equipment-affixes-base-stats-and-combat-numbers.md)에서 확인했다. 제작 실행·비용·확률·종료는 [DEC-0098](../Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)에서 확인했고 [기본 제작 기획서](../Systems/Equipment-Crafting.md)에 모았다. 장비 보관·비교·교체·분해는 [DEC-0100](../Decisions/DEC-0100-equipment-inventory-comparison-and-salvage.md)에서 확인했고 [장비 관리 기획서](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)에 통합했다. [DEC-0102](../Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md)에서 첫 제작은 기본 4종과 집중석부터 검증하는 A안으로 확인했다. 다음은 [고유 장비의 역할·획득·착용·처분](Unique-Equipment-Role-Acquisition-and-Handling.md)을 한 묶음으로 검토한다.

기획 승인은 게임 구현이나 밸런스 검증 완료를 뜻하지 않는다. [장비 분류 조사](../../Research/2026-11-18-equipment-catalog-and-affix-data.md)와 기능 기획서의 검증 계획을 함께 읽는다.
