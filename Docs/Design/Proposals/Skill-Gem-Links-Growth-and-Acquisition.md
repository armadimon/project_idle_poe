# 정식 스킬·젬의 연결·성장·획득 제안

**상태: 사용자 확인 전 제안 · 2026-11-19.** 사용자의 “오케이 진행하자”는 다음 기획 묶음 작성 요청으로 기록한다. 아래의 새 규칙을 승인받았다는 뜻으로 사용하지 않는다. [사전 조사](../../Research/2026-11-19-skill-gem-links-growth-and-acquisition.md)

이번에는 **젬을 어떻게 제공하고, 어디에 연결하며, 무엇을 통해 성장시키는가**를 한 번에 확인한다. 개별 스킬의 피해표·전투 실행·자원과 패시브는 다음 기능 묶음으로 남긴다.

## 출발점과 이번에 선택할 차이

확인된 방향은 [라이트한 PoE와 종결 장비 제작](../00-Concept.md), [장비·스킬의 PoE 1 참조](../Decisions/DEC-0005-poe1-reference.md)다. 별도로 승인된 로컬 프로토타입에는 네 클래스·다섯 무기·액티브 13종·보조 4종과 **액티브 3칸 × 각 보조 2칸**이 있다. 그 구현 실험과 정식 성장·획득 규칙의 승인은 구분한다.

GGG 공식 소개에서 PoE 1 젬은 장비에 넣는 아이템이며 개별 성장과 거래 가치도 갖는다. 추천안은 **액티브를 보조로 변형하고 장비로 성립 조건·성능을 맞추는 관계**를 계승하되, 젬의 실물 아이템 관리와 개별 육성은 간소화하는 자체 설계다. PoE 1 규칙을 그대로 옮기는 선택이 아니다. [GGG 소개](https://www.pathofexile.com/game)

| 선택 방향 | 제공·성장·연결 | 얻는 경험과 부담 |
| --- | --- | --- |
| **1안 · 추천: 목록 제공 + 구간 공통 성장** | 첫 목록을 무료 제공. 액티브는 파밍 해금에 따라 함께 Lv.1~5, 보조는 고정. 캐릭터의 3×2 연결 | 다른 빌드를 바로 시험하고 장비 제작에 집중. 젬 자체를 줍고 따로 키우는 재미는 줄어듦 |
| 2안 · 대안: 목록 제공 + 젬별 경험치 | 무료 제공과 3×2는 유지하고 액티브마다 경험치를 쌓음 | 주력 젬 육성의 애착이 생김. 새 조합을 시험할 때 육성 격차와 추격 규칙이 필요 |
| 3안 · 대안: 장비 소켓 + 실물 젬 | 젬을 개별 아이템으로 보관·획득·육성하고 장비 소켓/링크에 배치 | PoE 1의 장비·젬 준비 경험에 가까움. 장비 교체 시 링크 재구성과 별도 젬 파밍·보관·제작 규칙이 늘어남 |

**이번에 바로 승인할 수 있는 상세 묶음은 아래의 1안이다.** 2·3안을 고르면 그 방향의 성장량·획득·보관·교체 규칙을 다시 한 묶음으로 제안한다. 표에 없는 수치나 거래 경제까지 승인된 것으로 처리하지 않는다.

## 1안의 연결·획득 규칙

| 항목 | 제안할 규칙 |
| --- | --- |
| 첫 제공 | 처음 로비에 진입하면 액티브 13종·보조 4종을 계정의 젬 목록에 모두 무료로 제공. 현재 클래스·무기로 사용할 수 있는 젬부터 고름 |
| 제공과 사용의 구분 | 목록에 있어도 클래스·무기 관계와 능력치 조건을 충족해야 사용 가능. 안내 튜토리얼은 기존 연결·실제 명중 과정을 유지하며 나머지 젬을 보상 추첨으로 잠그지 않음 |
| 연결 자리 | 캐릭터에 액티브 최대 3개, 액티브마다 호환 보조 최대 2개. 장비마다 별도 소켓을 두지 않음 |
| 빈칸과 중복 | 빈칸 허용, 두 보조를 모두 채워야 하는 조건이나 완성 보너스 없음. 같은 액티브는 현재 편성에서 1개만 사용. 같은 보조는 한 액티브에 1개, 서로 다른 액티브에는 반복 연결 가능 |
| 교체 | 로비에서 무료 변경. 액티브를 바꾸면 호환 보조를 유지하고 비호환 보조만 해제하며 그 내용을 적용 전에 알림. 젬 목록에서 사라지거나 소비되지 않음 |
| 클래스 전환 | 기존 네 클래스의 무료 로비 전환과 클래스별 무기·3×2 편성 기억을 유지. 목록과 성장 단계는 계정에서 공유 |
| 사용 조건 | 검·도끼·망치 계열 액티브는 힘 20, 활은 민첩 20, 마법봉 주문은 지능 20을 첫 정식 요구치로 제안. 보조는 별도 능력치 요구 없음. 능력치는 숨은 피해 보너스 없이 기존 역할 유지 |
| 조건의 안정성 | 액티브 성장 단계가 올라가도 요구 능력치 20은 유지. 무기 변경·제작 등으로 조건을 잃으면 기존 연결을 보관하고 사용만 중지, 조건을 회복하면 다시 사용. 새로 연결하려는 젬은 부족 사유를 표시하고 거부 |
| 파밍과 보관 | 젬 실물 드롭·중복 수량·분해·판매·거래를 첫 범위에 두지 않음. 젬 목록은 장비 가방 500칸을 사용하지 않으며 장비/재료 보상 추첨에 끼어들지 않음 |
| 별도 준비 | 첫 범위에 젬 퀄리티·희귀도·타락·장비 소켓 수/색/링크 제작·연결 재료를 추가하지 않음 |

위의 **20은 기존 프로토타입 실험값에서 가져온 이번 정식 제안 수치**다. 이전에 정식 승인된 수치로 소급하지 않는다. 캐릭터의 기본 능력치를 비교용 10 또는 프로토타입의 5로 확정하는 제안도 아니다. 요구치를 고정하면 엔드게임에서 능력치 추가 확보의 가치는 낮아질 수 있다. 첫 범위에서는 장비의 피해·방어·재사용과 고유 효과 조합을 주된 제작 판단으로 삼고 그 한계를 검증한다.

## 1안의 성장 규칙

**액티브 Lv. = 계정에서 해금한 가장 높은 파밍 구간(1~5).** 장착한 장비의 성급이나 현재 입장한 던전으로 결정하지 않는다. 기존 [파밍 구간 해금](../Systems/Equipment-Drops-and-Farming-Targets.md)을 사용하고 새로운 경험치·재료·별도 성장 버튼을 추가하지 않는다.

| 계정 진행 | 모든 액티브 |
| --- | --- |
| 처음 시작, 1성 구간만 해금 | Lv.1 |
| 1성 첫 완주 → 2성 해금 | Lv.2 |
| 2성 첫 완주 → 3성 해금 | Lv.3 |
| 3성 첫 완주 → 4성 해금 | Lv.4 |
| 4성 첫 완주 → 5성 해금 | Lv.5, 첫 범위의 최대 |

패널티 유무와 관계없이 유효한 첫 완주를 인정한다. 실패·포기·경쟁 도전만으로는 구간을 해금하지 않는다. 같은 완주를 중복 정산해 추가 단계를 주지 않으며 이전 구간으로 돌아가거나 클래스를 바꾸어도 내려가지 않는다. 뒤늦게 바꾼 액티브와 비장착 액티브도 같은 Lv.를 쓴다. 기존 저장을 반영할 때도 보유 장비 성급으로 추정하지 않고 실제 구간 해금 기록을 기준으로 한다.

Lv.가 올라가면 공격 젬의 무기 피해 계수 또는 주문 젬의 기본 피해가 증가하도록 개별 표를 설계한다. 범위·투사체 수·타격 횟수·재사용·행동 규칙은 이 공통 성장으로 바꾸지 않는다. **각 Lv.의 실제 피해 수치는 후속 스킬·전투 묶음의 미정 값**이며 프로토타입 계수를 정식 수치로 채택하지 않는다. 보조 4종은 개별 Lv.나 성장 수치 없이 고정 효과를 쓴다. 그 고정 효과의 정식 수치도 같은 후속 묶음에서 확인한다.

이렇게 하면 5성 진입 시 젬 성장은 완료되고, 이후의 주된 성장은 [희귀 장비 제작](../Systems/Equipment-Crafting.md)과 [고유 효과의 조합](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에서 나온다. 실험 시작은 쉬워지지만 젬별 장기 육성이 사라지므로 이 구조가 제작 동기를 충분히 남기는지 실제 플레이로 확인해야 한다.

## 게임 안에서 알려 줄 내용

젬 목록에는 현재 Lv.와 다음 상승 조건, 요구 능력치의 현재/필요 값, 사용 가능한 무기, 호환 보조와 연결 후 변경 내용을 표시한다. 예를 들면 “Lv.3 · 3성 구간 해금으로 성장 / 다음: 3성 첫 완주”, “힘 17/20 · 현재 사용 불가”다. 장비 교체·제작 미리보기에서도 사용이 멈추거나 다시 가능해지는 액티브를 보여 준다.

현재 장비의 성급을 올려 젬을 강화한다고 오해하지 않게 장비의 ★와 젬의 Lv.를 구별해 설명한다. 요구치·보조 호환·다음 성장 조건을 알아보기 위해 외부 공략을 찾아야 하는 상태를 피하는 정보 요건이다. 화면 배치·그래픽 시안의 승인은 아니다.

## 적용 범위와 검증 계획

1안 승인 시 정식 스킬·젬 기능 기획서와 결정 파일 하나에 연결·제공·성장·요구치·교체·보관 범위를 통합한다. 이 문서 작성만으로 Unity 구현을 요청받은 것으로 처리하지 않는다.

문서 검사는 링크와 기존 파밍/가방/옵션 규칙의 관계를 확인한다. 구현 단계에서는 별도의 기술 적용 계획을 세운 뒤 다음을 실행 검증한다.

1. 첫 제공 13+4종, 각 무기의 호환과 3×2 상한, 빈칸·동일 액티브·보조 중복 규칙.
2. 네 클래스의 전환·편성 복원, 무료 교체와 비호환 보조 해제, 목록/가방/재료 보상의 독립성.
3. 첫 완주 → 다음 구간 → 전 액티브 Lv. 상승, 실패·반복 정산·하위 구간·비장착·클래스 전환·저장 복구 경계.
4. 요구 능력치 19/20/21, 장착/제작 후 조건 상실과 복구. Lv. 상승 자체가 사용 중 젬을 막지 않는지 확인.
5. 실제 공격/주문의 단계별 피해와 고정 보조, 고유 중첩을 후속 승인 수치로 비교. 5성의 새 조합을 젬 육성 대기 없이 시험할 수 있는지 직접 플레이.

**아직 하지 않은 검증:** 정식 성장 구현, Unity 실행, 모바일 기기, 성장 속도·전투 밸런스·재미. 이번 결과는 조사와 제안 문서이며 추천안이 확정됐다는 근거가 아니다.

## 다음에 함께 확인할 기능 묶음

- 스킬·보조의 정식 수치와 자동 전투 실행: 액티브 13종 × 5단계 피해, 보조 4종의 수치·손익과 동일 적 판정, 사거리·동작·재사용, 자동 선택 순서와 자원 사용 여부.
- 그 뒤 캐릭터 성장·패시브의 역할: 젬 요구 조건과 장비 제작 판단에 더할 범위. 첫 범위에 패시브를 넣을지부터 확인.

[이전 PoE 1 적용 논의](PoE1-Equipment-Skills.md)의 소켓 색상 보너스는 승인 전 후보였다. 1안을 승인하면 첫 정식 범위에서는 해당 후보를 채택하지 않는 선택까지 포함한다. 추후 소켓/색상·젬 득템을 추가할 때에는 별도의 변경 묶음으로 다시 확인한다.
