# PoE 1의 장비와 스킬을 적용하기 위한 논의

사용자가 확인한 방향은 [종결 장비 제작 중심](../Decisions/DEC-0007-endgame-crafting.md)과 [장비·스킬의 PoE 1 방식](../Decisions/DEC-0005-poe1-reference.md)이다. 제작 작업은 [PoE 2](../Decisions/DEC-0009-poe2-crafting-reference.md)를 참조한다. 아래는 [빌드 조사](../../Research/PoE1/README.md)에 따른 후속 제안이며 세부 사양은 사용자 확인 전까지 미정이다.

제작·장비·첫 고유 효과의 승인에 이어 [정식 스킬·젬의 연결·성장·획득 묶음](Skill-Gem-Links-Growth-and-Acquisition.md)을 제안했다. 새 묶음은 사용자 확인 전이다. 아래의 초기 소켓/색상 후보는 이력으로 남기며 정식 채택으로 취급하지 않는다.

## 보존할 상호작용의 후보

장비에 놓은 젬과 연결된 보조 효과가 행동을 만들고, 장비 옵션과 다른 규칙이 그 행동의 적용 조건·효과·유지 방식을 바꾸는 구성을 우선 논의하자. 개별 스킬이나 유니크의 채택보다 어떤 종류의 상호작용을 제공할지 확인하는 단계다.

| 논의할 요소 | 실험에서 기대하는 차이 | 확인할 세부 범위 |
| --- | --- | --- |
| 스킬과 보조의 연결 | 같은 기본 스킬의 행동과 효율을 바꾸기 | 소켓·링크 구조, 적용 조건, 보조 비용 |
| 기반 장비와 옵션 조합 | 필요한 여러 역할을 부위별로 배분하기 | 장비 종류, 옵션 계열, 자리와 등급 |
| 규칙을 바꾸는 장비 효과 | 기존 부품을 새 방식으로 결합하기 | 효과 유형, 조건과 예외 |
| 발동과 유지 조건 | 성립 조건을 맞춰 다른 전투 패턴을 만들기 | 사건·주체·확률·자원·회복 규칙 |
| 단계별 교체 | 확보한 부품에 맞춰 구성을 전환하기 | 획득 흐름, 변경 비용, 시작 구성 |
| 실험 결과의 해석 | 바꾼 내용과 전투 차이의 원인을 이해하기 | 비교 정보, 기록·공유·진단 기능의 범위 |

## 적용 범위를 정하는 대안

| 접근 | 장점 | 비용과 제약 |
| --- | --- | --- |
| 전체 장비·젬·패시브 범위를 먼저 정함 | 완성 구조의 관계와 규모를 한 번에 검토할 수 있음 | 많은 규칙을 플레이 검증 전에 정하게 됨 |
| 한 빌드의 작동부터 범위를 정함 | 상호작용을 구체적으로 검토하기 쉬움 | 첫 빌드에 맞춰 공통 규칙을 좁힐 수 있음 |
| 공통 상호작용을 정하고 서로 다른 빌드 사례로 검토함 | 빌드 실험의 폭과 규칙의 일관성을 함께 평가할 수 있음 | 비교할 사례와 검증 기준을 먼저 합의해야 함 |

세 번째 접근을 권장한다. 서로 다른 조합에서 같은 규칙이 일관되게 작동하는지 확인하면서 시스템 범위를 정할 수 있기 때문이다. 어떤 빌드 사례를 쓸지와 구현 범위는 별도 확인한다.

## 후속 확인 사항인 소켓 색상의 역할

PoE 1도 패치에 따라 색상의 역할이 다르다. 3.29 공식 패치에서는 색 불일치 장착을 허용하고, 일치하는 유색 소켓에 퀄리티 보너스를 추가했다. 구체적인 수치와 원본 아이템 효과는 우리 게임 수치로 확정하지 않는다. [공식 패치](https://www.pathofexile.com/forum/view-thread/3985332)

| 선택지 | 플레이 경험 | 장단점 |
| --- | --- | --- |
| 색상을 장착 제약으로 사용 | 원하는 조합을 쓰기 전에 장비 색상도 맞춤 | 장비 준비에 의미를 줄 수 있지만 조합을 바꿔 보는 과정에 추가 비용이 생김 |
| 색상을 최적화 보너스로 사용 | 먼저 조합을 시험하고 색상은 추가 최적화 대상으로 다룸 | 교체 실험을 시작하기 쉬우며 색상 준비의 비중은 낮아짐 |

장비를 교체해 성능을 확인하기 쉬운 접근으로는 **보너스 방식**을 권장한다. 소켓 준비가 제작과 장비 비교에서 차지할 비중을 검토한 뒤 선택한다. 색상 보너스의 종류·수치·획득 방식은 별도 제안 대상이다.

## 검증 계획의 후보

세부 규칙과 구현 범위를 확인받으면 다음을 검증하자.

1. 연결한 보조 효과가 허용된 대상에만 적용되는지 확인한다.
2. 장비 교체로 새로 성립하거나 깨지는 조건을 설명할 수 있는지 확인한다.
3. 같은 규칙으로 구성한 서로 다른 빌드가 서로 다른 행동이나 장단점을 보이는지 확인한다.
4. 같은 버전·대상·활성 조건에서 교체 전후를 비교한다.
5. 전투 관찰로 얻는 판단과 계산 결과가 어긋나면 원인을 추적한다.

이 단계에서는 게임 코드·밸런스 공식·아이템 데이터·프로토타입을 추가하지 않는다. 이번에 수행하는 검사는 조사 문서와 승인 결정의 기록·링크 정합성이다.
