# 옵션·전투 계산·초기 수치표 제안 결과

사용자가 핵심 규칙과 상세 수치표 전체를 “오케이 진행해줘”로 확인했다. 승인 기록은 [DEC-0097](../Decisions/DEC-0097-equipment-affixes-base-stats-and-combat-numbers.md)이며, 현재 규칙과 수치표는 [기능 기획서](../Systems/Equipment-Affixes-and-Combat-Numbers.md)에 모았다.

승인 범위는 기반 성능·고정 특성 수치, 접두 19종·접미 15종과 계열별 후보, 7단계 정수 범위·일부 겹침, 공격/주문·무기/캐릭터 적용과 합산/곱셈, 치명타·속도/CD·능력치·명중도·방어·보호막·회복의 초기 규칙이다.

수치표를 비교할 캐릭터·주문 예시는 실제 성장·직업·모든 젬의 기본값으로 확대하지 않는다. 문서 승인은 게임 구현·전투·경제 검증 완료와 구분한다.

제작 재료·비용·확률·실행과 종료는 [DEC-0098](../Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)에서 확인했고 [기본 제작 기획서](../Systems/Equipment-Crafting.md)에 모았다. 장비 보관·비교·교체·분해는 [DEC-0100](../Decisions/DEC-0100-equipment-inventory-comparison-and-salvage.md)에서 확인했고 [장비 관리 기획서](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)에 통합했다. [DEC-0102](../Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md)에서 첫 제작은 기본 4종과 집중석부터 검증하는 A안으로 확인했다. 고유 공통 규칙은 [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)의 2안(B)으로 확인했고 [기능 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다. 첫 고유 효과·수치·중복과 빌드 검증 목표는 [DEC-0105](../Decisions/DEC-0105-first-unique-effects-stacking-and-build-goals.md)에서 확인했고 [고유 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다. 후속 정식 스킬·젬 성장과 콘텐츠는 [기획 순서](../01-Decision-Queue.md)에서 확인한다.
