# 옵션·전투 계산·초기 수치표 제안 결과

사용자가 핵심 규칙과 상세 수치표 전체를 “오케이 진행해줘”로 확인했다. 승인 기록은 [DEC-0097](../Decisions/DEC-0097-equipment-affixes-base-stats-and-combat-numbers.md)이며, 현재 규칙과 수치표는 [기능 기획서](../Systems/Equipment-Affixes-and-Combat-Numbers.md)에 모았다.

승인 범위는 기반 성능·고정 특성 수치, 접두 19종·접미 15종과 계열별 후보, 7단계 정수 범위·일부 겹침, 공격/주문·무기/캐릭터 적용과 합산/곱셈, 치명타·속도/CD·능력치·명중도·방어·보호막·회복의 초기 규칙이다.

수치표를 비교할 캐릭터·주문 예시는 실제 성장·직업·모든 젬의 기본값으로 확대하지 않는다. 문서 승인은 게임 구현·전투·경제 검증 완료와 구분한다.

다음은 [제작 재료·비용·확률·실행과 종료](Crafting-Execution-Costs-and-Odds.md)를 한 묶음으로 검토한다. 해당 제작 세부 규칙은 아직 승인되지 않았다.
