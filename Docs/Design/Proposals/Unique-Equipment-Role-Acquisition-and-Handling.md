# 고유 장비의 역할·획득·착용·처분 묶음 제안

상태: **전체 미승인**. 희귀 장비는 제작으로 옵션 조합·단계·수치를 완성하고, 고유 장비는 정해진 특수 효과를 제공한다는 [선행 방향](../Decisions/DEC-0012-crafting-equipment-scope.md)을 구체화한다. [첫 제작 모델](../Systems/Equipment-Crafting.md)에 고유 장비 제작을 추가하는 안은 아니다.

## 추천 묶음

| 항목 | 제안 |
| --- | --- |
| 역할 | 전투 규칙·스킬 활용을 바꾸는 선택형 장비. 고유 획득을 입장·성급 해금의 필수 조건으로 두지 않음 |
| 첫 목록 | 목걸이·반지·허리띠에 각각 1종, 총 3종. 각 고유를 4성·5성으로 제공 |
| 옵션 구조 | 고유별 정해진 기반 성능과 일반 옵션 2개+특수 효과 1개. 같은 고유·성급의 모든 값 고정, 무작위 접두/접미 추첨 없음 |
| 성급·제작 | 획득 성급 고정·승급/옵션 이전 없음. 5성은 일반 성능을 높이고 특수 효과의 규칙·수치는 4성과 동일. 기본 4종 제작과 집중석 사용 불가 |
| 장착 | 전체 장비에서 고유 최대 1개. 전투 밖 무료 장착·해제, 부위 외 별도 성급/레벨/능력치 착용 제한 없음 |
| 획득 | 4~5성의 목걸이·반지·허리띠 파밍 장비 보상 1개마다 희귀 97%·해당 부위 고유 3%. 기본·모딩 추가 장비 추첨에 동일 적용 |
| 보상 개수 | 희귀 보상의 일부를 고유로 대체. 별도 추가 장비 지급 없음·기존 최대 장비 2개와 입장 공간 1/2칸 유지 |
| 추첨·정보 | 추첨별 독립, 중복 획득 허용·천장 없음. 대상/성급·97/3%·특수 효과와 고정값을 게임 안에 공개 |
| 보관·보호 | 기존 무료 500칸 안에서 1개=1칸. 획득 시 분해 보호 기본 해제, 장착/보호 장비는 분해 금지 |
| 분해 | 미장착·보호 해제된 고유는 무료 단건 분해만. 기존 제작재료 1회 추첨·1개, 30/15/35/15/5%. 일괄 분해·전체 선택에서는 고유 제외 |

첫 고유의 이름·기반/일반 성능 수치·특수 효과와 수치는 이번 확인 대상이 아니다. 공통 규칙을 확인한 뒤 **서로 다른 빌드 목표와 세 고유의 실제 효과·수치를 함께 제안**하고 다시 확인받는다. 고유의 효과를 미리 승인하거나 어떤 직업/스킬에서도 유효하다고 가정하지 않는다.

## 역할·구조와 장착

일반 옵션 2개는 고유별로 정해진 종류와 고정값을 사용하고 희귀 장비의 무작위 6칸 추첨과 구분한다. 고유의 기반·일반 성능은 정의표에 등록할 값이며 이번에 기존 희귀 기반 목록/옵션 범위를 변경하지 않는다. 고유를 희귀로 변환하거나 희귀에서 고유로 승급시키는 작업은 추가하지 않는다.

전투 중에는 고유 장착·해제·분해를 실행하지 않는다. 같은 부위의 고유를 다른 고유로 바꾸는 것은 교체 후 고유 1개인지 검사해 함께 처리한다. 다른 부위에 두 번째 고유를 장착하려 하면 변경 없이 제한과 현재 고유 위치를 안내한다. 먼저 기존 고유를 무료 해제하며 가방 빈 칸 1개가 필요하다. 공간이 없으면 정리 경로를 안내한다. 기존의 반지 교체 칸 선택·장비 수량 보존·젬 조건 재평가를 함께 따른다.

비교에는 일반 수치 변화와 새로 생기거나 사라질 특수 효과를 표시한다. 계산 데이터가 아직 없는 효과는 미정 사유를 안내하고 수치 0으로 대신하지 않는다. 특정 고유가 없어도 파밍·경쟁에 입장할 수 있으며 최고 도달 성과에 주는 영향은 후속 빌드/전투 검증에서 확인한다.

## 획득과 기존 규칙 변경 범위

현재 [희귀 드롭 기획](../Systems/Equipment-Drops-and-Farming-Targets.md)은 희귀만 생성한다. 이 제안이 승인되면 **4~5성·위 3부위에 한해** 장비 보상 생성 앞에 희귀 97%/고유 3% 판정을 추가하는 변경이다. 희귀가 선택된 뒤 기반·옵션 개수·종류·단계·값의 기존 조건부 분포는 그대로 사용한다.

고유가 선택되면 해당 부위의 첫 고유 1종을 구간과 같은 성급으로 준다. 따라서 목걸이를 목표로 파밍할 때 고유 반지를 지급하지 않는다. 1~3성이나 다른 부위는 기존 희귀 100%를 유지한다. 고유 목록 확장·경쟁/오프라인 지급·구매/교환 경로는 별도 확인 사항이다.

모딩은 기존대로 패널티 수×20% 확률로 장비를 한 번 더 추첨한다. 추가 장비도 희귀/고유 97/3%를 따르므로 모딩은 고유를 뽑을 기회도 늘리되 개별 장비의 3% 확률은 올리지 않는다. 재료 보상·모딩 준비 비용은 바꾸지 않는다. 파밍 실패/포기에는 해당 도전의 장비·재료 보상을 지급하지 않는 규칙을 유지한다.

고유를 직접 추가 지급하지 않아 장비 보상은 기본 1개·모딩 포함 최대 2개다. 기존 입장 전 빈 칸 1/2개 조건과 준비/전투 중단·1회 정산을 따른다. 천장 없는 독립 추첨이므로 획득 시점과 중복 횟수는 보장하지 않는다.

## 분해·취소와 복원

현재 [분해 규칙](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)은 희귀만 허용하고 고유를 제외한다. 이 안은 고유의 **단건 분해만** 추가하고 일괄 분해·필터 결과 전체 선택에서는 계속 제외하는 변경이다. 고유를 볼 수 있는 희귀/고유 필터를 추가하되 필터 변경만으로 처분 대상을 자동 선택하지 않는다.

단건 확인에는 실제 장비·고유 표시·특수 효과·분해 재료 확률을 보여 준다. 4/5성·중복·보유 기간과 관계없이 부여/제거/교체/조율/집중석을 30/15/35/15/5%로 한 번 추첨한다. 고유 전용 분해 재료·과거 비용 환급·모딩 보너스 재적용은 추가하지 않는다.

확정 전 취소는 변경이 없고 확정 뒤 삭제와 보상을 함께 저장한다. 재접속으로 아이템/보상을 복제하거나 추첨을 다시 하지 않는다. 장착·해제도 한 번 적용한 결과를 복원한다. 저장/서버 방식과 UI 시안·아트는 별도 구현 전 조사·제안 범위다.

## 대안·권장 이유와 검증 계획

대안 B는 부위만 맞으면 여러 고유를 함께 장착하는 방식이다. 특수 효과 간 조합이 넓어지지만 희귀 제작을 맡길 자리와 효과 충돌/중첩 검증이 늘어난다. 대안 C는 첫 검증에서 고유를 보류하고 희귀 장비만으로 목표 빌드를 만드는 방식이다. 범위가 작아지는 대신 규칙을 바꾸는 장비를 통한 빌드 차이는 나중에 검토한다.

위 **3종·4/5성·고유 1개·고정 성능·장비당 3% 대체·단건 분해**를 A안으로 권한다. 고유 하나가 빌드의 방향을 만들고 나머지 장비는 희귀 제작으로 조건과 성능을 완성하도록 역할을 나누려는 제안이다. 개별 효과가 정해지기 전에는 실제 재미·필수성·획득 속도·균형을 판단할 수 없다.

[고유 장비 조사](../../Research/2026-11-19-unique-equipment-role-acquisition-and-handling.md)에 GGG·PoEDB·커뮤니티·고정 PoB의 출처·버전·권리·Unity 호환성·재사용 제약을 기록했다. 장착 한도·성급·확률·분해 등 위 값은 자체 미승인 제안이며 PoE의 규칙/수치를 반입한 것이 아니다.

공통 규칙과 개별 효과/수치를 확인한 뒤 구현 전 기술 조사·적용·검증 계획을 제안한다. 후속 검증 범위는 허용 구간/부위·희귀 조건부 분포·기본/모딩 일치·보상 최대량·1개 제한/교체·수량 보존/젬 재평가·단건과 일괄 분해 경계·취소/중단·1회 정산이다. 목표 빌드·파밍 시간을 정한 뒤 희귀 교체의 가치와 고유 유무/성급별 성능·수급/긴 미획득 연속을 비교한다. 현재는 기획과 문헌/산술 확인이며 Unity 구현·PoB/게임 실행·경제/사용성 검증은 수행하지 않았다.
