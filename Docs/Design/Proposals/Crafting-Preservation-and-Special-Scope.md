# 보존과 손실·특수 제작의 초기 범위 제안

상태: **전체 미승인**. [기본 제작](../Systems/Equipment-Crafting.md)과 [장비 보관·비교·교체·분해](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)를 전제로, 첫 제작 검증 범위에서 추가 옵션 보호·확정 제작·파괴형 강화까지 넣을지를 함께 확인한다. 이 문서는 정식 제작의 후속 범위를 제안하며 Unity 구현 승인을 요청하는 문서가 아니다.

## 대안과 추천

| 안 | 플레이와 범위 | 장점·제약 |
| --- | --- | --- |
| A: 기존 제작부터 검증 — 추천 | 기본 4종과 집중석의 그룹 통제로 첫 제작 모델을 구성하고 추가 특수 제작은 후속 판단 | 재료 5종과 이미 합의한 확률을 익혀 드롭·중간 결과·다음 투자를 판단. 좋은 옵션을 확정 보존하며 다른 줄을 완성하는 경로는 없음 |
| B: 옵션 보호 1종 추가 | 기존 옵션 한 줄을 보호하며 다른 옵션을 다듬는 경로까지 먼저 설계 | 중간 완성품을 이어 갈 수 있지만 보호 범위·비용·해제·조율 영향과 종결 완성 비용을 추가 합의해야 함 |
| C: 되돌릴 수 없는 특수 강화 추가 | 완성품에 추가 결과와 손실 위험을 주는 마지막 제작 단계 | 완제품 소비와 강한 목표를 만들 수 있으나 장비 손실 부담·별도 보상 상한·희귀 재료 수급을 추가 설계해야 함 |

**A를 권한다.** 종결 장비 제작이 핵심이므로 장비·스킬의 목표 조합, 기본 제작의 도달 비용과 긴 실패 연속부터 검증하자는 제안이다. 특수 제작을 영구 배제하거나 현재 제작만으로 종결의 재미가 충분하다고 결론 내리는 안은 아니다. B/C를 원하면 선택한 특수 제작의 조건·비용·확률·종료 처리를 하나의 묶음으로 먼저 제안하고 확인받는다.

## A 전체 확인 범위

| 항목 | 제안 |
| --- | --- |
| 첫 제작 구성 | 추가·제거·교체·전체 수치 재추첨과 접두/접미 통제까지. 재료는 기존 부여석·제거석·교체석·조율석·집중석 5종 |
| 특정 옵션 보호 | 개별 줄 잠금·영구 고정·접두/접미 전체 보존·특정 옵션 확정 부여는 첫 범위에서 제외 |
| 결과 복구 | 제작 결과 선택·되돌리기·보험·투자 재료 환급 없이 기존 즉시 적용 규칙 유지 |
| 아이템 자체 위험 | 파괴·성급 하락·영구 제작 불가·타락과 같은 추가 위험 제작은 도입하지 않음 |
| 수치·자리 상한 | 기존 성급별 허용 3단계와 7단계 수치 범위·접두 3+접미 3 유지. 초과 수치·일곱 번째 옵션·기반/고정 특성 변경을 주는 별도 제작 없음 |
| 종결 이후 | ‘완성 확정’ 비용·봉인·강제 제작 종료 상태를 두지 않으며 사용자가 멈추거나 계속 제작 가능. 별도 완성 보너스 없음 |
| 보호 표시 | 승인된 ‘분해 보호’는 분해만 차단하며 제거·교체·조율로부터 옵션을 보호하지 않음. 집중석도 그룹 내 특정 줄을 보호하지 않음 |
| 변경 판단 | 목표 빌드와 파밍 시간을 정한 뒤 기본 제작의 완성 비용·중간 결과 손실·최악에 가까운 연속 시도를 평가하고 특수 제작 필요성 재검토 |

B/C의 세부 수치나 새 재료를 이번 A의 승인으로 확정하지 않는다. 자동·일괄 제작, 재료 교환·판매/거래·과금, 고유 제작, 젬 성장·직업·패시브의 미정 사항도 별도 범위다. 새 보호 수단을 추가하게 되면 기존 ‘모든 수치 조율’과 중복/그룹·단계 규칙에 미치는 변경부터 다시 확인한다.

## 판단 사례·조사와 검증 계획

분해 보호한 장비라도 교체석을 사용하면 좋은 옵션을 잃을 수 있다. 접두가 좋은 장비에 접미 지정 교체를 쓰면 해당 실행은 접미만 바꾸지만, 접두 보호라는 별도 영구 상태가 생기지는 않는다. 조율석은 분해 보호와 무관하게 기존 모든 옵션 값을 다시 뽑는다. 이 사례는 이미 승인된 동작의 해석이며 새 확률을 제안하지 않는다.

[특수 제작 범위 조사](../../Research/2026-11-18-crafting-preservation-and-special-scope.md)에 PoE2DB·GGG 공식 변경·커뮤니티의 중간 제작 단계와 공개 도구의 확인 버전·라이선스·Unity 호환성·재사용 제약을 기록했다. 원작에서 여러 통제 도구가 쓰인다는 사실과 우리 게임이 그 도구를 전부 필요로 한다는 판단은 구분한다.

A를 확인하면 기존 기본 제작과 분해 보호의 경계를 현행 기획서에 통합한다. 이후 구현 전 별도 기술 조사와 적용 범위·검증 계획을 제안한다. 보호 토글 유무에 따른 동일 후보/확률, 선택 그룹 밖 옵션 보존, 조율의 전체 수치 변경, 성급·고정 특성·옵션 개수 상한과 반복 제작 가능 상태를 검증할 계획이다.

실제 종결 비용은 목표 빌드와 전투/파밍 시간을 정한 후 비용 분포·중간 중단·분해 추가 수급을 함께 평가한다. 현재는 문헌 조사와 기능 제안까지이며 제작 시뮬레이터·Unity 전투/경제 실험을 실행하지 않았다.
