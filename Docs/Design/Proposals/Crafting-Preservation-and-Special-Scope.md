# 보존과 손실·특수 제작의 초기 범위 확인 결과

상태: 사용자 답변 “1번으로 가자”를 직전 첫 선택지인 A안으로 연결해 확인했다. 승인 기록은 [DEC-0102](../Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md), 현행 규칙은 [기본 제작 기획서의 첫 제작 검증 범위](../Systems/Equipment-Crafting.md)에 통합한다.

첫 제작은 기본 4종+집중석을 사용하고, 개별 옵션 잠금·영구 고정·확정 부여·추가 위험 제작·별도 완성 비용/보너스는 두지 않는다. 기존 상한과 반복 제작 가능 상태를 유지하며 분해 보호는 제작으로 옵션을 보호하지 않는다. 상세 조건과 사례도 기능 기획서를 따른다.

추가 특수 제작을 영구 배제하거나 기존 제작의 재미/경제를 검증했다고 해석하지 않는다. 목표 빌드와 파밍 시간을 정한 뒤 필요성을 다시 판단하고, 추가할 때 조건·비용·확률·기존 규칙과의 관계를 기능 단위로 제안해 확인받는다.

[조사](../../Research/2026-11-18-crafting-preservation-and-special-scope.md)에 출처·버전·권리·Unity 호환성과 재사용 제약을 기록했다. 이번은 기획 문서 반영이며 구현·제작 시뮬레이션·전투/저장·경제 실험을 실행하지 않았다.

다음 미승인 묶음은 [고유 장비의 역할·획득·착용·처분](Unique-Equipment-Role-Acquisition-and-Handling.md)이다. 개별 고유의 효과/수치·정식 빌드·젬/캐릭터 성장은 이번 승인으로 확정하지 않는다.
