# 라이트한 PoE의 스킬·젬·빌드 전체 기획 초안

**2026-11-23 · v1 · 검토용 초안.** 사용자는 [2안의 젬별 경험치 성장과 다양성 확대 방향](../Decisions/DEC-0106-individual-gem-growth-and-full-design-validation.md)을 선택하고, PoE 원본 조사·전체 기획 작성·정적 분석과 수치 테스트를 요청했다. 이 요청에 따라 아래의 세부 규칙과 데이터를 끝까지 작성했다. **새 개수·수치·전투 규칙의 최종 승인은 아니다.** 기존 승인 내용은 [현재 확정 범위](../Systems/Skill-Gem-Links-Growth-and-Acquisition.md)에서 구별한다.

## 1. 설계 목표와 범위

목표는 **장비 제작과 젬 연결의 선택이 전투 방식과 유리한 도전을 바꾸는 것**이다. 젬 수와 조합 개수는 다양성의 입력이며 실제로 유효한 빌드 수를 뜻하지 않는다. 단일 대상 피해, 다수 적 처리, 이동 대상의 명중 유지, 생존을 나누어 비교한다.

첫 정식 후보는 **액티브 24종·보조 24종, 네 클래스·다섯 무기, 세 액티브 × 각 보조 두 자리**다. 기존 13액티브·4보조를 토대로 액티브 11종·보조 20종을 추가한다. 보조는 모든 클래스에서 공유하며 같은 기본 액티브에도 서로 다른 연결이 성립하게 한다.

확장하는 규칙은 투사체 경로, 명중 분포, 반복·행동 시간, 재사용, 물리→원소 전환, 출혈·점화, 치명/막기 연동, 생명력 지불과 회복이다. 소환수·토템·중독·혼돈·저항 관통·패시브 트리는 이 목록의 작동 전제가 아니다. 소환은 다른 주체의 능력치 이전과 새 장비 옵션까지 필요하므로 다음 확장으로 분리한다. 이 문서가 PoE 전체 콘텐츠의 복제나 게임 전체 운영 기획을 의미하지는 않는다.

### PoE에서 남기고 간소화할 것

| 원본에서 참고한 관계 | 이 초안의 선택 | 이유와 손실 |
| --- | --- | --- |
| 액티브 + 연결된 보조로 행동 변화 | 유지. 호환과 상호 배제를 표시 | 젬의 행동과 장비 옵션을 함께 실험 |
| 젬 개별 경험치와 교체 단계 | 유지하되 미장착 젬에 25% 성장 | 주력 육성의 의미와 다른 빌드 추격을 함께 제공 |
| 장비 소켓·링크와 실물 젬 | 캐릭터의 3×2 목록 연결로 간소화 | 장비를 갈 때 소켓을 다시 만들지 않음. 젬 실물 거래·득템은 줄어듦 |

| 복잡한 피해 전환과 발동 연쇄 | 전환 1종, 발동 깊이 1, 공유 발동 제한 | 상호작용은 남기고 무한 루프·중간 단계 추적을 제한 |
| 젬 퀄리티·각성/변형·색상 최적화 | 첫 목록에는 없음 | 외부 공략에 의존하는 숨은 임계점을 줄임 |

PoE의 현재 색상 규칙을 예전의 강제 색상 일치로 가정하지 않는다. 3.29의 공식 변경과 이 초안의 소켓 생략은 별개의 선택이다. 출처와 버전은 조사 문서를 따른다.

## 2. 연결·제공·클래스·저장

- 처음 로비에 진입하면 48종을 계정의 영구 젬 목록으로 제공한다. 추천 시작 편성과 호환 필터로 안내하며, 전체 목록은 처음부터 열어 볼 수 있다. 젬 드롭 대기·중복 합성·젬 판매/분해·거래는 없다. 장비/재료 보상과 가방 500칸을 사용하지 않는다.
- 액티브는 최대 3개, 각 보조는 최대 2개다. 빈칸을 허용하고 두 칸 완성 보너스는 없다. 같은 액티브는 한 편성에 하나만 놓고, 같은 보조는 한 그룹에 하나만 놓는다. 다른 그룹에는 같은 보조를 반복해서 연결할 수 있다.
- 로비에서 무료로 변경한다. 액티브를 직접 교체하면 호환 보조는 남기고 나머지만 해제한다. 적용 전에 해제될 연결을 알려 준다. 젬 자체는 소비되거나 없어지지 않는다.
- 네 클래스와 무기 관계는 기존 프로토타입을 출발점으로 유지한다. 검투사=한손검, 사수=활, 원소술사=마법봉, 파쇄자=양손도끼/양손망치다. 클래스를 무료로 바꾸며 무기·3×2 편성을 클래스마다 기억한다. 계정의 장비·젬별 경험치는 공유한다.
- 공격 액티브는 무기 피해, 주문 액티브는 젬 기본 피해를 사용한다. 마법봉의 기본 공격은 물리 공격이며 주문 기본 피해와 섞지 않는다. 활·양손 무기는 방패를 쓸 수 없다.
- 첫 요구치는 검/도끼/망치 힘 20, 활 민첩 20, 주문 지능 20이다. 보조는 별도 능력치 요구가 없고 젬 Lv.로 요구치를 올리지 않는다. 수치 20의 정식 채택은 이번 초안이며 프로토타입 실험 승인을 확대 해석하지 않는다.
- 요구치가 부족한 새 연결은 거부하고 현재/필요 값을 보여 준다. 장비 교체·제작으로 기존 조건을 잃으면 연결을 보관하고 사용만 중지한다. 조건을 회복하면 다시 사용한다. 무기를 바꾸어 못 쓰게 된 기존 편성도 지우지 않는다.
- 던전 안에서는 연결/장비를 변경하지 않는다. 새 입장 때 임시 발동·행동·지대·상태이상을 초기화한다. 실패/포기에는 이번 젬 경험치를 주지 않고 보유 경험치를 잃지도 않는다. 중단은 같은 도전의 쿨다운·비용·RNG 상태를 이어가도록 설계하며 실제 Unity 복원은 후속 구현 검증 대상이다.

저장 항목은 젬 ID별 누적 XP, 버전, 클래스별 무기와 연결 ID, 도전 ID와 경험치 정산 상태다. 레벨은 XP에서 계산한다. 모르는 ID·중복·잘못된 호환을 적용하기 전에 검증하며, 구형 저장의 전 액티브를 보유 장비 성급만 보고 최대 레벨로 만들지 않는다. 기존 프로토타입에 정식 XP가 없으므로 최초 정식 이관은 Lv.1/XP 0부터 시작하는 후보로 둔다.

## 3. 젬별 경험치와 성장량

**액티브와 보조 모두 Lv.1~20.** 보조 개별 성장까지 추가하는 것은 이번 초안의 확장이다. Lv.1에 행동은 완성되어 있고 성장으로 투사체 수·반복 수·호환·발동 조건이 바뀌지 않는다.

| 항목 | 제안 |
| --- | --- |
| Lv.L → L+1 | XP 100×L, 최대 Lv.20 |
| 파밍 성공 | 구간 성급 s에 대해 장착·사용 조건이 유효한 젬마다 XP 20×s |
| 미장착/현재 사용 불가 | 목록의 젬마다 위 XP의 25%, 정수. 1~5성에서 5/10/15/20/25 |
| 같은 보조 여러 연결 | 종류별 한 번만 100%. 연결 개수·실제 발동 횟수·타격 수로 배수 지급하지 않음 |
| 모딩과 정산 | 모딩의 장비/재료 추가 추첨으로 젬 XP를 추가하지 않음. 도전 ID별 성공 정산 한 번 |
| 실패·포기·경쟁 | 이번 XP 없음. 기존 XP 감소 없음. 경쟁 도전을 XP 반복 수급 경로로 쓰지 않음 |
| 공격 젬 성장 | Lv.1 피해에 ×[1+0.02×(L−1)] |
| 주문 젬 성장 | Lv.1 피해에 ×[1+0.12×(L−1)] |
| 보조 성장 | 연결된 스킬 피해 증가에 보조마다 +(L−1)%p. 두 보조의 증가와 장비 증가를 같은 적용 합계에 더함 |

| Lv. | 누적 XP | 공격 배율 | 주문 배율 | 보조 하나의 피해 증가 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0 | 1.00 | 1.00 | 0% |
| 5 | 1,000 | 1.08 | 1.48 | 4% |
| 10 | 4,500 | 1.18 | 2.08 | 9% |
| 15 | 10,500 | 1.28 | 2.68 | 14% |
| 20 | 19,000 | 1.38 | 3.28 | 19% |

5성만 반복한다는 비교 조건에서 장착 젬은 190회, 미장착 젬은 760회 성공으로 Lv.20에 도달한다. 전투 시간·초반 구간 이동·자동 반복·오프라인 진척을 가정한 시간 단위 목표는 아니다.

공격은 무기 성급·물리 제작 성능의 성장을 받고 주문은 무기 물리 피해를 받지 않으므로 서로 다른 성장률을 제안한다. 초기 동일 성장률의 문제는 검증 결과에 남겼다. 새 주문의 육성 격차는 공격보다 클 수 있으며 25% 배경 성장의 추격 속도를 플레이로 확인해야 한다. 능력치는 조건 역할이며 엔드게임에서 과잉 능력치의 가치는 낮다는 한계가 있다.

투사체 기본 사거리는 9m, 비투사체 주문·지속 명중의 목표 선택 거리는 6m, 나머지 공격은 3m를 초안 기준으로 삼는다. 이동 구체는 주변 지대 명중을 전달하는 매개이며 다중 투사체 보조를 받는 실제 투사체와 구별한다. 폭발 화살은 이 초안에서 기본 물리 범위 명중이며 화염 전환을 연결해야 화염 기반이 된다.

추가 기하 규격: 회전/지대는 원, 쐐기 가르기·서리 파동은 전방 90도 부채꼴, 파쇄 고리는 바깥 반경의 55~100% 띠다. 연환 검격·집중 찌르기·집중 분쇄는 각 명중당 한 대상이다. 균열 확장은 목표 방향으로 중심을 1.2m씩 옮기는 세 판정이며 간격은 표를 따른다. 연쇄 번개는 기본 다른 적 2회 추가 도약, 각 도약은 5m와 가시선 안의 미명중 적을 고른다. 실제 장애물·고리 빈 중심·동적 표적 검증은 오프라인 모델이 대체하지 않는다.

### 호환과 상호 배제

1. 보조 두 개를 함께 적용한 **최종 구성**으로 호환을 판정한다. 화염 전환+점화는 가능, 물리가 사라지는 전환+출혈은 불가다. 장비에 붙은 소량의 화염 정액만으로 점화 보조의 기본 호환을 새로 열지 않는다.
2. 전환은 한 그룹에 하나, 연동 보조도 하나다. 다중 투사체+단일 조준은 배제한다.
3. 관통 투사체는 연쇄를 받지 않고 귀환을 받을 수 있다. 비관통 투사체/기본 연쇄는 연쇄를 받을 수 있고 귀환을 받지 않는다. 전체 경로 우선순위를 외우게 하는 대신 가능한 조합을 제한한다.
4. 연속 공격은 직접 공격, 메아리는 직접 주문만 받는다. 지대·여진·화살비의 지속 명중에는 붙지 않는다. 연동+반복/메아리/묵직한 일격은 금지한다. 즉시 연동으로 동작 시간의 손해만 없애는 구성을 막는다.
5. 막기 연동에는 실제 방패가 필요하다. 비호환으로 자동 해제하기보다 장비 변경 시 사용 중단 사유를 보이며 저장된 연결은 남긴다.
6. 치명타 불가 상태에서도 치명 관련 연결 데이터를 삭제하지 않는다. 치명 연동에 발동원이 없거나 치명 집중의 이득이 사라짐을 명확히 경고한다.

기계적 호환 목록은 분석 도구로 전수 열거한다. 같은 액티브에 같은 보조 두 개나 3개 이상의 보조를 몰래 연결하는 경우를 모두 거부한다.

## 6. 자동 전투·명중·발동의 실행 순서

영웅은 세 그룹 중 준비된 유효 일반 스킬을 슬롯 순서로 돌아가며 사용한다. 사용한 다음 슬롯부터 다시 찾고, 사용할 일반 스킬이 없으면 기본 공격을 한다. 행동은 직렬이며 동작 점유 중 다른 일반 스킬을 끼워 넣지 않는다. 다음 조건을 만족하는 가장 가까운 적을 택하고 거리 동률은 안정된 대상 ID로 정한다. 가시선/경로가 없으면 우회 이동하며 벽을 통과해 피해를 주지 않는다. 이동·물리 충돌은 후속 Unity 구현에서 검증한다.

- 재사용은 활성화 시작에 발생한다. 장비와 재사용 가속의 ‘회복 증가’를 더한 후 기본 재사용 시간을 나눈다. 완급 조절은 기본 시간에 ×1.5를 먼저 적용한다. 공격/시전 속도로 재사용을 별도 단축하지 않는다.
- 일반 첫 명중 예약 시점은 동작 시간의 50%. 연타/여진/지대는 표의 간격으로 추가 판정한다. 반복/메아리는 원래 동작 한 번 뒤 같은 실행을 65% 명중 피해로 한 번 더 하며 전체 동작 두 번을 점유한다. 이 추가 실행에 별도 재사용과 활성화 비용은 없다.
- 투사체의 기본 발사 수는 보통 1, 확산 화살은 3이다. 다중 보조는 +2다. 같은 실행·같은 명중 차례의 형제 투사체·폭발·연쇄가 같은 적을 여러 번 맞히지 못한다. 다른 연타/지대 차례는 다시 맞힐 수 있다.
- 귀환은 동일 경로를 되짚으며 왕로와 귀로에서 각각 적당 한 번, 귀로는 50% 피해다. 반복 실행은 별도 실행으로 취급한다. 실제 왕복 시간은 경로 길이/투사체 속도를 사용해야 하며 분석 모델의 귀환 +0.35초는 비교용 근사다.
- 지속 명중은 그룹당 동시에 한 실행만 유지한다. 새 실행을 만들면 이전 실행의 남은 지대/여진 판정을 취소한다. 중첩 폭증을 막되 너무 빠른 재사용으로 여진을 손해 보는 경우를 미리보기에서 알린다.
- 일반 액티브에는 마나 소모·예약을 두지 않는다. 생명 연소를 연결한 실행은 시작에 최대 생명력 4%를 지불한다. 현재 생명력이 비용 이하이면 사용하지 않고 다른 스킬/기본 공격으로 진행한다. 지불은 피해가 아니므로 피격/막기/치명 연동을 일으키지 않으며 자신을 죽이지 않는다.
- 흡혈은 방어 적용 후 실제 준 명중 피해를 기준으로 회복하고 받는 회복 증가·파밍 회복 약화를 적용한다. 영웅 전체의 초당 최대 생명력 10%를 공유한다. 회복하지 못하는 초과분을 미래로 적립하지 않는다. 오프라인 도구는 1초 단위 버킷이며 실제 연속 시간 상한은 구현 시 일치 여부를 검증한다.

### 연동과 순환 방지

치명 연동 그룹은 일반 순회에서 빠지고, **다른 그룹의 일반 직접 실행 첫 명중 또는 기본 공격이 치명타일 때** 후보가 된다. 같은 범위 명중의 적 수·형제 투사체 수로 여러 이벤트를 만들지 않는다. 막기 연동은 적의 명중을 실제 방패로 막았을 때만 후보가 된다.

여러 후보는 슬롯 순회로 하나를 고르고, 해당 스킬 자신의 재사용과 **영웅 전체 공유 0.5초 발동 간격**을 모두 만족해야 한다. 연동은 일반 동작을 점유하지 않지만 최소 다음 예약 시점에 피해를 판정한다. 분석의 최소 예약 지연은 0.02초다. 생명 비용이 있으면 그때 한 번만 지불한다.

연동이 만든 명중, 반복의 추가 실행, 지속 명중, 상태이상 틱은 다른 연동의 원천이 아니다. 발동 깊이는 1이다. 모든 그룹이 연동이어도 기본 공격이 유일한 일반 발동원으로 남는다. 스스로를 발동하거나 A→B→A로 반복하는 루프를 허용하지 않는다. 치명타가 최종 0이면 치명 연동이 발생하지 않는다.

## 7. 피해·전환·치명타·출혈/점화

기본 명중 계산은 [승인된 옵션·전투 공식](../Systems/Equipment-Affixes-and-Combat-Numbers.md)을 따른다. 지역 무기 증가와 캐릭터 증가, 증가 합산과 별도 배율, 공격속도와 재사용 회복을 구분한다.

**계산 순서:** 무기 지역 정액/증가 → 공격 계수 또는 주문 기본 피해/정액 → 젬 성장 → 물리 전환과 피해 성분 구분 → 적용 가능한 캐릭터/보조 증가 합산 → 명중 전용 보조·고유 증폭/감폭 → 치명타 → 대상 방어 → 실제 피해/회복.

전환은 기본 물리 성분 100%를 한 원소로 바꾼다. 전환된 성분에는 출발 물리 증가와 도착 원소 증가를 같은 합계에 한 번씩 더한다. 원래부터 있던 원소 정액은 물리 증가를 받지 않는다. 전환을 여러 번 거치거나 피해를 복제하지 않는다. 예를 들어 물리 100, 물리 증가 20%, 원소 증가 30%이면 화염 전환 후 증가 적용 결과는 150이며 100×1.2×1.3=156으로 계산하지 않는다. 명중 전용 감폭은 그 뒤다.

치명 확률은 기본 확률에 적용 가능한 증가를 더해 0~100%로 제한하고 기존 파밍 치명 약화를 적용한다. 치명 집중의 +200%는 +200%p가 아니다. 안정의 목걸이가 있으면 최종 확률 0이 가장 우선이다. 기본 치명타 배율 150%에 장비/보조 %p를 더한다.

**출혈과 점화는 새로 제안하는 규칙**이다. 적용 가능한 성분의 명중 전용 증폭/감폭·치명·대상 방어 적용 전 피해를 기반으로 한다. 출혈은 초당 물리 기준 18%, 점화는 초당 화염 기준 60%, 각각 3초다. 0.5초마다 피해를 주며 틱에는 치명타·회피·막기가 없다. 물리 지속 피해에는 방어도를 적용하지 않고 점화에는 화염 저항을 적용한다. 기존 지속 피해 약화는 ×0.7이다.

대상당·영웅당·종류당 하나의 가장 강한 효과만 유지한다. 더 강하거나 같은 효과는 교체/갱신, 약한 효과는 무시한다. 갱신해도 다음 틱 시각을 미루지 않는다. 출혈과 점화는 함께 존재할 수 있다. 명중 전용 25% 증폭이나 속행 반지의 명중 감폭을 지속 피해 기반에 다시 곱하지 않는다. 물리·원소·주문·보조 증가를 이미 반영한 기반을 사용하므로 같은 증가를 지속 피해에서 두 번째 적용하지 않는다.

냉기/번개 전환이 자동으로 동결/감전 효과까지 주는 것은 아니다. 그 상태이상은 이 첫 목록에 없다. 기존 고유의 ‘자신의 명중’과 새 지속 피해의 범위를 혼동하지 않는다.

## 9. 게임 안에서 제공할 설명과 진단

목록/편성에는 현재 Lv./XP와 다음 필요량, 사용 무기·능력치 현재/필요, 적용 가능한 보조와 배제 이유, 연결 후 피해 성분/반경/발사 수/명중 차례/재사용/행동 점유를 표시한다. 증가 %와 기본 확률 추가 %p를 구분한다.

빌드 진단은 최소 다음을 구별한다: ‘힘 19/20’, ‘방패 없음으로 막기 연동 중단’, ‘치명타 불가로 발동원 없음’, ‘기본 발사 3+2=5, 같은 적 중복 아님’, ‘지대 교체로 남은 명중 취소’, ‘생명 비용 대비 재생/흡혈 부족’, ‘다른 젬과 같은 출혈을 누적하지 않음’.

장비 비교/제작 미리보기는 성립/중단하는 젬과 바뀌는 재사용/행동 병목을 함께 보여 준다. 입력을 바꾼 이유와 결과를 게임 안에서 확인하게 하며 외부 공략만이 알 수 있는 숨은 아이템 레벨·젬 색상·서버 틱 임계점을 새로 만들지 않는다. 실제 모바일 화면·아트 시안은 이 문서의 승인 범위가 아니다.

## 10. 수치 검증, 한계와 적용 순서

분석용 데이터/도구와 Unity 실행 데이터를 분리했다. Python 표준 라이브러리로 호환을 전수 열거하고, 직렬 행동·재사용·지대 교체·대상별 상태이상·치명/막기 RNG·생명 비용/회복을 사건 큐로 계산한다. 비교용 장비는 승인된 34옵션과 성급별 허용 단계/정수 범위 안에서 생성한다.

기본 비교는 Lv.20/5성·6옵션·6단계 중앙 정수값, 같은 부위 예산이다. 목적에 따라 옵션 선택은 달라지며 최적화 보장은 없다. 불필요한 능력치 접미를 모든 부위에 강제로 넣지 않고 요구치 충족 이후 다른 옵션을 선택한다. 비교용 캐릭터 생명력 1000·능력치 각 10은 기존 비교 기준이며 실제 시작 캐릭터 확정값이 아니다. 활/망치의 기본 성능은 이 초안의 비교 확장값(활 24/초당 1.2, 망치 44/초당 0.72, 성급 배수)이며 기존 공식 장비 수치를 승인 없이 변경하지 않는다.

적 조건은 고정 단일·밀집 다수·이동 분산·생존 압박과 별도 보류 조건 네 가지다. 동일 시드로 비교하고 결과에 평균/분산·근사 구간·생존 비율을 남긴다. 12개 고유 착용 형태, 1/3/5성 × Lv.1/10/20, 기존 모딩 6종도 비교한다. **적 HP 무한 비교이므로 HP +30%가 DPS를 바꾸지 않으며 실제 클리어 시간은 계산하지 않는다.** 실제 대상 수·명중률은 기하 근사이므로 이동/관통/고리/장애물의 Unity 구현을 입증하지 않는다.

초기 출혈 편중과 주문 성장 부족을 발견해 조정했고 테스트로 빠른 상태이상 갱신의 틱 지연, 행동/재사용 분리, 발동 순환, 고유 중첩, 경험치 중복 정산의 회귀를 확인했다. 통과한 소프트웨어/산술 검사와 아직 불균형한 빌드를 분리해 기록한다. [검증 요약](../Analysis/SkillGems/SUMMARY.md)을 현재 수치 판단의 근거로 삼는다.

진행 순서는 전체 초안 검토 → 사용자 확인 범위를 한 결정에 기록 → 승인된 규칙만 정본/실제 데이터에 반영 → Unity 기술 적용·저장 이관 계획 → 실제 이동/충돌·자동 전투/중단 복원과 모바일 측정 → 직접 플레이/경제 검증이다. 이번 요청으로 전체 초안과 오프라인 분석까지 작성했으며 Unity 전투·저장·기존 프로토타입 파일을 수정하지 않았다.
