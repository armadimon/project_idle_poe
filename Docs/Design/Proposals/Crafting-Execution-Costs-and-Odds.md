# 기본 제작의 실행·비용·확률 제안 결과

사용자가 요약과 상세 조건 전체를 “오케이 진행해줘”로 확인했다. 승인 이력은 [DEC-0098](../Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)이며 현행 규칙은 [희귀 장비 기본 제작 기획서](../Systems/Equipment-Crafting.md)에 모았다.

확정한 내용은 부여석·제거석·교체석·조율석 각 작업당 1개와 그룹 지정 집중석 1개 추가, 유효 대상·무효 처리와 통제 선택, 작업별 균등 추첨·조율 독립성, 차감과 즉시 결과·취소/중단 복원·장착 중 제작과 젬 조건 처리다.

기존 파밍 공급 비율과 던전 재료 소모량, 장비당 제작 횟수 제한 없음은 유지한다. 첫 실험용 초기값의 승인은 실제 게임의 제작·저장·전투·경제 검증 완료와 구분한다.

다음은 [장비 보관·비교·교체·처분](Equipment-Inventory-Comparison-and-Salvage.md)을 한 묶음으로 검토한다. 보관 용량·분해/회수 등 새 세부 규칙은 아직 승인되지 않았다.
