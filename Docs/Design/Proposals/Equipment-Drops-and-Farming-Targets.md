# 장비 득템·파밍 대상 제안 결과

이 문서에서 검토한 묶음 전체를 사용자가 “응 진행해줘”로 확인했다. 승인 기록은 [DEC-0095](../Decisions/DEC-0095-equipment-drops-and-farming-targets.md)이며 현재 적용할 규칙은 [장비 득템·파밍 대상 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)에 모았다.

| 승인 범위 | 결과 |
| --- | --- |
| 구간과 해금 | 1~5성, 현재 구간 첫 완주로 다음 해금, 모딩 여부 무관 |
| 목표 장비 | 구간과 같은 성급·선택한 부위, 유효 기반 균등 추첨 |
| 희귀 옵션 | 4개 60%·5개 30%·6개 10%, 유효 그룹·종류·등급·수치의 조건부 균등 추첨 |
| 정보 | 성급·후보·등급·수치 범위와 확률을 게임 안에서 확인 |

다음은 [장비 편성·기반 구조](Equipment-Catalog-and-Base-Structure.md)를 묶어 검토한다. 실제 부위·슬롯·무기와 기반 목록·고정 특성, 개별 옵션·전투 적용·수치표는 아직 승인되지 않았다.

승인은 기획 규칙이며 게임 구현이나 드롭 분포·경제 검증 완료를 뜻하지 않는다. [기능 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)의 조사·검증 범위를 따른다.
