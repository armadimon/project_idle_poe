# 장비 득템·파밍 대상 구성 묶음 제안

상태: 아래 묶음은 아직 승인되지 않았다. [파밍 던전 변화 기획서](../Systems/Farming-Dungeon-Modification.md)의 확정 수급·정산을 전제로, **어디서 어떤 제작 출발 장비를 얻을지**를 한 번에 확인한다.

## 현재 확정 사항

장비는 획득 시 1~5성으로 고정되며 장비 간 옵션 이전은 없다. 희귀 장비는 일부 옵션과 6개 옵션 구성을 함께 드롭하고, 접두·접미는 최대 3개씩이다. 같은 장비 계열의 기반은 추가 옵션 후보를 공유하며 같은 종류 옵션은 장비당 1개다.

성급별 허용 옵션 등급은 낮은 쪽부터 1성 1~3, 2성 2~4, 3성 3~5, 4성 4~6, 5성 5~7이다. 이는 선행 결정의 비교용 등급 순서이며 최종 명칭·표기 방향은 별도다. 같은 등급 안에서도 범위의 여러 수치를 추첨하고 인접 등급 수치 범위는 일부 겹치는 기존 규칙을 따른다.

근거: [DEC-0021](../Decisions/DEC-0021-partial-and-full-affix-drops.md), [DEC-0023](../Decisions/DEC-0023-shared-affix-pool-by-equipment-family.md), [DEC-0028](../Decisions/DEC-0028-fixed-rare-equipment-star-grade.md), [DEC-0032](../Decisions/DEC-0032-three-affix-tiers-per-equipment-grade.md), [DEC-0033](../Decisions/DEC-0033-random-values-within-affix-tier-ranges.md), [DEC-0034](../Decisions/DEC-0034-overlapping-value-ranges-between-adjacent-affix-tiers.md), [DEC-0041](../Decisions/DEC-0041-one-affix-of-each-kind-per-rare-equipment.md).

## 이번 추천 묶음

| 항목 | 제안 규칙 |
| --- | --- |
| 파밍 구간 | 표시 성급 기준으로 1~5성의 다섯 구간 제공 |
| 해금 | 1성부터 시작. 해당 구간을 처음 완주하면 다음 구간 해금. 모딩 여부와 무관하게 완주 인정 |
| 장비 성급 | 해당 구간의 표시 성급 장비만 드롭. 5성 구간에서는 5성 장비 획득 |
| 목표 부위 | 입장 전에 목표 장비 부위를 하나 선택. 기본·모딩 추가 장비 추첨 모두 그 부위에서 생성 |
| 기반 종류 | 선택 부위의 해당 구간 후보에서 같은 확률로 추첨 |
| 옵션 개수 | 희귀 드롭에 4개 60%·5개 30%·6개 10%로 추가 옵션 생성 |
| 접두·접미 배치 | 유효한 그룹을 같은 확률로 선택하고 그룹 안의 유효 종류를 같은 확률로 추첨 |
| 등급·수치 | 해당 성급에서 그 옵션에 허용된 유효 등급과 범위 안의 유효 수치를 각각 균등 추첨 |
| 공개 정보 | 입장 전에 장비 성급·부위·기반 후보·옵션 개수 분포·허용 등급과 추첨 확률 표시 |

표의 내용은 모두 이번에 확인할 제안이며 묶음 전체 승인이나 항목별 수정이 가능하다.

## 구간과 획득 잠재력

| 파밍 구간 | 장비 성급 | 기본 허용 옵션 등급 | 선행 역할 |
| --- | --- | --- | --- |
| 1성 구간 | 1성 | 1~3 | 성장 초반 |
| 2성 구간 | 2성 | 2~4 | 성장 중반 |
| 3성 구간 | 3성 | 3~5 | 성장 후반 |
| 4성 구간 | 4성 | 4~6 | 엔드게임 진입 |
| 5성 구간 | 5성 | 5~7 | 종결 제작 |

구간별 장비의 표시 성급을 일치시켜 어떤 장비에 투자할지 알기 쉽게 하는 안이다. 해금된 이전 구간도 자유롭게 선택할 수 있다. 다음 구간의 첫 입장을 허용하는 조건만 정하며 실제 전투 시간·적 수치·진행 소요 시간을 확정하지 않는다.

기본 성공 보상인 희귀 장비 1회·제작재료 2회 추첨과 재료별 공급 비율, 모딩 추가 추첨은 이미 확정한 수급 규칙을 유지한다. 구간별 재료 종류·추첨 횟수를 이번 질문으로 다르게 바꾸지 않는다. 맵 이름·지형·몬스터 목록이나 각 구간의 세부 던전 수는 별도 콘텐츠 구성에서 확인한다.

## 목표 부위와 기반

목표 부위는 현재 장비 규격에 등록된 부위 중 하나를 고른다. 이번 묶음은 목표 부위의 드롭을 제공하는 원칙까지이며 정식 장비 부위 목록·슬롯 수·무기 분류·기반 장비 목록을 임의로 채우지 않는다. 그 실제 목록은 후속 **장비·옵션 데이터 규격** 묶음에서 함께 정한다.

선택한 부위와 해당 구간의 성급에 맞는 기반 후보에서 같은 확률로 하나를 고른다. 기반의 고정 특성은 추가 옵션 칸과 별도로 두고 기존 장비 계열별 후보 공유를 유지한다. 장비 기본 추첨과 모딩 추가 추첨에 같은 후보·확률을 사용한다.

## 희귀 장비의 추가 옵션 생성

1. 추가 옵션 개수를 4개 60%·5개 30%·6개 10%로 추첨한다.
2. 접두·접미 중 빈 칸과 유효 후보가 있는 그룹을 같은 확률로 선택한다. 둘 다 가능하면 각각 50%다.
3. 선택 그룹의 후보 중 이미 붙은 종류를 제외하고 같은 확률로 종류를 고른다.
4. 해당 성급의 허용 범위에서 그 옵션에 실제로 정의된 유효 등급을 같은 확률로 고른다. 허용 3개 등급이 모두 정의되어 있으면 각각 1/3이다.
5. 그 등급의 최솟값~최댓값 안에서 정의한 표시 단위·간격에 맞는 유효 수치를 같은 확률로 고른다.
6. 정해진 개수를 채울 때까지 반복하며 접두 최대 3개·접미 최대 3개와 동일 종류 중복 금지를 지킨다.

기반별 드롭 테이블은 최대 6개를 유효하게 채울 후보가 있는지 데이터 등록 때 확인한다. 정의되지 않은 등급·범위 밖 수치·후보를 만들어 내는 예외 동작을 기본값으로 채택하지 않는다. 실제 옵션 이름·수치 범위·단위와 복합 옵션의 수치 연동은 후속 데이터 규격에서 함께 확인한다.

이 추첨 규칙은 이 파밍의 희귀 장비 드롭 생성에 적용하는 제안이다. 장비 제작의 추가·제거·교체·수치 재추첨 확률을 같은 값으로 자동 확정하지 않는다. 고유 장비·추가 옵션이 없는 기반 장비·다른 보상 경로는 별도다.

## 정보와 대안

입장 전에는 장비 성급과 성급별 옵션 잠재력, 목표 부위와 기반 후보, 옵션 개수·등급·종류·수치 후보 및 추첨 확률을 게임 안에서 확인하게 하는 안이다. 이미 얻은 장비에는 성급과 실제 옵션 등급·수치 범위를 표시한다. 숨은 숫자 아이템 레벨을 다시 추가하지 않는다.

대안은 한 구간에서 여러 성급·여러 부위를 섞어 드롭하는 방식이다. 우연히 다른 부위의 좋은 장비를 얻는 폭은 커지지만 목표 부위와 제작 잠재력의 출발 장비를 모으는 시간이 늘 수 있다.

위 **성급 구간 일치 + 목표 부위 드롭 + 4~6개 옵션 구성과 균등 후보 추첨** 묶음을 권장한다. 원하는 출발 장비를 찾는 범위를 줄이고 옵션 조합·등급·수치 완성에서 득템과 제작의 변화를 남기려는 안이다. 실제 획득 속도와 종결 제작 난도를 검증한 결과는 아니다.

## 조사와 검증 계획

기존 [PoE 2 제작 조사](../../Research/Crafting/README.md)와 [출처·라이선스 목록](../../Research/Crafting/Sources.md), [PoE 1 장비·빌드 조사](../../Research/PoE1/README.md)를 참고했다. 조사에서 확인한 패치·DB 시점과 실제 실행 미검증 범위는 해당 문서에 구분했다. 이 제안의 구간·해금·4/5/6개 출현 비율·균등 추첨은 우리 게임을 위한 자체 제안이며 PoE의 현행 규칙을 채택한 값이 아니다. 원본 게임 데이터·문구·오픈소스 코드를 반입하지 않는다.

승인 뒤 구간 해금과 표시 성급의 일치, 목표 부위 보존, 옵션 개수 분포, 접두·접미 상한·동일 종류 중복 금지·유효 후보 조건, 허용 등급·수치와 공개 확률 일치를 검증한다. 제작 비용·적 수치와 실제 시간을 정한 뒤 원하는 기반과 유효 옵션 출발점을 얻는 시간, 완제품 드롭과 제작의 관계를 비교한다.

아직 장비 데이터나 게임 기능을 구현하지 않았다. 이번 확인 후 실제 장비 부위·무기 분류·기반 고정 특성·일반 옵션 후보와 각 등급의 수치 범위를 장비·옵션 데이터 규격 묶음으로 제안한다.
