# 장비 득템·파밍 대상 제안 결과

이 문서에서 검토한 묶음 전체를 사용자가 “응 진행해줘”로 확인했다. 승인 기록은 [DEC-0095](../Decisions/DEC-0095-equipment-drops-and-farming-targets.md)이며 현재 적용할 규칙은 [장비 득템·파밍 대상 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)에 모았다.

| 승인 범위 | 결과 |
| --- | --- |
| 구간과 해금 | 1~5성, 현재 구간 첫 완주로 다음 해금, 모딩 여부 무관 |
| 목표 장비 | 구간과 같은 성급·선택한 부위, 유효 기반 균등 추첨 |
| 희귀 옵션 | 4개 60%·5개 30%·6개 10%, 유효 그룹·종류·등급·수치의 조건부 균등 추첨 |
| 정보 | 성급·후보·등급·수치 범위와 확률을 게임 안에서 확인 |

[장비 편성·기반 구조](../Systems/Equipment-Catalog-and-Base-Structure.md)는 [DEC-0096](../Decisions/DEC-0096-equipment-catalog-and-base-structure.md)에서 확인했다. [옵션·전투 계산과 수치표](../Systems/Equipment-Affixes-and-Combat-Numbers.md)는 [DEC-0097](../Decisions/DEC-0097-equipment-affixes-base-stats-and-combat-numbers.md)에서 확인했다. 제작 실행·비용·확률·종료는 [DEC-0098](../Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)에서 확인했고 [기본 제작 기획서](../Systems/Equipment-Crafting.md)에 모았다. 장비 보관·비교·교체·분해는 [DEC-0100](../Decisions/DEC-0100-equipment-inventory-comparison-and-salvage.md)에서 확인했고 [장비 관리 기획서](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)에 통합했다. [DEC-0102](../Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md)에서 첫 제작은 기본 4종과 집중석부터 검증하는 A안으로 확인했다. 고유 공통 규칙은 [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)의 2안(B)으로 확인했고 [기능 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다. 첫 고유 효과·수치·중복과 빌드 검증 목표는 [DEC-0105](../Decisions/DEC-0105-first-unique-effects-stacking-and-build-goals.md)에서 확인했고 [고유 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다. 후속 정식 스킬·젬 성장과 콘텐츠는 [기획 순서](../01-Decision-Queue.md)에서 확인한다.

승인은 기획 규칙이며 게임 구현이나 드롭 분포·경제 검증 완료를 뜻하지 않는다. [기능 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)의 조사·검증 범위를 따른다.
