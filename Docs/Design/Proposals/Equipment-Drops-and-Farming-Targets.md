# 장비 득템·파밍 대상 제안 결과

이 문서에서 검토한 묶음 전체를 사용자가 “응 진행해줘”로 확인했다. 승인 기록은 [DEC-0095](../Decisions/DEC-0095-equipment-drops-and-farming-targets.md)이며 현재 적용할 규칙은 [장비 득템·파밍 대상 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)에 모았다.

| 승인 범위 | 결과 |
| --- | --- |
| 구간과 해금 | 1~5성, 현재 구간 첫 완주로 다음 해금, 모딩 여부 무관 |
| 목표 장비 | 구간과 같은 성급·선택한 부위, 유효 기반 균등 추첨 |
| 희귀 옵션 | 4개 60%·5개 30%·6개 10%, 유효 그룹·종류·등급·수치의 조건부 균등 추첨 |
| 정보 | 성급·후보·등급·수치 범위와 확률을 게임 안에서 확인 |

[장비 편성·기반 구조](../Systems/Equipment-Catalog-and-Base-Structure.md)는 [DEC-0096](../Decisions/DEC-0096-equipment-catalog-and-base-structure.md)에서 확인했다. [옵션·전투 계산과 수치표](../Systems/Equipment-Affixes-and-Combat-Numbers.md)는 [DEC-0097](../Decisions/DEC-0097-equipment-affixes-base-stats-and-combat-numbers.md)에서 확인했다. 제작 실행·비용·확률·종료는 [DEC-0098](../Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)에서 확인했고 [기본 제작 기획서](../Systems/Equipment-Crafting.md)에 모았다. 다음은 [장비 보관·비교·교체·분해](Equipment-Inventory-Comparison-and-Salvage.md)를 한 묶음으로 검토한다.

승인은 기획 규칙이며 게임 구현이나 드롭 분포·경제 검증 완료를 뜻하지 않는다. [기능 기획서](../Systems/Equipment-Drops-and-Farming-Targets.md)의 조사·검증 범위를 따른다.
