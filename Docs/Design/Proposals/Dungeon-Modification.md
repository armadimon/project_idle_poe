# 던전 변화와 부여 재화 종류 수 제안

## 확인된 방향

사용자는 **재화를 소모해 던전에 패널티를 추가하고 보상을 높이는 시스템**을 기획에 포함하도록 요청했다. PoE의 맵 모딩을 참고하는 도입 방향은 [DEC-0060](../Decisions/DEC-0060-currency-funded-dungeon-penalties-and-better-rewards.md)에 기록했다. [경쟁의 무료 재도전 입장](../Decisions/DEC-0059-no-separate-entry-cost-for-competition-retries.md)은 별도 원칙으로 유지한다.

던전 변화는 [DEC-0061](../Decisions/DEC-0061-dungeon-modification-for-farming-only.md)에 따라 **파밍에만 적용**한다. **최고 도달 단계 경쟁은 이 변화를 적용하지 않고 공통 도전 조건을 유지**한다. 패널티는 [DEC-0062](../Decisions/DEC-0062-randomly-assign-farming-dungeon-penalties.md)에 따라 플레이어가 고르지 않고 무작위로 부여한다. 재추첨은 [DEC-0064](../Decisions/DEC-0064-reroll-one-selected-dungeon-penalty.md)에 따라 바꿀 패널티 하나를 지정해 무작위로 교체하고 나머지는 보존한다. [DEC-0065](../Decisions/DEC-0065-right-side-lock-checkbox-for-dungeon-penalty-rows.md)에 따라 각 줄 우측에 잠금 체크박스 토글을 둔다. 잠금 해제는 [DEC-0066](../Decisions/DEC-0066-allow-only-one-unlocked-dungeon-penalty-row.md)에 따라 최대 한 줄이며 다른 줄을 해제하면 기존 줄은 자동으로 잠긴다. 교체한 새 결과는 [DEC-0067](../Decisions/DEC-0067-apply-new-dungeon-penalty-result-directly.md)에 따라 빌드에 더 불리해져도 바로 적용한다. 교체 실행마다 재화를 소모하는 원칙은 [DEC-0068](../Decisions/DEC-0068-consume-currency-for-each-dungeon-penalty-replacement.md)에서 확인했다. 사용할 재료는 [DEC-0070](../Decisions/DEC-0070-share-equipment-replacement-material-with-dungeon-penalty-replacement.md)에 따라 장비 옵션 교체의 기본 재료와 공유한다. 같은 조건에서 반복 횟수에 따른 교체 비용 증가를 두지 않는 원칙은 [DEC-0071](../Decisions/DEC-0071-no-cost-escalation-for-repeated-dungeon-penalty-replacement.md)에서 확인했다. 별도 교체 횟수 제한 없음은 [DEC-0073](../Decisions/DEC-0073-no-attempt-limit-for-dungeon-penalty-replacement.md)에서 확인했다. 파밍 성공 후 설정은 [DEC-0074](../Decisions/DEC-0074-reset-farming-dungeon-modifiers-after-successful-clear.md)에 따라 패널티와 연결된 보상 강화를 초기화한다. 파밍 실패 후에도 [DEC-0075](../Decisions/DEC-0075-reset-farming-dungeon-modifiers-after-failure.md)에 따라 패널티와 연결된 보상 강화 설정을 초기화한다. 실패한 도전의 패널티 교체에 사용한 재료는 [DEC-0076](../Decisions/DEC-0076-no-refund-of-dungeon-penalty-replacement-materials-after-failure.md)에 따라 환급하지 않는다. 실패 후 같은 파밍 대상에 새 도전을 허용하고 입장 자체에는 별도 비용을 두지 않는 원칙은 [DEC-0077](../Decisions/DEC-0077-allow-farming-retries-without-separate-entry-cost.md)에서 확인했다. 최초 기본 패널티는 [DEC-0078](../Decisions/DEC-0078-initial-farming-dungeon-penalties-generated-as-one-random-batch.md)에 따라 한 번의 작업으로 무작위 부여한다. 최초 부여 개수는 [DEC-0082](../Decisions/DEC-0082-currency-dependent-random-count-for-initial-dungeon-penalties.md)에 따라 사용하는 재화에 맞춰 무작위로 결정한다. 기본 잠금 상태·전체 잠금 처리와 부여 재화 종류 수·재화별 개수 범위·확률·최대 개수, 패널티 종류·수치·중복·삭제 허용 여부, 재료 이름·실제 소모량·공급·보상, 나머지 설정 유지 범위와 재도전 횟수·기타 조건은 아직 정하지 않았다.

## 조사에서 참고한 부분

GGG의 개발 회고에서 비용·위험·보상을 연결한 설계 의도를, PoEDB에서 던전 변화와 보상 관련 표현을, 커뮤니티·poe.re에서 빌드별 맵 옵션 대응과 필터·설정 공유 사례를 확인했다. 구체적인 출처·확인 버전·라이선스·Unity 호환성과 실제 실행 미검증 범위는 [맵 모딩 조사](../../Research/2026-11-17-dungeon-modification.md)에 둔다.

재화별 희귀도 변환과 옵션 생성 설명은 [2026-11-18 추가 조사](../../Research/2026-11-18-currency-dependent-dungeon-penalty-counts.md)에서 구분했다. 우리 게임에 적용할 패널티와 경제 규칙은 자체 설계한다. PoE의 통화·지도 아이템·옵션 개수·아틀라스·실패 제한이나 오픈소스 데이터는 가져오지 않는다.

## 확인된 적용 범위

던전 변화는 **파밍에 적용하고 경쟁 기록에는 적용하지 않는다.** 사용자는 최고 단계 경쟁에도 적용하는 대안과 비교해 이 1안을 선택했다. 파밍에서 얻은 장비·재료를 제작과 빌드 개선에 활용하고, 최고 단계 경쟁은 공통 도전 조건에서 성과를 비교한다. 확인 근거는 [DEC-0061](../Decisions/DEC-0061-dungeon-modification-for-farming-only.md)에 기록했다.

이번 결정은 적용 범위까지다. 별도 던전·모드·입장 화면의 구성, 경쟁의 구체적인 공통 조건·기록 인정·동률 처리는 아직 정하지 않았다. 장비·스킬이나 그 밖의 캐릭터 능력치를 통일하는 승인도 아니다.

## 확인된 패널티 부여 방식

**패널티는 플레이어가 고르지 않고 무작위로 부여**한다. 사용자는 무작위 후보 중 선택·무작위 부여·직접 지정의 세 대안 중 2안 무작위 부여를 선택했다. 확인 근거는 [DEC-0062](../Decisions/DEC-0062-randomly-assign-farming-dungeon-penalties.md)에 기록했다.

이번 결정은 부여 방식까지다. 재추첨 범위와 잠금 토글 방향, 교체 실행마다 재화를 소모하는 원칙은 아래와 같이 확인했다. 패널티의 종류·수치·개수·중첩과 추첨 확률, 삭제·취소와 추가 통제 수단의 허용 여부, 재료 이름·소모량과 실제 차감 처리 시점·보상 수치는 별도 확인한다. 무작위 부여를 선택했다는 이유로 모든 패널티를 같은 확률로 뽑거나 전투마다 자동으로 새로 뽑는 규칙을 확정하지 않는다.

## 확인된 패널티 교체 범위

**바꿀 패널티 하나를 지정해 무작위로 교체하고 나머지는 보존**한다. 사용자는 전체 무작위 재추첨·한 개를 지정해 무작위 교체·재추첨 없음 중 2안을 선택했다. 확인 근거는 [DEC-0064](../Decisions/DEC-0064-reroll-one-selected-dungeon-penalty.md)에 기록했다.

이번 선택은 한 개 교체와 나머지 보존까지다. 새 결과의 즉시 적용은 아래와 같이 확인했다. 교체 실행마다 재화를 소모하는 원칙은 아래와 같이 확인했다. 추첨 확률·같은 패널티 재등장·중복, 재료 이름·소모량·공급·실행 조건·보상 변경은 별도로 확인한다.

## 확인된 잠금 토글의 조작 방향

사용자가 제안한 대로 **각 패널티 줄 우측에 잠금 버튼을 체크박스 토글로 배치**한다. 체크한 줄은 보존할 패널티를 표시한다. 확인 근거는 [DEC-0065](../Decisions/DEC-0065-right-side-lock-checkbox-for-dungeon-penalty-rows.md)에 기록했다.

| 표시 | 의미 |
| --- | --- |
| 잠금 체크 | 해당 줄을 보존 대상으로 표시 |
| 잠금 해제 | 최대 한 줄이며 해당 줄이 교체 대상. 다른 줄을 해제하면 기존 줄은 자동 잠금 |

잠금 해제와 교체 대상의 연동 방식은 아래와 같이 확인했다. 기본 체크 상태·전체 잠금 시 처리·잠금 유지 기간·잠금에 따른 비용 변화는 미정이다.

이번 확인은 조작 기획까지다. 화면 전체 시안, 토글 크기·터치 영역·색·아이콘·상태 연출과 실제 UI 리소스·엔진 구현은 아직 수행하지 않았다.

## 확인된 잠금 해제와 교체 대상의 연동 방식

**잠금 해제는 최대 한 줄**이며, **다른 줄을 해제하면 기존 줄은 자동으로 잠긴다.** 교체를 실행할 때 잠금 해제된 해당 한 줄을 무작위로 교체하고 나머지는 보존한다. 사용자는 여러 줄을 함께 교체하는 대안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0066](../Decisions/DEC-0066-allow-only-one-unlocked-dungeon-penalty-row.md)에 기록했다.

이번 결정은 잠금 해제 범위와 대상 전환 동작까지다. 처음 표시할 때의 기본 체크 상태와 전부 잠겼을 때의 처리, 재추첨 뒤 잠금 상태의 유지 여부, 재료 이름·소모량·공급·보상·지속 범위는 별도로 확인한다. 새 결과의 즉시 적용과 교체 실행마다 재화를 소모하는 원칙은 아래와 같이 확인했다. 언제나 한 줄이 해제된 상태여야 한다는 규칙을 함께 확정하지 않는다.

## 확인된 교체 결과의 적용 방식

교체에서 추첨한 **새 결과를 바로 적용**한다. 빌드에 더 불리한 결과여도 기존 결과를 대체하며, 기존·새 결과 중 선택하는 단계는 두지 않는다. 사용자는 두 대안 중 이 1안을 선택했다. 확인 근거는 [DEC-0067](../Decisions/DEC-0067-apply-new-dungeon-penalty-result-directly.md)에 기록했다.

이번 결정은 교체 결과의 적용 방식까지다. 잠긴 나머지 줄의 보존과 한 줄만 교체하는 범위를 유지한다. 교체 실행마다 재화를 소모하는 원칙은 아래와 같이 확인했다. 재료 이름·소모량·공급·추첨 확률·같은 패널티 재등장·중복·보상 변화·취소·되돌리기·환급은 별도로 확인한다.

## 확인된 교체 때의 재화 소모

**패널티 교체를 실행할 때마다 재화를 소모**한다. 사용자는 교체 자체에는 별도 비용을 두지 않는 대안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0068](../Decisions/DEC-0068-consume-currency-for-each-dungeon-penalty-replacement.md)에 기록했다.

이번 결정은 교체 실행마다 재화를 소모하는 원칙까지다. 사용할 재료는 아래와 같이 확인했다. 재료 이름·소모량·공급, 실행 조건·실제 차감 처리 시점·취소·환급은 별도로 확인한다. 최초 부여 등 다른 던전 변화 작업의 비용도 함께 확정하지 않는다.

## 확인된 교체 재료의 공유

**장비 옵션 교체의 기본 재료를 파밍 던전의 패널티 교체에도 사용**한다. 사용자는 별도 전용 재화 한 종류를 두는 대안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0070](../Decisions/DEC-0070-share-equipment-replacement-material-with-dungeon-penalty-replacement.md)에 기록했다.

장비 제작의 [작업별 기본 재료 4종](../Decisions/DEC-0038-dedicated-basic-materials-for-each-crafting-operation.md)은 유지한다. 이번 결정은 그중 옵션 교체 재료의 사용처를 공유하는 범위다. 두 작업의 소모량·실행 조건·추첨 확률·횟수 규칙을 같게 두거나 접두·접미 통제를 던전 변화에 적용하는 승인은 아니다. 최초 패널티 부여 등 다른 변화 작업에 같은 재료를 쓰는지도 별도로 확인한다.

## 확인된 반복 교체의 비용 원칙

**다른 조건이 같으면 패널티 교체 횟수가 늘어도 한 번의 소모량을 유지**한다. 누적 교체 횟수만으로 비용을 올리지 않는다. 사용자는 교체할수록 비용이 증가하는 대안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0071](../Decisions/DEC-0071-no-cost-escalation-for-repeated-dungeon-penalty-replacement.md)에 기록했다.

이번 결정은 반복 횟수에 따른 비용 증가 여부까지다. 교체 횟수 제한 여부는 아래와 같이 확인했다. 실제 소모량·공급과 실행 조건은 별도로 확인한다. 서로 다른 던전 조건 사이에서도 같은 비용을 적용하는 승인은 아니다. 장비 옵션 교체와 던전 패널티 교체의 소모량을 같게 두는지도 별도 확인 사항이다.

## 확인된 패널티 교체 횟수

패널티 교체에 **별도 횟수 제한을 두지 않는다**. 매번 필요한 재료를 소모하고 실행 조건을 충족하면 계속 교체할 수 있다. 사용자는 재료 소모 외에 정해진 횟수까지만 교체하는 대안과 비교해 이 1안을 선택했다. 확인 근거는 [DEC-0073](../Decisions/DEC-0073-no-attempt-limit-for-dungeon-penalty-replacement.md)에 기록했다.

이번 결정은 패널티 교체의 횟수 제한 여부까지다. 실제 소모량·공급과 다른 실행 조건은 별도로 확인한다. 성공·실패 후 설정 처리는 아래와 같이 확인했다. 자동 연속 교체, 파밍 입장·재시도 횟수, 나머지 설정 유지 범위·취소·환급은 별도로 확인한다.

## 확인된 파밍 성공 후 설정 초기화

파밍 대상을 **성공적으로 클리어하면 패널티와 연결된 보상 강화 설정을 초기화**한다. 같은 대상에 다시 도전할 때 이전 설정을 자동으로 유지하지 않는다. 사용자는 설정을 유지하는 1안과 비교해 2안 클리어 후 설정 초기화를 선택했다. 확인 근거는 [DEC-0074](../Decisions/DEC-0074-reset-farming-dungeon-modifiers-after-successful-clear.md)에 기록했다.

이번 결정은 성공 후 설정 초기화까지다. 초기화 뒤 다시 패널티를 부여하는 방식·시점·비용, 반복 입장 비용과 재료 재소모, 보상 지급량·정산 시점은 별도로 확인한다. 실패 후 설정의 초기화는 아래와 같이 확인했다. 재시도 조건, 다른 대상 전환·앱 재접속 시 처리, 잠금 체크 상태의 유지와 자동 반복 입장은 별도로 확인한다. 초기화를 새 패널티의 자동 무작위 부여와 같은 동작으로 정하지 않는다.

## 확인된 파밍 실패 후 설정 초기화

파밍에서 **클리어에 실패해도 패널티와 연결된 보상 강화 설정을 초기화**한다. 성공·실패 모두 도전 종료 후 해당 설정을 유지하지 않는 방향이다. 사용자는 실패 후 설정 유지인 1안과 비교해 2안 실패해도 초기화를 선택했다. 확인 근거는 [DEC-0075](../Decisions/DEC-0075-reset-farming-dungeon-modifiers-after-failure.md)에 기록했다.

이번 결정은 실패 후 설정 초기화까지다. 교체 재료의 환급은 아래와 같이 확인했다. 실패 판정 기준, 재시도 허용·횟수·비용, 초기화 뒤 다시 설정하는 방식·시점·비용, 실패 보상과 다른 작업의 환급·취소는 별도로 확인한다. 다른 대상 전환·앱 재접속이나 잠금 체크 상태의 처리는 이번 결정의 범위가 아니다.

## 확인된 실패 시 패널티 교체 재료의 환급

**실패한 도전의 패널티 교체에 이미 사용한 재료는 환급하지 않는다.** 사용자는 전액 환급하는 2안과 비교해 1안 환급 없음을 선택했다. 확인 근거는 [DEC-0076](../Decisions/DEC-0076-no-refund-of-dungeon-penalty-replacement-materials-after-failure.md)에 기록했다.

이번 결정은 해당 실패 도전에 연결된 패널티 교체 재료의 환급 여부까지다. 파밍 재도전의 허용과 입장 자체의 별도 비용 없음은 아래와 같이 확인했다. 재도전 횟수·기타 조건, 실패 보상, 최초 패널티 부여 등 다른 작업의 비용·환급, 취소·중단·접속 종료 처리는 별도로 확인한다. 실제 소모량과 공급도 미정이다. 설정 초기화와 재료 환급은 서로 다른 규칙으로 기록한다.

## 확인된 파밍 실패 후 재도전과 입장 비용

**실패 후 같은 파밍 대상에 새 도전을 허용하며, 재도전 입장 자체에는 별도 비용을 두지 않는다.** 사용자는 재도전 입장에 별도 재화를 소모하는 2안과 비교해 1안을 선택했다. 확인 근거는 [DEC-0077](../Decisions/DEC-0077-allow-farming-retries-without-separate-entry-cost.md)에 기록했다.

초기화된 설정 상태에서의 새 도전이며 실패 전 설정을 복구하지 않는다. 이번 결정은 재도전 허용과 입장 자체의 비용까지다. 최초 부여 작업의 단위는 아래와 같이 확인했다. 재도전 횟수·대기 시간·기타 조건, 최초 부여의 실제 개수·재료·비용·시점과 교체의 실제 소모량·공급, 실패 보상·자동 반복 입장은 별도로 확인한다. 재도전 입장 무료를 최초 입장이나 던전 변화 작업 전체의 무료화로 확장하지 않는다.

## 확인된 최초 패널티 부여 작업의 단위

**최초 기본 패널티들을 한 번의 작업으로 무작위 부여**한다. 사용자는 한 개씩 무작위 추가하는 2안과 비교해 1안을 선택했다. 확인 근거는 [DEC-0078](../Decisions/DEC-0078-initial-farming-dungeon-penalties-generated-as-one-random-batch.md)에 기록했다.

이번 결정은 최초 부여 작업의 단위까지다. 개수의 무작위 결정은 아래와 같이 확인했다. 재화별 개수 범위·확률·최대 개수와 이후 추가 허용 여부, 부여 재료·소모량·공급·시점·실행 조건, 패널티 없는 입장 허용·중복·삭제·보상 강화 규칙은 별도로 확인한다. 기본 패널티들의 일괄 부여를 기존 설정 전체를 다시 추첨하는 별도 작업이나 자동 부여로 확대하지 않는다. 이후에는 기존에 확인한 한 줄 교체·나머지 보존을 유지한다.

## 확인된 재화에 따른 무작위 패널티 개수

**최초 패널티 개수는 효과 부여에 사용하는 재화에 따라 무작위로 결정**한다. 사용자는 고정 개수 비교에 대해 이 방향을 직접 지정했다. 확인 근거는 [DEC-0082](../Decisions/DEC-0082-currency-dependent-random-count-for-initial-dungeon-penalties.md)에 기록했다.

최초 패널티들을 한 번에 부여하는 기존 범위를 유지한다. 재화별로 개수를 추첨하는 원칙까지 확인했으며 재화 종류 수·이름·장비 제작 재료 공유 여부, 개수 범위·확률·최대 개수·소모량·공급과 보상 강화 규칙은 별도로 확인한다. PoE의 통화 이름·희귀도 단계·실제 개수 범위·확률을 우리 게임의 값으로 확정하지 않는다. 한 줄 교체는 기존대로 한 개를 바꾸고 나머지를 보존하며, 이 결정으로 전체 개수를 다시 추첨하는 작업으로 바꾸지 않는다.

## 다음 확인인 최초 부여 재화의 종류 수

아래 두 안은 아직 승인되지 않은 제안이다. **최초 패널티 부여에 사용할 재화 종류 수**를 비교한다. 각 재화에 맞는 개수 추첨 규칙을 두는 방향이며 구체적인 범위·확률은 이후 확인한다.

| 대안 | 부여 재화 종류 수 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 2종으로 시작 — 추천 | 두 종류의 재화에 맞춰 개수 추첨 규칙을 구분 | 익히고 관리할 부여 규칙을 줄일 수 있음. 두 규칙 사이의 선택이 의미 있는지는 범위·확률·비용을 정한 뒤 검증 필요 |
| 2안: 3종으로 시작 | 세 종류의 재화에 맞춰 개수 추첨 규칙을 구분 | 선택할 추첨 규칙을 세분화할 수 있음. 재화와 규칙을 하나 더 익히고 관리해야 함 |

라이트한 준비 과정을 유지하면서 재화 선택을 제공하도록 **1안**을 권장한다. 이는 추천이며 아직 채택된 규칙이 아니다.

이번 질문은 최초 부여에 사용할 재화 종류 수까지다. 기존 장비 제작 재료를 공유할지 새 전용 재화를 추가할지, 이름·개수 범위·확률·등급 간 관계·최대 개수·소모량·공급·보상 강화는 별도로 확인한다. 재화 종류를 나눈다고 비싼 재화가 언제나 더 많은 패널티나 더 좋은 결과를 보장한다고 정하지 않는다. 기존 장비 제작 기본 재료 4종과 별도 통제 재료를 변경하는 승인도 아니다.

## 후속 확인 범위

- 나머지 설정 유지 범위: 성공·실패 후 초기화와 재도전 허용을 유지하며 재도전 횟수·기타 조건·설정 변경 가능 여부, 다른 대상 전환·앱 재접속 시 처리와 초기화 뒤 재설정 방식 확인.
- 재화: 공유 재료의 이름·공급·소모량·소모 시점, 다른 변화 작업의 재화 종류, 재도전 시 재소모와 다른 작업의 환급·취소·중단 처리. 실패한 도전의 교체 재료 환급 없음은 유지.
- 패널티: 종류·수치·개수·중첩·확률, 삭제·취소·되돌리기·같은 종류 재등장과 빌드가 감당하기 어려운 조합의 처리.
- 보상: 수량·품질·특정 재료 등의 강화 대상, 지급 조건과 실패 보상, 반복 수령 조건.
- 안내: 패널티와 보상의 공개 범위, 현재 빌드가 받는 영향의 설명.
- 경쟁과의 연결: 모딩 미적용과 공통 도전 조건을 유지하며 기록 인정·동률·다른 성장 요소와 비교 조건 확인.

보상 강화는 이미 획득한 희귀 장비의 성급을 바꾸거나 성급별 옵션 등급 허용 범위를 무시하는 승인이 아니다. 장비 제작의 접두·접미 3개씩, 통제 재료, 별도 실패 판정 없음 등의 규칙을 던전 변화에 자동 적용하지 않는다.

## 검증 계획

최초 부여 재화의 종류 수를 확인한 뒤 기존 재료 공유 여부·재화별 개수 범위·확률·최대 개수·추가 허용·비용·재도전 횟수·기타 조건·공급·보상·나머지 지속 범위·기본 잠금 상태·전체 잠금 처리를 제안한다. 규칙과 수치를 확인받으면 서로 다른 빌드의 패널티 대응, 성공률과 시간당 제작 재료 획득, 반복 설정 부담을 검증한다. 최고 단계 경쟁에는 모딩이 적용되지 않고 공통 도전 조건을 유지하는지도 확인한다.

현재는 도입 방향·파밍 적용 범위·무작위 부여·한 개 교체·줄 우측 잠금 토글·한 줄만 잠금 해제하는 연동·새 결과 즉시 적용·교체 실행마다 재화 소모·장비 옵션 교체 재료와의 공유·반복 횟수에 따른 비용 증가와 별도 교체 횟수 제한 없음·파밍 성공·실패 후 설정 초기화·실패 시 교체 재료 환급 없음·파밍 재도전 허용과 입장 자체의 별도 비용 없음·최초 패널티 일괄 무작위 부여·부여 재화에 따른 개수 무작위 결정을 기록하고 미승인 최초 부여 재화의 종류 수를 비교했다. 던전 변화 기능·수치·화면을 구현하거나 경제·재미 검증을 수행하지 않았다.
