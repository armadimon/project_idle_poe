# 파밍 던전 변화 제안 결과

이 문서에서 검토한 준비·변경, 패널티·보상, 수급·정산 묶음은 사용자 확인을 거쳐 [파밍 던전 변화 기획서](../Systems/Farming-Dungeon-Modification.md)에 통합했다.

| 승인 묶음 | 기록 |
| --- | --- |
| 준비·변경 기본 동작 | [DEC-0090](../Decisions/DEC-0090-farming-dungeon-preparation-and-modification-rules.md) |
| 패널티·보상 콘텐츠 | [DEC-0092](../Decisions/DEC-0092-farming-dungeon-penalties-and-bonus-drops.md) |
| 수급·정산과 접속 중단 | [DEC-0094](../Decisions/DEC-0094-farming-dungeon-supply-settlement-and-resume.md) |

현재 적용할 규칙은 기능 기획서에서 읽고 세부 승인 근거는 연결된 이력에서 확인한다. 미승인 추천을 확정 규칙으로 취급하지 않는다.

[장비 득템·파밍 대상 구성](../Systems/Equipment-Drops-and-Farming-Targets.md)도 [DEC-0095](../Decisions/DEC-0095-equipment-drops-and-farming-targets.md)에서 확인했다. 장비 부위·계열·기반 역할은 [DEC-0096](../Decisions/DEC-0096-equipment-catalog-and-base-structure.md)의 [장비 구성 기획서](../Systems/Equipment-Catalog-and-Base-Structure.md)에서 확인했다. 기반 성능·특성 수치와 개별 옵션·전투 계산은 [DEC-0097](../Decisions/DEC-0097-equipment-affixes-base-stats-and-combat-numbers.md)의 [옵션·전투 기획서](../Systems/Equipment-Affixes-and-Combat-Numbers.md)에서 확인했다. 제작 실행·비용·확률·종료는 [DEC-0098](../Decisions/DEC-0098-crafting-execution-costs-odds-and-recovery.md)에서 확인했고 [기본 제작 기획서](../Systems/Equipment-Crafting.md)에 모았다. 장비 보관·비교·교체·분해는 [DEC-0100](../Decisions/DEC-0100-equipment-inventory-comparison-and-salvage.md)에서 확인했고 [장비 관리 기획서](../Systems/Equipment-Inventory-Comparison-and-Salvage.md)에 통합했다. 입장 전 1/2칸의 장비 보상 공간과 가방 정리 복귀 시 준비 보존을 따른다. [DEC-0102](../Decisions/DEC-0102-initial-crafting-scope-without-extra-special-crafting.md)에서 첫 제작은 기본 4종과 집중석부터 검증하는 A안으로 확인했다. 고유 공통 규칙은 [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)의 2안(B)으로 확인했고 [기능 기획서](../Systems/Unique-Equipment-Role-Acquisition-and-Handling.md)에 통합했다. 다음 미승인 묶음은 [첫 고유 3종의 효과·수치·중복과 빌드 검증](Unique-Equipment-Effects-and-Build-Cases.md)이다.

## 조사와 검증 상태

[맵 모딩 조사](../../Research/2026-11-17-dungeon-modification.md), [재화별 생성 조사](../../Research/2026-11-18-currency-dependent-dungeon-penalty-counts.md), [패널티·보상 조사](../../Research/2026-11-18-dungeon-penalties-and-rewards.md)에 출처·버전·라이선스·재사용 범위와 실제 실행 미검증을 기록했다.

승인 수량과 확률은 초기 기획 수치다. 구현·실제 난도·경제 검증을 완료했다는 뜻이 아니다. 구현 전에 기술 조사와 적용·검증 계획을 제안하고 확인받는다.
