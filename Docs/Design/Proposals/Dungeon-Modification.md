# 던전 변화 시스템과 패널티 재추첨 제안

## 확인된 방향

사용자는 **재화를 소모해 던전에 패널티를 추가하고 보상을 높이는 시스템**을 기획에 포함하도록 요청했다. PoE의 맵 모딩을 참고하는 도입 방향은 [DEC-0060](../Decisions/DEC-0060-currency-funded-dungeon-penalties-and-better-rewards.md)에 기록했다. [무료 재도전 입장](../Decisions/DEC-0059-no-separate-entry-cost-for-competition-retries.md)은 별도 원칙으로 유지한다.

던전 변화는 [DEC-0061](../Decisions/DEC-0061-dungeon-modification-for-farming-only.md)에 따라 **파밍에만 적용**한다. **최고 도달 단계 경쟁은 이 변화를 적용하지 않고 공통 도전 조건을 유지**한다. 패널티는 [DEC-0062](../Decisions/DEC-0062-randomly-assign-farming-dungeon-penalties.md)에 따라 플레이어가 고르지 않고 무작위로 부여한다. 패널티 종류·개수·수치·추첨 확률과 재추첨·삭제 허용 여부, 보상 강화의 종류·수치와 지속 범위는 아직 정하지 않았다.

## 조사에서 참고한 부분

GGG의 개발 회고에서 비용·위험·보상을 연결한 설계 의도를, PoEDB에서 던전 변화와 보상 관련 표현을, 커뮤니티·poe.re에서 빌드별 맵 옵션 대응과 필터·설정 공유 사례를 확인했다. 구체적인 출처·확인 버전·라이선스·Unity 호환성과 실제 실행 미검증 범위는 [맵 모딩 조사](../../Research/2026-11-17-dungeon-modification.md)에 둔다.

우리 게임에 적용할 패널티와 경제 규칙은 자체 설계한다. PoE의 통화·지도 아이템·옵션 개수·아틀라스·실패 제한이나 오픈소스 데이터는 가져오지 않는다.

## 확인된 적용 범위

던전 변화는 **파밍에 적용하고 경쟁 기록에는 적용하지 않는다.** 사용자는 최고 단계 경쟁에도 적용하는 대안과 비교해 이 1안을 선택했다. 파밍에서 얻은 장비·재료를 제작과 빌드 개선에 활용하고, 최고 단계 경쟁은 공통 도전 조건에서 성과를 비교한다. 확인 근거는 [DEC-0061](../Decisions/DEC-0061-dungeon-modification-for-farming-only.md)에 기록했다.

이번 결정은 적용 범위까지다. 별도 던전·모드·입장 화면의 구성, 경쟁의 구체적인 공통 조건·기록 인정·동률 처리는 아직 정하지 않았다. 장비·스킬이나 그 밖의 캐릭터 능력치를 통일하는 승인도 아니다.

## 확인된 패널티 부여 방식

**패널티는 플레이어가 고르지 않고 무작위로 부여**한다. 사용자는 무작위 후보 중 선택·무작위 부여·직접 지정의 세 대안 중 2안 무작위 부여를 선택했다. 확인 근거는 [DEC-0062](../Decisions/DEC-0062-randomly-assign-farming-dungeon-penalties.md)에 기록했다.

이번 결정은 부여 방식까지다. 패널티의 종류·수치·개수·중첩과 추첨 확률, 재추첨·삭제·교체·취소와 추가 통제 수단의 허용 여부, 재화 소모 시점과 비용·보상 수치는 별도 확인한다. 무작위 부여를 선택했다는 이유로 모든 패널티를 같은 확률로 뽑거나 전투마다 자동으로 새로 뽑는 규칙을 확정하지 않는다.

## 다음 확인인 패널티 재추첨의 허용 범위

아래 세 안은 아직 승인되지 않은 제안이다. 부여된 패널티 조합을 다시 무작위로 바꿀 수 있는 범위를 비교한다. 재추첨에 드는 재화와 소모 시점은 별도로 확인한다.

| 대안 | 패널티를 바꾸는 범위 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 전체 무작위 재추첨 — 추천 | 현재 패널티 조합 전체를 다시 추첨할 수 있음 | 작업이 단순하고 감당할 조합을 다시 노릴 수 있음. 유지하고 싶은 패널티도 함께 바뀔 수 있음 |
| 2안: 하나를 지정해 무작위 교체 | 플레이어가 바꿀 패널티 하나를 지정하고 나머지는 유지 | 기존 조합을 보존하면서 다듬을 수 있음. 대상 선택과 비용·확률 설계가 더 복잡해짐 |
| 3안: 재추첨 없음 | 부여된 패널티를 재추첨으로 바꾸지 않음 | 결과를 받아들이는 구조가 단순함. 빌드에 불리한 조합을 수정할 수단이 줄어듦 |

무작위 모딩을 단순한 작업으로 유지하면서 불리한 조합을 다시 바꿀 여지를 주기 위해 **1안**을 권장한다. 개별 패널티를 보존·지정하는 조작을 늘리지 않고 결과의 변화를 제공하는 방향이다. 이는 추천이며 채택된 규칙이 아니다.

이번 질문은 재추첨의 허용 범위까지다. 재추첨 횟수·비용·소모 시점·실행 조건, 패널티 개수의 유지 여부, 종류와 수치의 상세 추첨, 새 결과의 즉시 적용 또는 기존 결과와 선택, 보상 변경과 취소·환급은 별도로 확인한다. 3안을 선택해도 패널티 해제나 다른 던전으로 변경하는 규칙까지 자동으로 정하지 않는다.

## 후속 확인 범위

- 변화의 단위와 지속 범위: 한 전투·단계·던전 또는 다른 범위, 파밍 실패 후 재시도의 허용 여부와 변화 유지·변경 가능 여부.
- 재화: 종류·공급·소모량·소모 시점, 재도전 시 재소모와 실패·취소 시 환급.
- 패널티: 종류·수치·개수·중첩, 해제·교체·재추첨과 빌드가 감당하기 어려운 조합의 처리.
- 보상: 수량·품질·특정 재료 등의 강화 대상, 지급 조건과 실패 보상, 반복 수령 조건.
- 안내: 패널티와 보상의 공개 범위, 현재 빌드가 받는 영향의 설명.
- 경쟁과의 연결: 모딩 미적용과 공통 도전 조건을 유지하며 기록 인정·동률·다른 성장 요소와 비교 조건 확인.

보상 강화는 이미 획득한 희귀 장비의 성급을 바꾸거나 성급별 옵션 등급 허용 범위를 무시하는 승인이 아니다. 장비 제작의 접두·접미 3개씩, 통제 재료, 별도 실패 판정 없음 등의 규칙을 던전 변화에 자동 적용하지 않는다.

## 검증 계획

패널티 재추첨 범위를 확인한 뒤 비용·보상·지속 범위를 제안한다. 규칙과 수치를 확인받으면 서로 다른 빌드의 패널티 대응, 성공률과 시간당 제작 재료 획득, 반복 설정 부담을 검증한다. 최고 단계 경쟁에는 모딩이 적용되지 않고 공통 도전 조건을 유지하는지도 확인한다.

현재는 도입 방향·파밍 적용 범위·무작위 부여를 기록하고 미승인 재추첨 범위를 비교했다. 던전 변화 기능·수치·화면을 구현하거나 경제·재미 검증을 수행하지 않았다.
