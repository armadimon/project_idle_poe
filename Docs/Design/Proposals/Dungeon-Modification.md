# 파밍 던전 패널티·보상 콘텐츠 묶음 제안

상태: 아래 콘텐츠 묶음은 아직 승인되지 않았다. 확정된 [파밍 던전 변화 기획서](../Systems/Farming-Dungeon-Modification.md)와 준비·변경 묶음 [DEC-0090](../Decisions/DEC-0090-farming-dungeon-preparation-and-modification-rules.md)를 전제로 한 다음 제안이다.

## 이번에 확인할 기능

**어떤 패널티를 감수하고 어떤 추가 획득 기회를 얻는지**를 한 번에 확인한다. 아래 종류·수치·추첨·보상·표시는 모두 이번에 확인할 제안이며 묶음 전체 승인이나 항목별 수정이 가능하다.

## 초기 패널티 6종

각 종류의 강도는 우선 아래 고정값 하나로 시작한다. 추가 강도 등급이나 수치 재추첨은 제공하지 않는 안이다. 비율 변화는 해당 효과를 적용하기 전 계산값에 한 번 곱한다.

| 종류 | 제안 효과 | 주로 확인할 대응 |
| --- | --- | --- |
| 두꺼운 생명력 | 몬스터 최대 생명력 30% 증가 | 지속 화력과 처치 시간 |
| 강한 공격 | 몬스터가 주는 피해 20% 증가 | 방어와 생존 |
| 빠른 공격 | 몬스터 공격속도 15% 증가 | 연속 피격 대응 |
| 회복 약화 | 플레이어가 받는 생명력 회복량 30% 감소 | 회복에 의존하는 정도 |
| 치명타 약화 | 플레이어 치명타 확률 30% 감소 | 치명타에 의존하는 정도 |
| 지속 피해 약화 | 플레이어가 주는 지속 피해 30% 감소 | 지속 피해에 의존하는 정도 |

회복 약화는 생명력 회복량을 0.70배로 만들되 최대 생명력 자체를 줄이는 효과가 아니다. 치명타 확률 감소는 30%p 차감이 아니라 기존 확률의 0.70배다. 몬스터 공격속도는 1.15배이며 이동·시전속도를 함께 올리는 효과로 확대하지 않는다. 치명타·지속 피해 관련 항목은 해당 빌드를 평가할 패널티 규칙이며 정식 스킬·성장 시스템 전체나 해당 빌드의 콘텐츠 구현 승인으로 확장하지 않는다.

이번 초기 구성에는 피해 반사·회복 완전 차단·스킬 사용 금지 같은 기능 봉쇄형을 넣지 않는 안이다. 수치는 PoE에서 가져온 값이 아니라 우리 게임의 미승인 출발 제안이다.

## 추첨과 한 줄 교체

| 항목 | 제안 규칙 |
| --- | --- |
| 최초 종류 추첨 | 승인된 개수에 맞춰 위 6종 중 같은 확률로 중복 없이 추첨 |
| 동일 종류 중복 | 한 도전에 같은 종류는 한 줄만 허용 |
| 한 줄 교체 후보 | 잠긴 나머지 줄에 있는 종류를 제외한 후보에서 같은 확률로 추첨 |
| 방금 교체한 종류 | 제거된 종류도 후보에 포함하므로 같은 결과가 다시 나올 수 있음 |
| 조합 | 종류 중복 외 별도 조합 금지는 두지 않음. 실제 위험 조합은 검증해 조정 |

기존 개수별 확률인 추가 재료 1개·2개 각각 50%, 교체 재료 3개·4개 각각 50%는 유지한다. 종류별 추첨 확률과 이미 승인된 개수별 확률을 구분한다. 6종에서 최대 4개를 중복 없이 만들므로 최초 추첨 후보가 모자라지 않는 구성이다.

## 보상 강화

강화 대상은 **장비와 제작재료의 추가 드롭 기회**로 한정하는 안이다. 패널티 한 줄당 추가 추첨 확률을 20%p 더한다.

| 패널티 개수 | 기본 드롭 추첨마다 추가 1회 추첨할 확률 | 클리어 성공 시 평균 드롭 기대량의 배율 |
| --- | --- | --- |
| 0개 | 0% | 1.0배 |
| 1개 | 20% | 1.2배 |
| 2개 | 40% | 1.4배 |
| 3개 | 60% | 1.6배 |
| 4개 | 80% | 1.8배 |

각 기본 장비·제작재료 드롭 추첨마다 해당 확률로 같은 보상 범주의 기본 테이블을 추가로 한 번 독립 추첨한다. 추가 추첨에는 이 보너스를 다시 적용하지 않는다. 기본 추첨의 성공·실패와 별개로 같은 테이블에서 추첨하며, 평균 배율은 실제 획득량을 매번 보장하는 수치가 아니다.

장비 성급·옵션 등급·희귀도와 드롭 후보 가중치는 기본 테이블을 따른다. 경험치·골드·랭킹 기록 등 다른 보상에는 이 배율을 자동 적용하지 않는다. 기본 제작 재료 4종과 통제 재료의 공급 테이블 자체를 이번 질문으로 확정하지 않는다.

같은 개수를 유지하는 한 줄 교체는 추가 드롭 확률을 바꾸지 않는다. 빌드가 감당할 패널티로 바꾸는 판단에 집중하게 하는 안이다. 모딩으로 생긴 추가 보상은 클리어 성공 때 정산하며 실패하면 그 추가분은 지급하지 않는다. 기본 보상이나 진행 중 획득물의 실패 처리는 수급·종료 예외 묶음에서 확인한다.

## 정보 표시

전투 전 준비 화면에 실제 패널티 효과·현재 줄 수·장비와 제작재료의 추가 드롭 확률을 함께 표시한다. 예를 들어 3개면 추가 추첨 확률 60%라고 안내한다. 관련 효과에는 생존·회복·치명타·지속 피해 같은 영향 태그를 붙여 직접 확인하게 하되, 자동 안전 판정이나 성공 보장을 제공하는 승인은 아니다.

## 대안과 권장 이유

대안은 패널티에 강도 등급과 서로 다른 위험 점수를 두고 점수 합으로 보상을 높이는 방식이다. 더 강한 결과를 노리고 다듬는 폭이 커지지만 읽어야 할 수치·희소성·보상 관계와 교체 판단도 늘어난다.

우선 위 **고정 강도 6종 + 동일 확률·중복 금지 + 줄 수에 따른 추가 드롭 기회** 묶음을 권장한다. 모바일에서 확인할 정보를 줄이면서 빌드에 따라 덜 불리한 조합을 만드는 판단을 제공하려는 설계다. 같은 줄 수에도 실제 위험이 다르고 교체 재료 소비가 달라질 수 있어 난도·경제 검증이 필요하다.

## 조사와 검증 계획

[패널티·보상 조사](../../Research/2026-11-18-dungeon-penalties-and-rewards.md)에 PoEDB·GGG 개발 회고·빌드 작성자와 커뮤니티의 출처, 확인 버전·라이선스·재사용 범위와 실제 실행 미검증을 구분했다. 원본 문구·수치·게임 데이터를 복사하거나 새 라이브러리를 도입하지 않았다.

승인 뒤 0~4개 구성의 추첨 분포·중복 방지·같은 결과 재등장과 나머지 줄 보존, 보상 기대량·추가 추첨의 비재귀·성공 정산을 검증한다. 서로 다른 회복·치명타·지속 피해 의존도의 빌드에서 완주 성과·재료 순소비·시간당 장비와 제작재료 획득을 비교한다. 이 기능의 수치를 승인해도 모든 빌드의 난도나 재료 수급이 균형을 이룬 것으로 처리하지 않는다.

다음 수급·종료 예외 묶음에서 공급 테이블·기본 실패 보상·최초 부여 재료 환급·취소·접속 종료·대상 전환·재도전 조건을 함께 확인한다. 이번에는 기획 제안만 작성했으며 콘텐츠·확률·보상 기능과 실제 수치를 구현하지 않았다.
