# 던전 변화 시스템의 도입 방향과 적용 범위 제안

## 확인된 방향

사용자는 **재화를 소모해 던전에 패널티를 추가하고 보상을 높이는 시스템**을 기획에 포함하도록 요청했다. PoE의 맵 모딩을 참고하는 도입 방향은 [DEC-0060](../Decisions/DEC-0060-currency-funded-dungeon-penalties-and-better-rewards.md)에 기록했다. [무료 재도전 입장](../Decisions/DEC-0059-no-separate-entry-cost-for-competition-retries.md)은 별도 원칙으로 유지한다.

확인된 것은 재화 소비와 패널티·보상 강화를 연결한다는 방향까지다. 파밍·경쟁의 적용 대상, 패널티 부여 방식·종류·수치, 보상 강화의 종류·수치와 지속 범위는 아직 정하지 않았다.

## 조사에서 참고한 부분

GGG의 개발 회고에서 비용·위험·보상을 연결한 설계 의도를, PoEDB에서 던전 변화와 보상 관련 표현을, 커뮤니티·poe.re에서 빌드별 맵 옵션 대응과 필터·설정 공유 사례를 확인했다. 구체적인 출처·확인 버전·라이선스·Unity 호환성과 실제 실행 미검증 범위는 [맵 모딩 조사](../../Research/2026-11-17-dungeon-modification.md)에 둔다.

우리 게임에 적용할 패널티와 경제 규칙은 자체 설계한다. PoE의 통화·지도 아이템·옵션 개수·아틀라스·실패 제한이나 오픈소스 데이터는 가져오지 않는다.

## 다음 확인인 적용 범위

아래 두 안은 아직 승인되지 않은 제안이다. 보상 획득을 위한 플레이와 최고 도달 단계의 기록 측정을 기준으로 던전 변화의 적용 범위를 비교한다. 별도 던전·모드·입장 화면의 구성을 이 질문에 함께 묶지 않는다.

| 대안 | 적용 범위 | 장점과 검토할 부담 |
| --- | --- | --- |
| 1안: 파밍에 적용, 경쟁 기록에는 미적용 — 추천 | 보상 획득 플레이의 패널티·보상을 변화시키고, 최고 단계 경쟁은 공통 도전 조건으로 측정 | 모딩으로 얻은 재료·장비를 제작과 빌드 개선에 연결하고 경쟁의 비교 조건을 설명하기 쉬움. 모딩 판단 자체를 경쟁 기록에 반영하는 폭은 줄어듦 |
| 2안: 최고 단계 경쟁에도 적용 | 파밍과 경쟁 모두에 던전 변화를 허용 | 장비 조합과 던전 조건을 함께 준비하는 판단을 경쟁에도 반영할 수 있음. 서로 다른 패널티에서 얻은 최고 단계 기록을 어떻게 공정하게 비교할지 추가 규칙이 필요함 |

종결 장비를 제작하고 그 장비의 자동 전투 성과를 비교하는 목표에 맞춰 **1안**을 권장한다. 던전 변화는 제작에 쓸 획득물을 늘리거나 개선하는 판단에 활용하고, 경쟁에서는 장비·스킬을 비교할 조건을 명확히 두는 방향이다. 이것은 추천이며 현재 채택된 규칙이 아니다.

이번 질문은 적용 범위까지다. 2안을 선택하면 동일 조건별 비교나 기록 보정 등 대안을 다음에 확인해야 한다. 어느 안도 점수 공식·시즌·별도 콘텐츠 수를 자동으로 확정하지 않는다.

## 적용 범위 확인 뒤 남은 질문

- 패널티 부여 방식: 무작위, 원하는 패널티 직접 선택, 제시된 후보 중 선택 등.
- 변화의 단위와 지속 범위: 한 전투·단계·던전 또는 다른 범위, 무료 재도전 시 유지와 변경 가능 여부.
- 재화: 종류·공급·소모량·소모 시점, 재도전 시 재소모와 실패·취소 시 환급.
- 패널티: 종류·수치·개수·중첩, 해제·교체·재추첨과 빌드가 감당하기 어려운 조합의 처리.
- 보상: 수량·품질·특정 재료 등의 강화 대상, 지급 조건과 실패 보상, 반복 수령 조건.
- 안내: 패널티와 보상의 공개 범위, 현재 빌드가 받는 영향의 설명.
- 경쟁과의 연결: 적용 여부 확인 후 기록 인정·동률·다른 성장 요소와 비교 조건.

보상 강화는 이미 획득한 희귀 장비의 성급을 바꾸거나 성급별 옵션 등급 허용 범위를 무시하는 승인이 아니다. 장비 제작의 접두·접미 3개씩, 통제 재료, 별도 실패 판정 없음 등의 규칙을 던전 변화에 자동 적용하지 않는다.

## 검증 계획

적용 범위를 확인한 뒤 패널티 부여 방식과 비용·보상·지속 범위를 제안한다. 규칙과 수치를 확인받으면 서로 다른 빌드의 패널티 대응, 성공률과 시간당 제작 재료 획득, 반복 설정 부담을 검증한다. 최고 단계 경쟁에 적용하는 경우 동일 조건 비교가 가능한지도 확인한다.

현재는 방향 기록과 미승인 대안 비교를 마쳤다. 던전 변화 기능·수치·화면을 구현하거나 경제·재미 검증을 수행하지 않았다.
