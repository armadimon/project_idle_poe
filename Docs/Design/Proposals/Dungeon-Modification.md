# 파밍 수급·정산 묶음 제안

상태: 아래 묶음은 아직 승인되지 않았다. [파밍 던전 변화 기획서](../Systems/Farming-Dungeon-Modification.md)의 준비·변경 규칙과 [패널티·보상 콘텐츠](../Decisions/DEC-0092-farming-dungeon-penalties-and-bonus-drops.md)를 전제로 다음 내용을 함께 확인한다.

## 이번에 확인할 기능

**입장 → 재료 투자 → 도전 → 성공·실패·중단 → 보상과 다음 도전**의 수급·정산 흐름을 한 번에 제안한다. 아래 기본 보상·공급 비율·환급·보관·정산은 모두 이번에 확인할 제안이며 묶음 전체 승인이나 항목별 수정이 가능하다.

## 입장과 기본 보상

| 항목 | 추천 묶음 |
| --- | --- |
| 입장 | 해금된 파밍 대상의 최초 입장·재입장·재도전 입장 무료 |
| 반복 조건 | 입장·재도전 횟수 제한과 대기 시간 없음 |
| 성공 기본 보상 | 희귀 장비 추첨 1회 + 제작재료 추첨 2회 |
| 기본 추첨 결과 | 각 추첨에서 해당 범주의 보상 1개를 확정 생성 |
| 모딩 추가 보상 | 이미 승인한 패널티 수 × 20% 확률의 추가 1회 추첨을 각 기본 추첨에 적용 |
| 실패·자발적 중도 포기 | 해당 도전의 기본 보상과 모딩 추가 보상 모두 지급하지 않음 |

입장 무료는 해금된 파밍 대상에 적용하며 대상 해금 조건을 확정하지 않는다. 패널티 없이도 기본 성공 보상을 얻을 수 있다. 장비 성급·기반·옵션 분포와 구체적인 대상별 드롭 후보는 후속 **장비 득템·파밍 대상 구성** 묶음에서 정한다. 이미 승인한 성급 체계와 드롭·제작의 옵션 제한은 유지한다.

제작재료의 두 기본 추첨은 각각 독립적으로 수행해 같은 재료가 두 번 나올 수 있다. 모딩 추가 추첨은 같은 범주의 기본 테이블을 사용하고 추가 추첨에 보너스를 다시 적용하지 않는다. 예를 들어 4줄을 감당해 성공하면 장비 평균 1.8개·제작재료 평균 3.6개이며 매번 해당 수량을 보장하는 것은 아니다.

## 제작재료 공급 비율

각 제작재료 추첨에서 아래 5종 중 하나를 1개 생성하는 안이다. 기본 추첨과 모딩 추가 추첨에 같은 비율을 사용한다.

| 기본·통제 재료 | 한 번의 재료 추첨에서 나올 확률 |
| --- | --- |
| 옵션 추가 기본 재료 | 30% |
| 옵션 제거 기본 재료 | 15% |
| 옵션 교체 기본 재료 | 35% |
| 수치 재추첨 기본 재료 | 15% |
| 접두·접미 공통 통제 재료 | 5% |

던전 최초 부여·한 줄 교체와 장비 제작에 쓰이는 추가·교체 재료의 공급 비중을 높인 출발안이다. 장비 제작 자체의 한 번 소모량·재료 이름·교환·과금 공급이나 다른 콘텐츠의 보상 테이블을 이번 질문으로 정하지 않는다.

## 소비·종료·재접속

| 상황 | 추천 처리 |
| --- | --- |
| 최초 부여·한 줄 교체 확정 | 결과 확정과 해당 재료 1개 차감을 함께 처리. 무효 동작은 재료를 차감하지 않음 |
| 성공·실패·중도 포기 | 사용한 최초 부여·한 줄 교체 재료는 환급하지 않음 |
| 전투 전 준비 취소·대상 변경 | 기존 설정 초기화, 이미 사용한 재료 환급 없음. 설정을 버리기 전에 안내와 확인 제공 |
| 준비 중 앱 종료·접속 중단 | 같은 대상의 설정과 사용 재료 내역 보관. 복귀 시 그대로 준비 재개 |
| 전투 중 앱 종료·접속 중단 | 진행 중인 파밍 도전 일시정지. 복귀 시 같은 상태에서 이어하기 |
| 재접속과 정산 | 재접속으로 재추첨·재소모·보상 중복이 발생하지 않게 동일 도전을 한 번만 정산 |
| 성공 뒤 다음 도전 | 기본 보상과 승인된 모딩 추가 보상을 정산하고, 기존 규칙대로 패널티·보상 강화 설정 초기화 |

접속 중단만으로 실패·포기로 처리하지 않는다. 중단한 파밍 도전은 닫혀 있는 동안 전투를 진행하지 않는 안이다. 이 규칙을 계정 전체의 오프라인 보상 도입·폐지로 확대하지 않는다. 별도 오프라인 성장·보상은 해당 접속 흐름의 기획에서 확인한다.

성공·실패 후 설정 초기화와 실패한 도전의 교체 재료 환급 없음, 같은 대상의 새 도전 허용이라는 기존 규칙을 유지한다. 보상 미지급은 해당 미완주 도전에 한정하며 이전에 확보한 인벤토리 보상을 회수하는 규칙이 아니다.

## 정보 표시

입장 전에 기본 보상 추첨 횟수·재료별 공급 확률·현재 패널티의 추가 드롭 확률을 함께 확인할 수 있게 한다. 소모 작업에는 필요한 재료와 수량, 취소·대상 변경·중도 포기에는 버릴 설정과 보상·환급 처리를 안내한다. 재접속 시에는 보관된 도전을 이어한다는 점을 보여준다.

## 대안과 권장 이유

대안은 실패·포기에도 기본 보상의 일부를 지급하는 방식이다. 미완주 때의 손실을 줄일 수 있지만 실패를 반복해 재료를 얻는 경로와 부분 정산의 기준을 함께 설계해야 한다.

우선 위 **무료 반복 입장 + 성공 때 기본·추가 보상 정산 + 사용 재료 환급 없음 + 접속 중단 시 도전 보관** 묶음을 권장한다. 패널티 없는 기본 파밍으로 재료를 확보하고, 더 많은 획득 기회를 위해 투자하는 흐름을 만들려는 안이다. 모바일 접속 중단은 동일 도전 이어하기로 처리한다.

제안한 보상 횟수와 공급 비율은 아직 난도·진행 속도·경제 검증을 마친 값이 아니다. 승인 후 실험 결과로 조정이 필요하면 변경 묶음을 다시 확인받는다.

## 조사와 적용 범위

기존 [맵 모딩 조사](../../Research/2026-11-17-dungeon-modification.md)와 [패널티·보상 조사](../../Research/2026-11-18-dungeon-penalties-and-rewards.md)의 출처·확인 버전·라이선스·재사용 제약을 참고했다. 현재 추천은 우리 게임의 자체 수급·정산 설계이며 PoE의 현행 재료 드롭 확률이나 종료 정책을 그대로 채택한 것이 아니다. 새 라이브러리·외부 코드·데이터를 도입하지 않았다.

이 문서는 기획 제안이다. 드롭·재료 차감·정산·중단 복원이나 서버 저장을 구현하지 않았다. 구현 전에는 관련 공식 기술 문서·오픈소스와 현재 프로젝트의 저장·실행 환경을 조사하고 구현 방식·검증 범위를 별도로 제안한다.

## 검증 계획

승인 뒤 5종 공급 비율의 합계·추첨 분포, 기본과 모딩 추가 추첨의 독립성·비재귀, 결과 확정과 재료 차감, 성공·실패·포기·준비 취소·대상 변경·접속 중단·재접속을 연결한 정산을 검증한다. 동일 도전의 보상 중복과 접속 중단을 이용한 재추첨이 없는지 확인한다.

실제 파밍 시간과 장비 제작 소모량을 정한 뒤 패널티 0~4개별 완주 성과·재료 순소비·시간당 획득·장비 제작 시도 수를 비교한다. 아직 정하지 않은 전투 시간이나 장비 제작 비용을 임의의 검증 결과로 채우지 않는다.
