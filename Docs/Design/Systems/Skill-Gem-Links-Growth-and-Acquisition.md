# 정식 스킬·젬의 확정 방향과 초안 경계

[사용자 방향 승인](../Decisions/DEC-0106-individual-gem-growth-and-full-design-validation.md) · [전체 기획 초안](../Proposals/Skill-Gems-and-Build-Diversity.md) · [조사](../../Research/2026-11-23-poe1-skill-gem-build-layers.md) · [수치 검증](../Analysis/SkillGems/SUMMARY.md)

## 확인된 방향

사용자는 2026-11-23 **2안인 목록 제공·캐릭터 3×2 연결·액티브 젬별 경험치 성장**을 선택했다. 모든 액티브를 파밍 구간 해금에 맞춰 함께 같은 레벨로 만드는 1안은 선택하지 않았다. 액티브와 보조 젬을 늘려 조합과 빌드 컨셉을 다양하게 해야 한다고 요청했다.

이후 원본을 면밀히 조사해 경량화한 전체 기획을 작성하고, 정적 분석·테스트로 수치 검증까지 하도록 요청했다. 따라서 조각 질문마다 멈추지 않고 전체 초안과 자체 분석 결과를 작성한다.

## 세부 초안과 구분할 것

현재 **24액티브·24보조, 보조 경험치, Lv.20/XP 표, 배경 성장 25%, 요구치 20, 새 발동/전환/상태이상/비용 수치와 편성 13개**는 전체 초안의 제안이다. 원본 조사·문서/모델 검사 결과만으로 사용자 승인이나 최종 밸런스가 되지 않는다.

기존 승인된 장비·제작·고유·파밍 규칙은 유지한다. 모델의 비교용 적·캐릭터·활/망치 성능은 정본 수치로 전파하지 않는다. 로컬 프로토타입의 클래스·13액티브·4보조·3×2와 이번 정식 확장 초안, 실제 Unity 실행을 구별한다.

전체 초안을 검토하고 확인받은 범위만 후속 결정과 현행 규칙으로 통합한다. 이번 작업은 Unity 게임 데이터·전투·기존 세이브를 수정하는 요청으로 확대하지 않는다.
