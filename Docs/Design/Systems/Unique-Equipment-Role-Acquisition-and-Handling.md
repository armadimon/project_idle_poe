# 고유 장비의 역할·획득·착용·처분 기획

상태: [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)에서 직전 제안의 **2안(B), 부위가 맞는 여러 고유의 동시 착용**을 확인했다. 공통 획득·성급·수치 구조·처분 규칙은 유지하며 추천 1안의 고유 총수 1개 제한을 채택하지 않는다. 희귀 제작과 고유의 특수 효과라는 [선행 방향](../Decisions/DEC-0012-crafting-equipment-scope.md)을 구체화하고 [첫 제작 모델](Equipment-Crafting.md)에 고유 제작을 추가하지 않는다.

## 확정 공통 규칙

| 항목 | 확정 규칙 |
| --- | --- |
| 역할 | 전투 규칙·스킬 활용을 바꾸는 선택형 장비. 고유 획득을 입장·성급 해금의 필수 조건으로 두지 않음 |
| 첫 목록 | 목걸이·반지·허리띠에 각각 1종, 총 3종. 각 고유를 4성·5성으로 제공 |
| 옵션 구조 | 고유별 정해진 기반 성능과 일반 옵션 2개+특수 효과 1개. 같은 고유·성급의 모든 값 고정, 무작위 접두/접미 추첨 없음 |
| 성급·제작 | 획득 성급 고정·승급/옵션 이전 없음. 5성은 일반 성능을 높이고 특수 효과의 규칙·수치는 4성과 동일. 기본 4종 제작과 집중석 사용 불가 |
| 장착 | 부위 관계가 맞는 여러 고유를 함께 착용, 고유 총수 1개 제한 없음. 전투 밖 무료 장착·해제, 별도 성급/레벨/능력치 착용 제한 없음. 동일 고유도 부위가 허용하면 착용. 속행의 반지 두 개의 일반 수치/회복 증가 합산·감폭 곱셈은 아래 확정 규칙 적용 |
| 획득 | 4~5성의 목걸이·반지·허리띠 파밍 장비 보상 1개마다 희귀 97%·해당 부위 고유 3%. 기본·모딩 추가 장비 추첨에 동일 적용 |
| 보상 개수 | 희귀 보상의 일부를 고유로 대체. 별도 추가 장비 지급 없음·기존 최대 장비 2개와 입장 공간 1/2칸 유지 |
| 추첨·정보 | 추첨별 독립, 중복 획득 허용·천장 없음. 대상/성급·97/3%·특수 효과와 고정값을 게임 안에 공개 |
| 보관·보호 | 기존 무료 500칸 안에서 1개=1칸. 획득 시 분해 보호 기본 해제, 장착/보호 장비는 분해 금지 |
| 분해 | 미장착·보호 해제된 고유는 무료 단건 분해만. 기존 제작재료 1회 추첨·1개, 30/15/35/15/5%. 일괄 분해·전체 선택에서는 고유 제외 |

후속 [DEC-0105](../Decisions/DEC-0105-first-unique-effects-stacking-and-build-goals.md)에서 안정의 목걸이·속행의 반지·불굴의 허리띠의 기반/일반 성능·특수 효과와 수치, 동일 고유 복수 착용·중첩/무효 우선순위·장착 상태·세 빌드 검증 목표를 함께 확인했다. 아래 정의를 현행 규칙으로 적용한다. 이름은 확인한 자체 기획용 이름이며 최종 세계관/외형은 별도다.

## 역할·구조와 장착

일반 옵션 2개는 고유별로 정해진 종류와 고정값을 사용하고 희귀 장비의 무작위 6칸 추첨과 구분한다. 고유의 기반·일반 성능은 정의표에 등록할 값이며 이번에 기존 희귀 기반 목록/옵션 범위를 변경하지 않는다. 고유를 희귀로 변환하거나 희귀에서 고유로 승급시키는 작업은 추가하지 않는다.

전투 중에는 고유 장착·해제·분해를 실행하지 않는다. 장착 부위 관계를 지키며 고유라는 이유로 전체 장착 수를 1개로 제한하지 않는다. 서로 다른 부위의 고유를 함께 착용할 수 있고, 기존 고유를 해제하라는 총수 제한을 적용하지 않는다. 장비 교체는 기존 반지 교체 칸 선택·가방 수량 보존·젬 조건 재평가를 따른다. 개별 장비를 가방으로 해제할 때는 빈 칸 1개가 필요하고 부족하면 정리를 안내한다.

동일한 고유도 부위가 허용하면 함께 착용한다. 속행의 반지 두 개를 두 반지 칸에 각각 착용할 수 있으며 다른 성급의 조합도 가능하다. 각 인스턴스의 기반/일반 성능을 모두 합산하고 효과별 중첩·무효 우선순위는 아래 확정 정의를 따른다.

비교에는 일반 수치 변화와 새로 생기거나 사라질 특수 효과를 표시한다. 계산 데이터가 아직 없는 효과는 미정 사유를 안내하고 수치 0으로 대신하지 않는다. 특정 고유가 없어도 파밍·경쟁에 입장할 수 있으며 최고 도달 성과에 주는 영향은 후속 빌드/전투 검증에서 확인한다.

## 첫 고유 3종의 확정 정의

이름은 자체 기획용이다. 괄호의 4성→5성 수치는 같은 고유·성급에서 고정이며 각 효과는 장착 중에만 적용한다.

| 고유 | 기반 성능 | 일반 옵션 2개 | 특수 효과 1개 |
| --- | --- | --- | --- |
| 안정의 목걸이 | 힘형: 힘 +20→25 | 최대 생명력 +60→75, 힘 +16→20 | 치명타를 발생시키지 않으며 자신의 명중 피해 25% 증폭 |
| 속행의 반지 | 화염 저항형: 화염 저항 +12→14%p | 최대 생명력 +48→60, 재사용 회복 속도 12→15% 증가 | 재사용 회복 속도 40% 증가, 자신의 명중 피해 20% 감폭 |
| 불굴의 허리띠 | 생명력형: 최대 생명력 +80→100 | 최대 생명력 +60→75, 화염 저항 +12→15%p | 최대 보호막 0, 최대 생명력 30% 증가 |

세 고유 모두 일반 옵션 종류·값을 무작위로 뽑지 않는다. 기반 성능은 이미 확인한 힘형 목걸이·화염 저항형 반지·생명력형 허리띠의 4/5성 고정 특성을 사용한다. 고유의 일반 옵션은 자체 고정 정의이며 희귀 접두/접미의 7단계 추첨이나 6칸 구조를 변경하지 않는다.

## 중복 착용·적용 대상과 계산

| 연결 규칙 | 확정 규칙 |
| --- | --- |
| 같은 고유 착용 | 부위가 허용하면 가능. 속행의 반지 두 개를 반지 두 칸에 각각 착용 가능 |
| 일반 수치 | 각 장착 인스턴스의 기반 성능·일반 옵션을 모두 정상 합산 |
| 반지 중첩 | 개당 재사용 회복 +40%를 같은 증가 합계에 더하고, 명중 피해는 개당 ×0.8을 곱함. 두 개면 특수 효과만 +80%와 ×0.64 |
| 목걸이 우선순위 | 무기/젬 기본 확률·장비 증가·패널티와 관계없이 자신의 최종 치명타 확률 0. 치명타 배율은 해당 장착 중 피해에 기여하지 않음 |
| 허리띠 우선순위 | 다른 장비에서 보호막을 얻어도 최종 최대 보호막 0. 생명력 증가 +30%는 해당 증가 합계에 더함 |
| 함께 착용 | 목걸이+반지 2개+허리띠 동시 가능. 이 첫 목록으로 고유 4개를 착용할 수 있으며 추가 총수 제한을 두지 않음 |
| 효과 주체 | 자신의 기본 공격과 공격/주문 스킬의 명중 피해. 반지 회복 속도는 재사용 시간이 있는 자신의 스킬에 적용하며 공격/시전 동작 속도는 바꾸지 않음 |
| 장착/해제 상태 | 장착 변경 자체로 생명력/보호막을 회복하지 않음. 현재값은 새 최대값 이하로만 제한하며, 허리띠 해제 후 보호막은 0에서 기존 재충전 규칙으로 회복 |

같은 고유의 다른 성급도 각 인스턴스를 합산한다. 4성+5성 속행의 반지는 일반 재사용 회복 +27%, 특수 회복 +80%, 명중 피해 ×0.64다. 목걸이와 허리띠는 각 부위가 1칸이므로 첫 목록에서 같은 고유를 두 개 착용할 자리가 없다. 향후 고유/부위가 늘면 해당 효과의 중복 규칙도 다시 확인한다.

안정의 목걸이는 기본 공격·공격/주문 모두 최종 치명타를 막으며 치명타 발생을 조건으로 하는 사건을 만들지 않는다. 기초 치명타/배율 데이터와 장비 옵션은 삭제하지 않고 목걸이를 해제하면 기존 규칙으로 다시 계산한다. 확률 0은 조건을 만족해도 치명타가 발생하지 않는다는 뜻이지 치명타 옵션을 다른 능력으로 전환한다는 뜻이 아니다.

속행의 반지의 40%는 재사용 시간 40% 차감이 아니다. 특수 효과 외 회복 증가 합계를 I(%), 반지 수를 k=0~2라 하면 최종 재사용 시간은 기본 시간÷(1+(I+40k)/100)이다. I에는 반지 일반 옵션 12/15%와 다른 장비·보조의 적용 가능한 회복 증가가 포함된다. 소켓 그룹/보조의 호환성과 자동 사용 순서는 기존 규칙을 따른다. 실제 발동이 동작 시간·타깃·이동 때문에 늦어질 수 있다.

증폭·감폭은 일반 증가 합계와 구분해 곱한다. 목걸이와 반지 두 개를 함께 쓰면 이 세 특수 효과의 명중 피해 배율은 1.25×0.8×0.8=0.8이다. 기본 공격에도 감폭은 적용되지만 기본 공격에 재사용 시간이 없으면 반지의 회복 증가로 그 공격을 빠르게 만들지 않는다. 지속 피해·소환수·상태이상에 적용하는 새 규칙은 이번에 도입하지 않는다.

불굴의 허리띠는 기반/옵션의 생명력 정액 합산 후 최대 생명력 증가 합계에 +30%를 더한다. 첫 정의에서 다른 최대 생명력 증가가 없으면 전체 생명력 합계×1.3이며 최종 최대 생명력의 소수점 아래만 버린다. 현재 생명력을 늘려 주는 회복 효과는 아니다. 최대 보호막과 현재 보호막은 0으로 제한하며 다른 장비의 보호막 옵션을 생명력으로 전환하지 않는다. 생명력 회복/패널티는 기존 규칙을 따르고 허리띠로 치유나 즉시 재충전을 발동하지 않는다.

## 세 빌드 목표와 희귀 제작의 역할

| 검증 목표 | 먼저 비교할 구성 | 희귀 제작에서 볼 부분 |
| --- | --- | --- |
| 안정적인 비치명 명중 | 목걸이 있음/없음, 낮은 치명타와 높은 치명타 투자 각각 | 피해·속도·요구 능력치와 생존. 목걸이 중 치명타 확률/배율 투자의 기여가 없어지는 점 |
| 재사용 중심의 잦은 스킬 사용 | 반지 0/1/2개와 4/5성 혼합, 목걸이 결합 | 실제 동작 시간·재사용 회복·명중 피해·젬 조건. 대기시간 단축이 실제 발동 수로 이어지는지 |
| 보호막을 포기한 생명력 생존 | 허리띠 있음/없음, 보호막 장비 비중 변화와 다른 고유 결합 | 생명력·방어도·회피·저항·회복. 사라지는 보호막과 생명력 증가의 교환 |

세 검증 목표는 직업 세 개나 고유 필수 입장 조건을 확정한 것이 아니다. 무고유 희귀 구성도 같은 조건에서 비교한다. 특수 효과가 없는 희귀의 6칸 옵션으로 높은 치명타·보호막·조건 충족을 완성하는 구성이 경쟁력을 갖는지도 확인할 대상이다.

## 비교 사례와 실제 검증의 구분

목걸이 효과만 비교해 일반 명중 100·치명타 배율 200%를 가정하면, 치명타 0% 구성의 평균 100은 목걸이로 125가 된다. 치명타 50% 구성의 평균 150은 목걸이로 125가 된다. 이는 다른 장비 교체 차이를 제외한 설명 사례이며 실제 스킬의 기본 피해/치명타를 확정하는 값이 아니다.

다른 회복 증가가 없고 재사용 시간만 병목인 사례에서 4성 반지 하나는 시간÷1.52·명중×0.8, 두 개는 시간÷2.04·명중×0.64다. 5성 둘은 시간÷2.10·명중×0.64다. 이 수치를 실제 종합 DPS나 클리어 성과로 보장하지 않는다. 세 자동 스킬이 동작 시간을 공유하는 경우와 보조·타깃/이동을 포함한 결과는 실제 실행에서 비교해야 한다.

## 획득과 기존 규칙 변경 범위

선행 DEC-0095의 희귀 드롭에 대해 DEC-0104에서 **4~5성·위 3부위에 한해** 장비 보상 생성 앞에 희귀 97%/고유 3% 판정을 추가했다. [장비 드롭 기획서](Equipment-Drops-and-Farming-Targets.md)의 희귀 조건부 분포는 유지한다. 희귀가 선택된 뒤 기반·옵션 개수·종류·단계·값은 기존 규칙을 사용한다.

고유가 선택되면 해당 부위의 첫 고유 1종을 구간과 같은 성급으로 준다. 따라서 목걸이를 목표로 파밍할 때 고유 반지를 지급하지 않는다. 1~3성이나 다른 부위는 기존 희귀 100%를 유지한다. 고유 목록 확장·경쟁/오프라인 지급·구매/교환 경로는 별도 확인 사항이다.

모딩은 기존대로 패널티 수×20% 확률로 장비를 한 번 더 추첨한다. 추가 장비도 희귀/고유 97/3%를 따르므로 모딩은 고유를 뽑을 기회도 늘리되 개별 장비의 3% 확률은 올리지 않는다. 재료 보상·모딩 준비 비용은 바꾸지 않는다. 파밍 실패/포기에는 해당 도전의 장비·재료 보상을 지급하지 않는 규칙을 유지한다.

고유를 직접 추가 지급하지 않아 장비 보상은 기본 1개·모딩 포함 최대 2개다. 기존 입장 전 빈 칸 1/2개 조건과 준비/전투 중단·1회 정산을 따른다. 천장 없는 독립 추첨이므로 획득 시점과 중복 횟수는 보장하지 않는다.

## 분해·취소와 복원

선행 DEC-0100의 희귀 분해에 대해 DEC-0104에서 고유의 **단건 분해만** 추가했다. [장비 관리 기획서](Equipment-Inventory-Comparison-and-Salvage.md)를 함께 따르며, 일괄 분해·필터 결과 전체 선택에서는 고유를 계속 제외한다. 고유를 볼 수 있는 희귀/고유 필터를 제공하고 필터 변경만으로 처분 대상을 자동 선택하지 않는다.

단건 확인에는 실제 장비·고유 표시·특수 효과·분해 재료 확률을 보여 준다. 4/5성·중복·보유 기간과 관계없이 부여/제거/교체/조율/집중석을 30/15/35/15/5%로 한 번 추첨한다. 고유 전용 분해 재료·과거 비용 환급·모딩 보너스 재적용은 추가하지 않는다.

확정 전 취소는 변경이 없고 확정 뒤 삭제와 보상을 함께 저장한다. 재접속으로 아이템/보상을 복제하거나 추첨을 다시 하지 않는다. 장착·해제도 한 번 적용한 결과를 복원한다. 저장/서버 방식과 UI 시안·아트는 별도 구현 전 조사·제안 범위다.

## 승인·후속 범위와 검증

승인 기록은 [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)이며 사용자는 직전 선택지 “2안으로 가자”로 복수 고유 착용을 확인했다. 1안의 총수 제한을 해제한 대안을 적용하고 나머지 공통 규칙을 유지한다. 첫 3종의 효과/수치·중복·중첩과 세 검증 목표는 후속 [DEC-0105](../Decisions/DEC-0105-first-unique-effects-stacking-and-build-goals.md)에서 확인했다. 정식 스킬·젬 성장·캐릭터 구성과 콘텐츠/파밍 시간은 [기획 순서](../01-Decision-Queue.md)의 후속 범위다.

[고유 장비 조사](../../Research/2026-11-19-unique-equipment-role-acquisition-and-handling.md)에 GGG·PoEDB·커뮤니티·고정 PoB의 출처·버전·권리·Unity 호환성과 재사용 제약을 기록했다. 위 성급·드롭 확률·분해 등은 자체 초기 규칙이며 PoE의 규칙/수치를 반입한 것이 아니다.

이번에는 기획 문서만 반영했다. 고유 데이터·Unity 장착/드롭/분해/저장·PoB/게임 실행·경제/모바일 사용성 검증을 수행하지 않았다. 확인받은 공통 규칙과 개별 효과/수치를 실제로 구현하기 전에 기술 조사·적용·검증 계획을 별도로 제안한다.

후속 검증은 허용 구간/부위·희귀 조건부 분포·기본/모딩 일치·최대 장비 수·복수 착용과 교체·가방 수량/젬 재평가·단건/일괄 경계·취소/중단/1회 정산이다. 빌드와 파밍 시간을 정한 뒤 희귀 교체의 가치·고유 조합별 성능·수급/긴 미획득 연속을 비교한다.

개별 효과의 [조사](../../Research/2026-11-19-unique-effects-stacking-and-build-cases.md)는 문헌·정의/산술 확인과 실제 게임 검증을 구분한다. 12가지 착용 형태와 성급/혼합, 일반 수치 합산, 치명타/보호막 무효, 재사용 합산/감폭·패널티/보조·동작 병목, 장착 반복의 무회복·중단 복원·표시/실제 일치와 무고유 희귀 구성을 후속 검증한다. 새 고유의 전투·생존·경제 성능이 검증됐다는 의미는 아니다.
