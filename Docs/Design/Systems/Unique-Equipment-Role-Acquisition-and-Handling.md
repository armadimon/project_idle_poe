# 고유 장비의 역할·획득·착용·처분 기획

상태: [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)에서 직전 제안의 **2안(B), 부위가 맞는 여러 고유의 동시 착용**을 확인했다. 공통 획득·성급·수치 구조·처분 규칙은 유지하며 추천 1안의 고유 총수 1개 제한을 채택하지 않는다. 희귀 제작과 고유의 특수 효과라는 [선행 방향](../Decisions/DEC-0012-crafting-equipment-scope.md)을 구체화하고 [첫 제작 모델](Equipment-Crafting.md)에 고유 제작을 추가하지 않는다.

## 확정 공통 규칙

| 항목 | 확정 규칙 |
| --- | --- |
| 역할 | 전투 규칙·스킬 활용을 바꾸는 선택형 장비. 고유 획득을 입장·성급 해금의 필수 조건으로 두지 않음 |
| 첫 목록 | 목걸이·반지·허리띠에 각각 1종, 총 3종. 각 고유를 4성·5성으로 제공 |
| 옵션 구조 | 고유별 정해진 기반 성능과 일반 옵션 2개+특수 효과 1개. 같은 고유·성급의 모든 값 고정, 무작위 접두/접미 추첨 없음 |
| 성급·제작 | 획득 성급 고정·승급/옵션 이전 없음. 5성은 일반 성능을 높이고 특수 효과의 규칙·수치는 4성과 동일. 기본 4종 제작과 집중석 사용 불가 |
| 장착 | 부위 관계가 맞는 여러 고유를 함께 착용, 고유 총수 1개 제한 없음. 전투 밖 무료 장착·해제, 별도 성급/레벨/능력치 착용 제한 없음. 동일 고유 중복/중첩은 후속 확인 |
| 획득 | 4~5성의 목걸이·반지·허리띠 파밍 장비 보상 1개마다 희귀 97%·해당 부위 고유 3%. 기본·모딩 추가 장비 추첨에 동일 적용 |
| 보상 개수 | 희귀 보상의 일부를 고유로 대체. 별도 추가 장비 지급 없음·기존 최대 장비 2개와 입장 공간 1/2칸 유지 |
| 추첨·정보 | 추첨별 독립, 중복 획득 허용·천장 없음. 대상/성급·97/3%·특수 효과와 고정값을 게임 안에 공개 |
| 보관·보호 | 기존 무료 500칸 안에서 1개=1칸. 획득 시 분해 보호 기본 해제, 장착/보호 장비는 분해 금지 |
| 분해 | 미장착·보호 해제된 고유는 무료 단건 분해만. 기존 제작재료 1회 추첨·1개, 30/15/35/15/5%. 일괄 분해·전체 선택에서는 고유 제외 |

이번 확인은 공통 규칙이다. 첫 고유의 이름·기반/일반 성능 수치·특수 효과와 수치는 아직 미정이다. 서로 다른 빌드 목표와 세 고유의 실제 효과·수치, 같은 고유의 복수 착용·동일 효과 중첩과 충돌 처리를 [다음 묶음](../Proposals/Unique-Equipment-Effects-and-Build-Cases.md)에서 함께 제안하고 다시 확인받는다.

## 역할·구조와 장착

일반 옵션 2개는 고유별로 정해진 종류와 고정값을 사용하고 희귀 장비의 무작위 6칸 추첨과 구분한다. 고유의 기반·일반 성능은 정의표에 등록할 값이며 이번에 기존 희귀 기반 목록/옵션 범위를 변경하지 않는다. 고유를 희귀로 변환하거나 희귀에서 고유로 승급시키는 작업은 추가하지 않는다.

전투 중에는 고유 장착·해제·분해를 실행하지 않는다. 장착 부위 관계를 지키며 고유라는 이유로 전체 장착 수를 1개로 제한하지 않는다. 서로 다른 부위의 고유를 함께 착용할 수 있고, 기존 고유를 해제하라는 총수 제한을 적용하지 않는다. 장비 교체는 기존 반지 교체 칸 선택·가방 수량 보존·젬 조건 재평가를 따른다. 개별 장비를 가방으로 해제할 때는 빈 칸 1개가 필요하고 부족하면 정리를 안내한다.

동일한 고유 반지 두 개의 장착 허용과 같은 특수 효과의 중복/중첩·무효 우선순위는 이번 공통 결정에서 임의로 확정하지 않는다. 서로 다른 고유를 동시에 사용할 수 있다는 정책과 같은 고유 인스턴스를 여러 개 쓰는 정책을 구분한다. 개별 효과/수치 묶음에서 연결된 조건을 함께 확인하며, 현행 기획을 읽는 구현은 미정인 중복 규칙을 임의 기본값으로 채우지 않는다.

비교에는 일반 수치 변화와 새로 생기거나 사라질 특수 효과를 표시한다. 계산 데이터가 아직 없는 효과는 미정 사유를 안내하고 수치 0으로 대신하지 않는다. 특정 고유가 없어도 파밍·경쟁에 입장할 수 있으며 최고 도달 성과에 주는 영향은 후속 빌드/전투 검증에서 확인한다.

## 획득과 기존 규칙 변경 범위

선행 DEC-0095의 희귀 드롭에 대해 DEC-0104에서 **4~5성·위 3부위에 한해** 장비 보상 생성 앞에 희귀 97%/고유 3% 판정을 추가했다. [장비 드롭 기획서](Equipment-Drops-and-Farming-Targets.md)의 희귀 조건부 분포는 유지한다. 희귀가 선택된 뒤 기반·옵션 개수·종류·단계·값은 기존 규칙을 사용한다.

고유가 선택되면 해당 부위의 첫 고유 1종을 구간과 같은 성급으로 준다. 따라서 목걸이를 목표로 파밍할 때 고유 반지를 지급하지 않는다. 1~3성이나 다른 부위는 기존 희귀 100%를 유지한다. 고유 목록 확장·경쟁/오프라인 지급·구매/교환 경로는 별도 확인 사항이다.

모딩은 기존대로 패널티 수×20% 확률로 장비를 한 번 더 추첨한다. 추가 장비도 희귀/고유 97/3%를 따르므로 모딩은 고유를 뽑을 기회도 늘리되 개별 장비의 3% 확률은 올리지 않는다. 재료 보상·모딩 준비 비용은 바꾸지 않는다. 파밍 실패/포기에는 해당 도전의 장비·재료 보상을 지급하지 않는 규칙을 유지한다.

고유를 직접 추가 지급하지 않아 장비 보상은 기본 1개·모딩 포함 최대 2개다. 기존 입장 전 빈 칸 1/2개 조건과 준비/전투 중단·1회 정산을 따른다. 천장 없는 독립 추첨이므로 획득 시점과 중복 횟수는 보장하지 않는다.

## 분해·취소와 복원

선행 DEC-0100의 희귀 분해에 대해 DEC-0104에서 고유의 **단건 분해만** 추가했다. [장비 관리 기획서](Equipment-Inventory-Comparison-and-Salvage.md)를 함께 따르며, 일괄 분해·필터 결과 전체 선택에서는 고유를 계속 제외한다. 고유를 볼 수 있는 희귀/고유 필터를 제공하고 필터 변경만으로 처분 대상을 자동 선택하지 않는다.

단건 확인에는 실제 장비·고유 표시·특수 효과·분해 재료 확률을 보여 준다. 4/5성·중복·보유 기간과 관계없이 부여/제거/교체/조율/집중석을 30/15/35/15/5%로 한 번 추첨한다. 고유 전용 분해 재료·과거 비용 환급·모딩 보너스 재적용은 추가하지 않는다.

확정 전 취소는 변경이 없고 확정 뒤 삭제와 보상을 함께 저장한다. 재접속으로 아이템/보상을 복제하거나 추첨을 다시 하지 않는다. 장착·해제도 한 번 적용한 결과를 복원한다. 저장/서버 방식과 UI 시안·아트는 별도 구현 전 조사·제안 범위다.

## 승인·후속 범위와 검증

승인 기록은 [DEC-0104](../Decisions/DEC-0104-unique-equipment-with-multiple-equipped-items.md)이며 사용자는 직전 선택지 “2안으로 가자”로 복수 고유 착용을 확인했다. 1안의 총수 제한을 해제한 대안을 적용하고 나머지 공통 규칙을 유지한다. 개별 고유와 효과/수치·중복·중첩/충돌은 [다음 미승인 묶음](../Proposals/Unique-Equipment-Effects-and-Build-Cases.md)에서 확인한다.

[고유 장비 조사](../../Research/2026-11-19-unique-equipment-role-acquisition-and-handling.md)에 GGG·PoEDB·커뮤니티·고정 PoB의 출처·버전·권리·Unity 호환성과 재사용 제약을 기록했다. 위 성급·드롭 확률·분해 등은 자체 초기 규칙이며 PoE의 규칙/수치를 반입한 것이 아니다.

이번에는 기획 문서만 반영했다. 고유 데이터·Unity 장착/드롭/분해/저장·PoB/게임 실행·경제/모바일 사용성 검증을 수행하지 않았다. 공통 규칙과 개별 효과/수치를 확인한 뒤 구현 전 기술 조사·적용·검증 계획을 제안한다.

후속 검증은 허용 구간/부위·희귀 조건부 분포·기본/모딩 일치·최대 장비 수·복수 착용과 교체·가방 수량/젬 재평가·단건/일괄 경계·취소/중단/1회 정산이다. 빌드와 파밍 시간을 정한 뒤 희귀 교체의 가치·고유 조합별 성능·수급/긴 미획득 연속을 비교한다.
