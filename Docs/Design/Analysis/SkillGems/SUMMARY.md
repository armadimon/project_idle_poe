# 스킬·젬 전체 초안의 정적·수치 검증 결과

**2026-11-23 · 검토용 초안.** [전체 기획](../../Proposals/Skill-Gems-and-Build-Diversity.md) · [원본 조사](../../../Research/2026-11-23-poe1-skill-gem-build-layers.md) · [상세 표](REPORT.md) · [전체 결과](results.json)

**결론:** 24액티브·24보조·13개 편성이 규칙상 성립하며 적 조건에 따라 성과 순위가 달라졌다. 그러나 **모든 빌드의 경쟁력이 검증된 상태는 아니다.** 출혈 도끼의 밀집 다수 우세, 치명 연동의 낮은 화력, 생명 소모의 생존 문제와 속행 반지의 제한적인 이득을 발견했다. 합법 조합 수를 재미나 유효 빌드 수로 보고하지 않는다.

보조 순서는 구별하지 않고 서로 다른 액티브의 세 슬롯 순서는 구별한다. 공유 액티브는 무기 문맥마다 포함한다. 장비·세 그룹 전체·적을 전역 최적화한 수가 아니다.

## 발견·수정과 남은 문제

1. **출혈의 전 조건 우세:** [조정 전 결과](calibration-v1.json)는 기본 네 조건 모두 출혈 도끼가 1위였다. 초당 계수 60%→18%, 직접 물리 공격으로 범위 제한, 지속 명중의 출혈 연결 제거로 조정했다. 현재도 밀집 조건 평균 12,303.7로 2위보다 높다. 균열의 다중 명중/범위·도끼 기반 피해까지 함께 조정할 과제다.
2. **주문 성장 부족:** 무기가 성급으로 커지는 공격과 같은 +2%/Lv.로 두니 주문이 뒤처졌다. 주문만 +12%/Lv., Lv.20 배율 3.28로 제안했다. 새 주문의 육성 격차가 커지는 비용도 있다.
3. **상태이상 틱 지연:** 빠른 갱신마다 다음 틱을 미뤄 피해가 사라지는 모델 오류를 고쳤다. 다음 틱을 유지하는 회귀 테스트를 추가했다.
4. **연동으로 동작 손해 제거:** 연동+묵직한 일격은 동작 증가의 손해만 사라지므로 금지했다. 연동+반복/메아리도 제한한다.
5. **불필요한 능력치 접미:** 모든 부위에 요구 능력치를 우선 넣던 비교 장비를 고쳐 요구치 충족 후 다른 옵션을 선택하게 했다. 여전히 휴리스틱이며 최적 장비 보장은 없다.
6. **관찰 종료 경계:** 정확히 60초에 새 활성화를 세던 경계를 [0,60초)로 수정했다. 초당 220 피해가 나오는 독립 예제로 확인했다.
7. **치명 연동의 화력 부족:** 발동원 빈도·세 액티브 자리·공유 제한을 고려하면 일반 시전보다 불리한 경우가 많다. 성립만 했다는 이유로 완성 빌드로 추천하지 않는다.
8. **생명 소모의 지속 가능성:** 흡혈 2%→4% 조정 뒤에도 압박 조건 생존 0/24다. 생명 비용·재생·실제 표적·피해 감소를 함께 조정할 과제다.
9. **고유 손익:** 시험한 12형태의 기본 조건 전체 최고 피해 편성은 고유 없는 희귀 또는 안정 목걸이 구성이었다. 재사용 증가 합산·동작 병목·반지당 ×0.8을 반영하면 속행 반지 두 개가 항상 이득이 아니다. 기존 승인 성능은 변경하지 않았다.

테스트는 지정 규칙과 산술을 확인한다. 수치 우열을 모두 ‘통과’로 만들거나 약한 후보를 숨기지 않았다.

## 검증 경계

- 실제 Unity 실행·이동·충돌·가시선·렌더/기기 성능은 수행하지 않았다. 범위/투사체 표적 수는 기대 기하 근사다. 고리 빈 중심·일제 발사 각도·벽·왕복 이동을 물리적으로 재현한 결과가 아니다.
- 적 HP/오버킬이 없어 클리어 시간·최고 단계·파밍 시간·종결 제작 시간을 계산하지 않는다. HP +30%가 무한 대상 DPS를 바꾸지 않는 것은 모델 한계다.
- 고유 비교는 동일 5성 착용 형태다. 모든 4/5성 혼합·모든 희귀 옵션 조합을 전수 검사하지 않았다.
- 1/3/5성은 같은 적 조건의 민감도이며 실제 초반 난도나 성장 시간 검증이 아니다.
- 소환수·중독·혼돈·마나/예약·패시브·서버·오프라인 진행은 모델 밖이다. XP JSON 정산 검사를 실제 전투 세이브 복원과 구분한다.
- 시간은 연속 초와 반올림을 사용하며 실제 틱 양자화는 다루지 않는다. 흡혈 상한은 이동 시간창 대신 정수 초 버킷이다. 적 공격속도 모딩은 공격/주문 혼합의 기대 빈도를 보존하지만 정확한 사건 간격은 근사다.
